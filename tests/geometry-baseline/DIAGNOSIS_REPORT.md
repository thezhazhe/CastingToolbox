## 一、链路数据（合成模型模拟真实形态；真实 STL 待用户提供后补入 tests/real-stl/）

### 案例 A：板 20mm + 圆柱 100mm（= 用户报告的"100mm 圆柱无法识别"）

```
① STL bbox:          800 × 600 × 100 mm   mdim=800   triCount=154k
② 距离场:            gs=48³  vs=16.667 mm
   壁厚 20mm 采样层 = 1.2 voxel ← 异常起点
③ inside:            3616 / 110592
④ 距离场统计:        min=0.26  P50=1.67  P95=1.67  max=38.15（半壁厚语义）
   厚度估计:          P95×2=3.33mm   max×2=76.3mm（圆柱 100 → 应≈100）
⑤ hotspot:           NO_HOTSPOT (uniform)  ← 漏检
   uniform 判据:      候选=1 区域=1（圆柱中心）→ 无第二结构 → 判均匀
```

**第一次出错位置：② 距离场**——vs=16.667mm 由 `mdim=800 ÷ 48 格` 决定，与壁厚无关。
板 20mm = 1.2 voxel → 板中面层消失 → 板信号在 ③④ 全部丢失 → ⑤ uniform 判据只见
圆柱（1 个候选）→ 无薄区对比 → 判"均匀" → 漏检。

## 二、根因分类（A-F）

| 分类 | 结论 | 证据 |
|---|---|---|
| **A. 几何问题** | **排除** | tetMC 与真实 CAD 网格同链路；watertight/体积正常 |
| **B. STL 单位/尺度问题** | **排除** | 三尺度行为完全一致（采样层数不变）；单位明确假设 mm |
| **C. voxel 分辨率问题** | **主根因** | vs=mdim/48 与壁厚无关；箱体/框架/壳体件（壁厚 << bbox）升分辨率条件（minDim < 6×vs）**不触发** → 壁厚 1-2 voxel → 测不准/漏检。20mm 板在 800mm 级 bbox 下 = 1.2 voxel（案例 A/B） |
| **D. distance field 问题** | **次因（方法学）** | 距离场 = 最近表面距离（半壁厚语义）对"板/管/壳"（平行面）正确（tube20 P95×2=19.5 ✓）；对"圆柱/环"（非平行面）P95×2 只有直径的 73-91%（应 max×2 或径向厚度）。引擎 mc=局部极大=中面半厚 ✓ 语义正确 |
| **E. hotspot 判定问题** | **次因（uniform 误判）** | 低分辨率下薄区信号（板中面/候选/局部极大）全部消失 → uniform 判据只见主厚区 1 个候选 → 判均匀 → 漏检（案例 A：wall20+cyl100） |
| **F. 其他** | 无 | — |

**根因链一句话**：`vs=bbox主维÷48` 使大铸件的 20mm 壁厚只有 1-2 个 voxel（C 类），
距离场在 1 voxel 层上无法产生有效薄区信号（板中面层消失，D 类连带），uniform 判据
因此把"厚区+薄区"件误判为均匀件（E 类）→ "过薄/无法识别"。

## 三、修复方向（下一轮，待用户确认后实施）

1. **升分辨率改为"基于粗扫距离场估计壁厚"**（两阶段）：
   48³ 粗扫 → 距离场高百分位（P95×2）估计壁厚 → 若 < 6 voxel → 升分辨率重扫。
   替换现有"minDim（bbox 最小维）近似壁厚"规则——这是 C 类的直接修法，
   对箱体/壳体/框架件立即生效。**不是调低阈值，是让采样层数达标**。
2. **uniform 判据兜底**（E 类）：低分辨率（vs > 薄区厚度）时薄区信号消失——
   增加"绝对厚度差"信号（主候选厚度 vs 全局低百分位厚度，如 >3 倍）。
   需要先用真实 STL 验证再定。
3. **圆柱/环厚度语义**（D 类）：诊断输出 max×2（径向厚度）+ 形状提示；
   mc 语义不动（V2.2 冻结）。
