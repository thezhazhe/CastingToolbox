# Casting Toolbox · 铸造工具箱

> **铸造工程师每天都会打开一次的开源瑞士军刀** —— 完全离线 · 完全免费 · 完全开源

Casting Toolbox 是一个专注于解决铸造工程师日常高频问题的工具箱：**计算工具 + 知识库 + 工艺向导** 三大模块。只解决每天最常遇到的 20% 问题（80/20 原则），不碰有限元 / CFD / AI 自动设计。

**隐私承诺**：所有计算与数据都在本地浏览器完成，不经过任何服务器，无需联网，数据不出本机。

## ✨ 功能

### 🏠 首页（Bing 式搜索）
打开即是大搜索框：输入关键字即**实时下拉**出相关知识 / 计算工具（与顶栏搜索一致），回车进独立搜索页。首屏只显示大搜索框 + 常驻「🎯 生产场景」面板（**材料大类** / 造型线 / 生产方式 / 铸造方法），下方推荐区**渐进展开**（点提示条 / 滚轮展开）——设置场景后变为「🎯 针对你的生产场景」推荐：**场景摘要 + 📋参数速查卡 + ✅操作要点**，以及**对口计算工具 · 常见缺陷 · 相关标准 · 相关知识**（由 `data/scenarios.js` 映射 + 标签确定性驱动，无 AI、结果稳定）。应用场景时直接回显「已匹配 N 工具 / M 缺陷 / K 标准」。不设置场景时显示常用工具与工艺向导入口。

### 🧮 计算工具（8 个，独立模块）
| 工具 | 说明 |
|---|---|
| 浇注系统设计 | Dietert 浇注时间 · 奥赞阻流截面 · 直/横/内浇道 · 排气面积 · 流速/排气校核 |
| 冒口设计 | 热节模数 Mc · 冒口形状库 · 补缩效率 · 冒口颈 · 自动迭代至校核通过 |
| 线收缩率 | 各材质线收缩率 · 模型/模具放尺计算 |
| 加工余量 | GB/T 6414 查表（RMA）· 铸造方法推荐等级 |
| 铁液重量 | 铸件毛重 ÷ 出品率，估算铁液/浇冒口重量 |
| 出品率 | 铸件/浇注重量比，对照材料推荐区间 |
| 铸件结构工艺性 | 最小壁厚 · 临界壁厚 · 铸造圆角 · 拔模斜度 · 最小铸孔（按材质/尺寸/批量） |
| 缺陷查找 | 按缺陷名/俗称/症状找问题：GB/T 5611 八大类 · 特征 · 原因 · 对策 · 相关标准 |

### 📚 知识库（145 条 · 工艺卡片）
- **统一搜索**是普通用户主入口（独立搜索页 `#/search`）：结果按 **材料 / 知识 / 计算工具 / 常见缺陷 / 标准** 分类显示；若已设置**生产场景**，顶部还会出现「🎯 符合生产场景」组（按标签匹配，只提升不隐藏，结果稳定）。
- 叶子条目升级为**工艺卡片**：推荐参数 + 内容 + **相关计算工具 / 常见缺陷·同材质 / 相关标准 / 相关知识**（按标签确定性互链），一卡看懂一条数据能用在哪。
- 三级树（6 大主题 → 分组 → 条目）保留用于**后台维护**：普通用户不可见，开发者点左上角 **Logo 5 次 → 输密码** 解锁后浏览。

六大主题数据：**🧪 铸造材料**（26，含国内外牌号对照/结构工艺性）· **🧱 熔炼原辅材料**（20，入厂验收技术要求）· **⏳ 型砂与造型**（8，湿型砂控制通用 + DISA 型砂双显）· **🌡️ 铸造工艺与配料**（33，含热处理规范/8 个配料案例/垂直分型通用设计）· **🩹 缺陷对策**（30，按 GB/T 5611 八大类：孔洞/裂纹冷隔/表面/夹杂/形状重量/残缺/多肉/金相成分组织，供「缺陷查找」工具检索）· **🖨️ 设备**（29，3D砂型打印 + DISA 垂直造型线）
- 每条知识保留**出处**（书/章，**不再维护页码**）并带**置信度**（🟢 高 = 一手工厂资料/官方手册 · 🟡 中高 = 标准成熟值 · 🟠 中 = 二手整理），后续新数据冲突时按置信度取舍
- ⭐ 数据源自**真实工厂资料 + DISA 官方手册 + 国标/联网核对**，已做**公司信息脱敏**；湿型砂控制与垂直线浇注计算**适用于各类造型线**

### 🎯 生产场景（Current Context）
**首页常驻设置面板**，或向导完成**自动保存**当前**材料大类（灰铁/球铁/铸钢/铝合金/铜合金）/ 造型线 / 生产方式 / 铸造方法**；顶栏显示场景条（可手动编辑/清除）。
- **设置即见**：应用场景后首页立即给出**场景摘要**（已匹配 N 工具 / M 缺陷 / K 标准）、**理由话术**（为什么这么建议）、**参数速查卡**（代表牌号的浇温/密度/线收缩/出品率/补缩效率/凝固特性）与**操作要点**——来自 `data/scenarios.js` 映射层，确定性、可解释。
- **向导反向读取**：设置过场景后，进工艺向导第 1 步**自动预选**该材质族代表牌号，第 5 步生产条件自动带入，不用重复选。
- 各计算工具**优先读取场景自动预选材质**（无匹配仍可手输）；搜索按场景提升「符合生产场景」卡片。
- **扩展**：加新材质族/缺陷/标准/参数/要点，只需改 `data/scenarios.js`（数据独立，逻辑与视图不动）。

### 🚀 下一步建议
每个计算工具算完，底部给出确定性"下一步操作"（如冒口 → 计算浇道 / 查缩松 / 工艺向导完整方案），**不是 AI 推荐、不是猜你喜欢**，结果稳定可预期。

### 🔓 开发者模式
三级树仅开发者可见（普通用户用搜索）。点左上角 **Logo 5 次 → 输密码** 解锁（密码在 `js/devmode.js`）；解锁后侧栏出现「知识库」导航与「🔓 已解锁 · 点击锁定」徽章。

### 🧭 工艺向导
Win 激活式分步引导：选材料 → 输入重量 → 壁厚/热节 → 尺寸 → 工艺（含生产条件）→ 自动调用浇注系统 + 冒口计算工具，一键生成**工艺建议报告**并**自动保存生产场景**。材料参数自动预填，全程「下一步、下一步」即可完成。

## 🚀 怎么用

### 方式一：Node.js（源码版）
1. 下载本项目解压
2. 安装 Node.js（https://nodejs.org ，一路下一步）
3. 双击 **`start.bat`**，浏览器自动打开 http://localhost:8090/

### 方式二：单文件 EXE（免安装）
1. 双击 **`build_exe.bat`** 生成 `dist\CastingToolbox.exe`（首次需联网下载打包工具；EXE 自带品牌图标，建快捷方式时直接可见）
2. 把 EXE 与整个文件夹放在一起，双击 EXE 即用

### 方式三：安卓 APK
`dist\apk\CastingToolbox.apk` 为离线套壳安装包（约 0.5MB，内含全部 13 工具 + 164 条知识数据）。侧载安装后完全离线使用；报告「下载」会保存到手机「下载/Download」目录。

> 也可直接用 `node serve.js` 启动。
> **单实例**：EXE / start.bat / serve.js 已做单实例防重——重复双击只会**打开浏览器到现有实例**，不会多开服务器、多开页面；关闭那个服务器的控制台窗口即停止。

## 🗂 目录结构

```
CastingToolbox/
├── index.html          # 应用壳（侧边栏 + 搜索 + 视图）
├── css/                # 设计系统 tokens + 组件样式
├── js/                 # 应用入口 / 视图(首页·计算工具·搜索·知识库·向导·缺陷查找) / liveSearch(实时下拉) / context(生产场景) / scenario(场景推荐逻辑) / defect(缺陷查找逻辑) / devmode(开发者模式)
├── calcs/              # 计算工具独立模块（registry 注册）
├── data/               # 知识库 JSON（materials/rawmaterials/defects/process/equipment/disa）
│   ├── taxonomy.js     # 分类树（组织层，数据文件不动；新 JSON 在此挂节点）
│   ├── tags.js         # 标签映射表（工况过滤 + 工艺卡片互链；数据 JSON 不动）
│   ├── scenarios.js    # 生产场景建议数据（材质族→缺陷/标准/参数要点/理由；只改这里加信息）
│   └── defects.js      # 缺陷查找数据（GB/T 5611 八大类 + 名称/俗称/症状别名表；只改这里加检索词）
├── scripts/            # 数据校验 / 浏览器测试 / QA / 截图 / 资料抽取
│   └── extract/        # PDF/Word/Excel 抽取 + OCR 管线（RapidOCR）
├── serve.js            # 本地服务器（Node）
├── start.bat           # 双击启动
├── build_exe.bat       # 打包单文件 EXE
└── ...
```

**扩展计算工具**：在 `calcs/` 建模块 → 在 `calcs/registry.js` 登记（可带 `next` 下一步建议）→ 完成。
**新增知识**：`data/` 下加 JSON → 在 `data/index.js` 登记 → 在 `data/taxonomy.js` 挂树节点 → 在 `data/tags.js` 补标签 → `node scripts/validate_data.mjs` 校验（分类树 + 标签自动查漏查重）。
**扩展生产场景建议**：只改 `data/scenarios.js`（材质族 → 代表牌号/常见缺陷/相关标准/操作要点/理由话术；维度值增强）→ 首页速查卡与推荐自动更新，逻辑与视图不用动。
**扩展缺陷查找**：`data/defects/` 加对策 JSON → 在 `data/index.js`/`data/taxonomy.js`/`data/tags.js` 登记 → 在 `data/defects.js` 的 `CATEGORY_OF` 指定大类、`DEFECT_ALIASES` 补检索词 → 「缺陷查找」工具自动可用。

## 🛠 开发与测试

```bash
npm start                 # 启动本地服务器
npm test                  # 无头浏览器端到端测试（开发者模式/搜索分类/工艺卡片/生产场景/下一步建议等）
npm run validate          # 知识库 JSON 校验（领域规则）
npm run qa                # 全面测试：静态交叉引用 + 浏览器全巡检（8 工具/6 主题/全部 145 详情/搜索/向导/弹窗）
node scripts/screenshot.mjs   # 生成界面截图
python scripts/extract/ocr_pipeline.py <pdf> <页码>  # 扫描 PDF OCR 单页识别
```

**数据准确性三层安全网**：
1. `validate_data.mjs` 领域规则校验（浇温范围/密度/碳当量等，异常值拒收）
2. 关键数值双源交叉核对
3. 数据来源保留出处（书/章）

> ⚠️ **关于数据**：每条知识带**置信度**（🟢 高 = 一手工厂资料/DISA 官方手册/设备手册；🟡 中高 = 标准成熟值，关键数值已交叉核对；🟠 中 = 二手整理）。**不再维护页码**（国标会更新，页码失去意义），只保留书/章出处。数据与权威来源不符时，欢迎提 Issue 修正。
