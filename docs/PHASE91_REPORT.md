## 2. §6：Product ↔ Gating Connection 是怎么识别的

### 2.1 先说 PHASE 90 为什么在"插入"上失效（实测复现，不是推测）

PHASE 90 的判据是「浇注系统三角形**质心**到产品**外表面**的距离 ≤ tol」。用一个 ⌀20 圆柱插进 20mm 厚平板做实测：

| | 面接触 | **插入 15mm** | 贯穿 |
|---|---|---|---|
| 找到的连接口 | **1 个** ✓ | **4 个** ✗ | **15 个** ✗ |
| 连接口形心 | `[-0.03,-10.08,-0.03]` ✓ | `[-6.90,-10.12,-0.48]`（偏轴 6.9mm）✗ | 散落 |
| 起始方向偏轴 | 0° ✓ | **31°** ✗ | — |

两条根因：

1. **用质心而不是顶点** —— 插入时只有高度 ≈ tol 的一圈**窄带**的质心落在阈值内；带宽不足一个三角形就把这圈**切碎**成 4 段弧。
2. **完全没有"内 / 外"概念** —— 插在产品内部的那些面，和悬空件在算法眼里一模一样。

所以 §25 说的「识别不到 → tolerance ×10」这条路走不通：**问题不是阈值大小，是判据的维度不够。**

### 2.2 PHASE 91 的判据（§6 点名的 80/20 组合）

对每个浇注系统**顶点**：

```
d = 到产品表面的最近距离（沿用既有加速结构）
d ≤ tol          → SURFACE（贴着产品表面；由阈值直接定性，不靠射线碰运气）
d > tol          → 射线法判 IN / OUT（三条互不平行的射线取多数票，见 js/model/meshInside.js）
```

三角形按三个顶点的状态分三类：

| 类别 | 条件 | 含义 |
|---|---|---|
| **crossing 穿越** | 同时有 IN 和 OUT 顶点 | 明确穿过产品边界 —— **与阈值无关的几何事实** |
| **contact 接触** | 没有穿越，但有顶点落在表面带内 | 面接触 / 近接 |
| **inside 内部** | 顶点全在内且无穿越 | 插入体的内部，**不参与成口**，只用来回答"插进去多深" |

**成口 = {穿越 ∪ 接触}**，按**浇注系统内部的邻接**聚合（不是空间聚类 —— 空间聚类会把交汇处两条挨得很近的流道并成一个口，这是 PHASE 89 的教训）。

面的归类再决定这一口属于 §6 的哪一种：`insideCount > 0` → **insertion**；否则 `crossingCount > 0` → **crossing**；否则 → **contact**。

### 2.3 实测结果

| 情形 | PHASE 90 | **PHASE 91** | 真值 |
|---|---|---|---|
| 面接触 | 1 个口，形心 ✓ | 1 个口，`kind=contact`，312.05mm² | π·10²=314.16 |
| **插入 15mm** | **4 个口**，偏轴 6.9mm、31° | **1 个口**，`kind=insertion`，形心偏轴 **0.07mm**，方向偏轴 **0.3°**，312.18mm² | 314.16（−0.63%） |
| 插入 9mm | 4 个口 | 1 个口，312.18mm² | 同上 |
| 插入 19mm（几乎贯穿） | 多片 | 1 个口 | 同上 |
| **贯穿** | **15 个口** | **2 个口**（下表面入口 + 上表面出口，对称） | 几何上确实是 2 个 |
| 完全不接（间隙 25mm） | 0 个口 ✓ | 0 个口 ✓ | 0 |
| 完全不接（间隙 2mm） | 0 个口 ✓ | 0 个口 ✓ | 0 |

### 2.4 ★阈值无关性（§25 的正面回答）

§25 禁止「识别不到 → tolerance ×10 → 再 ×10」。这里反过来做实验：把 `tolFrac` 压到 **1/50**（tol 0.57mm → 0.011mm），**结论必须完全不变** —— 因为判连接靠的是内外几何，不是距离。

实测：连接口数 1→1，`kind` 仍是 `insertion`，口处截面积 **311.96 vs 312.18（差 0.07%）**。测试 `91-H` 锁住这条。

## 3. §8/§14：局部流动方向是怎么定的

**不使用**包围盒最长边、**不使用**主轴、**不使用**固定 X/Y/Z 平面（§14 明令 + §8 明令）。

方向来自三处，按可靠性排序：

1. **起点方向（粗估）**：连接口形心 → 本浇注系统连通分量质心。一条减法，完全可解释（§6 的字面表述）。
   退化时 → 产品质心指向浇注系统质心；再退化 → −连接面法向（只对平面接触口有效，穿越环的法向自相抵消，法向一致度会把它挡掉）；**都不行就不给方向、报 WARNING**（§13）。
2. **起步校正**：切一刀，用**截面自己的形心**反推一次局部流向（与粗估差 >15° 才改）。
3. **沿程更新**：相邻两刀**截面形心位移**（§12 的"相邻截面中心变化"）。

`91-K` 用 45° 斜管验证：截面积 **151.7~152.0**，解析 π·7² = **153.94（−1.4%）**。
若截面垂直于某个固定坐标轴，45° 管会被切成椭圆 → πr²/cos45° = **217.7（+41%）**。测试断言最大值不得接近 217.7。

## 4. §8/§16：有效横截面积 A(s) 是怎么算的

沿路径每步：

1. 取**与当前局部流向垂直**的平面（`sliceArea` 的法向 = 当前 D）；
2. **只切本连通分量的三角形**（PHASE 89 的教训：对整份网格切片会把交汇处另一条流道算进来）；
3. 取**离预测点最近的闭合环**，记 `{distance, area, centroid, direction, confidence}`。

### 4.1 §16 的四条闸门（逐刀独立判定，一刀不合规**不判整条路径死刑**）

| §16 条目 | 落地 |
|---|---|
| ① 截面闭合 | `slice.closed === false` → 标 `confidence: 'low'`，**不进 headline 统计**（环没走完就断了，面积必然被少算） |
| ② 截面面积有效 | 切不到闭合环 → invalid（`no_loop`） |
| ③ 截面中心合理 | 形心离预测点 > 上刀等效半径 × 2.5 → invalid（`off_axis`）；两环离得一样近 → invalid（`ambiguous`，不猜） |
| ④ **与相邻截面变化连续** | 低于最近几刀中位数 × 0.05 → invalid（`too_small`：畸形碎片，不是"流道变细了"） |

**第 ④ 条是 PHASE 91 新加的**，理由是实测：横浇道 + 2 内浇口的系统，交汇处斜刀切出细长条 / 子集碎环，它们**是闭合环、形心也不远**，前三条闸门全部放行，于是"最小截面积"里混进一个 **0.66mm²** 的假数（本夹具物理下限 113）。

**口处截面积**同样是**切出来实测**的，不是拿连接面的三角面面积冒充：插入情况下连接区域是一圈**环面**（面积只和带宽有关，没有通流含义）。测试 `91-A3` 断言二者必须明显不同。

### 4.2 一个必须记下来的坑：拿粗估方向去切就是斜切

口处截面积最初用的是**未校正**的粗估方向。实测一个「直浇道 + 横浇道 + 2 条并联内浇口」的系统，粗估方向**偏管子轴线 27.2°** → 斜切把面积放大了 12.4% → **同一个口给出两个矛盾的数**（口处 174.7，沿程 151.2）。这是最容易被工程师一眼看穿的那种错。

修正：切之前先用**截面形心**把方向校正一次（与起步校正同一套）。修好后 151.22 / 151.84（真值 π·7² = 153.94，−1.8% / −1.4%），与沿程实测一致。测试 `91-P` 锁住。

⚠ 中途还踩了一次：校正后的那一刀我加了"整刀只能有 1 个闭合环"的条件 —— **错了**。整个浇注系统是一个连通体，两条并联内浇口在 x=±30，水平切一刀必然同时切到两条 → 2 个环 → **正确的校正结果被我自己丢掉**。`cutSection` 本来就会挑"离预测点最近的环"，并对"两环一样近"有拒绝逻辑，用它就够了，不要在它之上再加一道更粗的闸门。

## 6. §10：多分支怎么处理

沿用 PHASE 90 已验证的两条判据（**未改动**）：

1. **闭合环 1 → ≥2**，且两环**既分得开又挨得近**（`(r1+r2)×0.6 ≤ 环心距 ≤ (r1+r2)×2.0`）。上界是实测补的：两条并排内浇口相距 90mm，追踪其中一条转向竖直后切面把另一条也带了进来，曾被误判成分叉。
2. **垂直 T 型**：沿原方向切永远只有 1 个环（切到的是横通道的纵剖面，一块板），判据 ① 永远够不到。补齐三条同时成立：板状（长宽比 ≥ 2.0）+ 面积跳升 ≥ 1.5× + **板状在半个横向跨度内就消失**。

## 7. §16：哪些情况无法可靠计算（**明确写出来**）

一行也不藏的清单。以下情况程序**不给数**，只说明原因：

| 情况 | 程序行为 |
|---|---|
| 产品 STL 没导入 | `no_product`，不猜基准 |
| 浇注系统没导入 / 空网格 | `no_gating` |
| 找不到任何连接区域 | `no_connection`（**绝不硬编一个口**） |
| 浇注系统整块埋在产品内部、没有任何边穿过产品表面 | `gating_inside_no_boundary` —— 连接关系在几何上不可判定 |
| 产品网格不水密（有洞） | `product_not_closed` —— 射线法奇偶失效，**连接结论可信度下降，如实报** |
| 有顶点的内外判定三条射线不一致 | `inside_unreliable`（带数量）—— 这些点不当作连接证据 |
| 连接口附近几何定不出起始方向 | `connection_no_direction`，该口不追踪 |
| 某一刀切不到闭合环 / 有歧义 / 面积与相邻几刀不连续 | 该刀标 invalid（带原因），**继续追踪**，不判整条路径死刑 |
| 有效样本 < 3 | 该段 `usable = false`，给 `insufficient_samples`，**量到的数照样如实给出** |
| 流道段数达到上限 | `segments_truncated`，如实说有几条支路没展开 |

### ★ 一个必须说清楚的限制：**穿过横浇道的垂直交汇处，追踪会如实停下**

真实浇注系统几乎都是「直浇道 →（垂直交汇）横浇道 →（垂直交汇）内浇口」。
从产品往外追，**必定**在第一个垂直交汇处撞上障碍：⌀12 内浇口汇入 ⌀12 横浇道时，横浇道截面形心离内浇口轴线 **30mm**（判据 15.5mm）→ 判 `off_axis` → 该段以「流道到头」结束。

**这是有意的。** 中途试过加一条宽松规则（"预测点落在环的平面包围盒内 且 环比上一刀大"就放行），A/B 实测：

| | 连接口 | 段数 | 分叉 | 最小截面积 | 可信度 |
|---|---|---|---|---|---|
| **放行** | 2 | **9** | **4** | **18.56 mm²** | ✗ 其中两段是 18.56 / 20.79（⌀12 真值 113.1）—— 漂亮但错误 |
| **不放行** | 2 | 2 | 0 | **110.62 mm²** | ✓ 各自干净量出 ⌀12 内浇口（−2.2%），交汇处如实报"流道到头" |

按 91.txt §22「**宁可 WARNING，也不要制造一个漂亮但错误的数字**」**回退了**。那段被否决的实验记录直接写在 `cutStream` 上方的注释里，免得下次再走一遍。

**后果**：对"直浇道+横浇道+多内浇口"的完整系统，目前能可靠给出的是**从产品到第一个垂直交汇处这一段**的 A(s)（也就是内浇口本身 —— 恰恰是浇注系统里最该查的那一段），横浇道以远量不到。

**这不是阈值问题，是拓扑问题**：真正的解法是"沿交汇处横向展开 + 逐支路独立成段"，属于另一个课题，91.txt §23 明确禁止本阶段扩张范围。**留给下一阶段裁决。**

## 13. 已知限制（完整清单）

1. **★ 垂直交汇处追踪会如实停下**（见 §7 末）。这是本阶段最要紧的限制：
   完整浇注系统目前能可靠给出的 A(s) 是**从产品到第一个垂直交汇处**这一段（内浇口本身）。
   **不给错数，只给"流道到头"。** 解法属于下一个课题。
2. **产品网格不水密时内外判定变弱** —— 会报 `product_not_closed`，但不会阻止分析（真实 CAD 导出件通常水密）。
3. **斜交 T 型交汇可能漏判分叉**（PHASE 90 遗留）：判据依赖切面方向，入流与横向通道明显不垂直时探针可能落空 → 漏判时给"流道到头"，不给错数。对称 T / Y 型稳定。
4. **圆头末端会让倒数第二刀也偏小**（Y 型斜臂 168 vs 沿程 199）—— 保留在序列里，不进 headline。
5. **分支不切分三角形子集**：子段共用父段的三角形集合，交汇处附近的子段截面可能带上交汇体本身（由 §16 第 ④ 条闸门挡住）。
6. **继承 PHASE 85~90 的未决项**（真值套件位置定义裁决、真实件护栏等）。
7. **Android 未真机验收**，本阶段**未发布任何东西**（沿用 PHASE 88 §三十四）。

## 15. 是否建议进入下一阶段

> ### **PASS —— 建议进入下一阶段。**

理由：

1. §22 的成功标准是「给程序一个 Product STL + 一个完整 Gating System STL，它能尽可能自动地找到连接、沿各流道路径采样，并给出可信的 A(s) 横截面积数据」。**这一条达到了**，而且是**在阈值缩小 50 倍后结论不变**的前提下达到的。
