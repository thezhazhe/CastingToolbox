## 1. 目标

系统回答四个问题：
1. 当前采样率是否足够？
2. "局部特征过薄"到底是什么原因（A 采样不足 / B 判定敏感 / C 共同 / D 真实几何 / E 其他）？
3. 真正需要改什么？
4. 改完以后真实 STL 是否更可靠？

原则：实验数据优先于猜测；有证据就修，没有证据不猜；通用机制优先于模型特例；不降阈值屏蔽 warning。

## 2. 当前采样率算法原理（31.txt 二，阅读实际代码后）

**V3 链路**（生产默认，js/engine/v3/sampling.js → adaptiveVs + coarseSample）：

```
模型 bbox（computeBounds）→ mdim = 最长边
   ↓
粗探测（probeResolutionSteps=[16,32,48,64,96,128]，逐级升级到 ≥8 个有效 char 为止）
  每级：scanInside 三方向扫描线判内外 → 体素中心点 → BVH 最近距离
  char = 2×最近表面距离（=局部壁厚粗测）
  过滤 char < 2mm（charFilterMin，MC 网格伪尖峰）
   ↓
estMinWall = char 第 10 百分位（p10），保底 ≥ 4mm（estWallFloor）
   ↓
vs = clamp(0.5×estMinWall, [mdim/128, mdim/24])      ← 最薄处 ≥2 层
   ↓
主网格多级采样：3 级 × 2 相位（半格偏移），minInsidePoints=128，
  maxSampleGs=256（硬上限）→ 内部点 + BVH 距离 → char/dists
   ↓
WARNING 判定（v3ViewAdapter.samplingWarn，PHASE 17 四级）：
  🔴 failed        = V3 明确失败（NO_INSIDE_POINTS/INVALID_MESH）
  🟠 resolution    = 主体壁厚（bodyWallOf）/vs < 2 或 vs > wallMax
  🟡 local_thin    = estMinWall/vs < 2（主体正常但"局部特征"欠采样）
  🟢 ok            = 其余
```

**V2 链路**（几何分析/诊断用）：48³ 默认 → minDim 薄壁触发升级 → ×2 多级到 256，停判据 内部点≥8 且 p95 壁厚≥1 层。

关键关系：模型尺寸 → vs 上限（mdim/128）；壁厚（char p10）→ 目标 vs（0.5×p10）；局部细化（refineSample）→ 峰 ±R 区域加密（refineMaxPoints=8000 上限）。

**关键发现：**
1. **提高分辨率不改善热结结果**：192→256→384 热结数量/位置持续漂移（1→3→4、3→3→0），
   且 256 与 384 多数情况结果相同或更差。根因：`refineMaxPoints=8000` 上限使细化 stride
   随网格分辨率增长（256³ 时细化 stride 4-6），区域提取退化 → 区域收缩 → 置信度下降。
   生产自动档（gs 96-128）恰好在稳定区间。**结论：默认采样率不宜提高**。
2. **charP10 跨分辨率稳定（2.2-5.0）**——"薄"信号不随分辨率变化，但**该信号对所有模型
   恒低**（包括 48mm 主体模型），因为它不是薄特征测量。
3. 计算时间：256³ ≈ 3.7-6.2s、384³ ≈ 7.6-13.1s（对比生产 1.6-2.8s）——384³ 收益为负。

## 9-11. 根因分析（31.txt 六 A-E 分类）

**根因 = 两种机制共同（C 类），但都不是"主采样率不足"：**

**根因①（"局部特征过薄"误报）——判定逻辑使用了错误统计量：**
`estMinWall = char p10`（最近表面距离的低分位）是**表面密度统计**，不是薄特征测量：
- 任何实体的距离场低分位恒 ≈2-4mm（表面壳层占体积 25-40%），与真实最薄特征无关
- estMinWall 被 estWallFloor=4mm 保底夹住、vs 被 mdim/128 上限夹住 → estLayers=4/2.7=1.5<2
  → 10/30 模具结构性误报（HR4012 大板家族 6 个 + ALHR45xx 系列——全部无真实薄材料）
- 误报模型的"约 4mm 薄特征"在空间上不存在（t 测度证明，见下）

**根因②（部分"采样率不足"误报）——bodyWallOf 的 wallAvg 兜底：**
主体壁厚估计不可信时回退 wallAvg——薄材料多的模具（浇道/滑块）wallAvg 被拉低
（ALHR4520A v3：wallMain=27.1、wallAvg=10 → 判"主体 5.8mm <2 层"→ resolution 误报），
而采样点级的中位局部厚度 tP50=15.1mm 证明主体远非过薄。

**排除项：**
- 主采样率不足（A）：30 模型内部点充足；192/256/384 提升无收益（§7）
- 距离场/BVH/法线底层错误（D）：t 测度（同一 BVH 原语）与几何一致（厚板 t≈48、薄板 t≈3）
- 真实薄壁模型的 warning 是**正确**的（ALR2510 0.62、滑块x3 0.37——t 测度保持警告）

## 12. 修复内容（31.txt 九/十）

**通用机制，非打补丁：以"局部完整厚度" t = d + d2 取代 p10 判定。**

- `localThicknessStats`（sampling.js，纯函数）：每采样点 t = 最近表面距离 d（已有）
  + 沿局部法线到远侧表面距离 d2（BVH 射线，PHASE 22 中面修正同一几何原语）
  → 48mm 厚板表面点的 t≈48（旧 char=2mm 误判）；4mm 肋的 t≈4。t 分布与表面壳层解耦。
- `thinFrac = P(t < 2×vs)`——真实低于 2 层采样下限的材料占比
- **新触发（v3ViewAdapter.samplingWarn）**：
  - 🟡 local_thin：`thinFrac ≥ thinFractionMin(0.10)`（旧 estMinWall/vs<2 废弃）
  - 🟠 resolution：主体层数用 `max(bodyWallOf, tP50)`，**但 tP50 仅在物理一致时可用**
    （≤2×wallMax——2m 壳 5mm 壁的断网格伪采样 tP50=795 vs wallMax=50.8，超界即退回
    geometry 链，P18-T3 回归锁定），修 wallAvg 兜底误报同时不破坏真超薄语义
  - 消息改为诚实文案："约 X% 的材料局部厚度小于 Ymm（低于 2 层采样下限，最薄约 Zmm）"
- 阈值依据（30 真实 STL 实测）：误报家族 thinFrac 全部 0.000~0.011；真薄壁 ALR2510 0.618 /
  滑块x3 0.375；边界 ALHR4520A v3 0.090 → **0.10 留 10× 余量**（configV3.thinFractionMin 注释留档）

**不修改**：vs 选择（p10 驱动的采样公式是 30/30 验证过的，PHASE 22 已证明主体壁厚驱动会破坏
ALHR4510）；estWallFloor/charFilterMin（它们是采样保底，不是判定阈值）；热结计算链路零改动。

## 20. 最终生产采样率建议

**维持现状（不提高默认采样率）**。证据：
1. 192/256/384 强制实验：结果不稳定且不随分辨率单调改善（ALHR4520A 384³ 全灭、ALHR4530 v1
   1→3→4 漂移），根因是 refineMaxPoints 上限下的细化 stride 退化——生产自动档（gs 96-128）
   恰在稳定区间
2. 提高默认采样率只增加 2-4× 时间（256³ 3.7-6.2s、384³ 7.6-13.1s vs 生产 1.6-2.8s），
   收益为负
3. 生产 vs 已被 mdim/128 上限约束（350mm 模具 → vs≥2.7mm），对 20mm 级主体 7+ 层、对
   5mm 级特征 2 层——满足"主要壁厚 ≥3-5 层"目标（30.txt 十）

## 21. 是否需要局部高精度复核（31.txt 八）

**不需要新增**。现有 refineSample 局部细化（峰 ±R 区域、vs 同量级或更细）已承担复核角色；
实验未发现"全局 ok 但个别区域需要局部复核"的缺失——warning 误报的根因是判定统计量，
不是复核不足。

## 22. 剩余风险

1. **滑块x3/ALR2510 类真薄壁模型的 warning 保留但分辨率不提高**——其热结结果在低 vs 下
   仍可能不完整（滑块x3 生产 0 热结）。如需处理属新 PHASE（薄壁模型的可靠性策略），
   不属本次误报修复范围
2. **热结结果跨分辨率稳定性**（§7 实验发现的漂移）是独立问题：细化 stride 随网格分辨率
   退化（refineMaxPoints 上限）。生产档不受影响，但若未来提高默认分辨率需一并解决
3. **t 测度阈值 0.10 按当前 30 个真实 STL 校准**——新模型家族若出现薄材料占比 5-10% 的
   中间态（ALHR4520A v3 0.090 属此类，当前不警告），需在真实使用中复核
4. 探测 p10（estMinWall）仍用于 vs 选择——它对"最薄特征≥2 层"是保守正确的，但其值受
   保底夹住（4mm）——若未来模型最薄特征 <4mm，vs 会停在 mdim/128 上限而非更细（上限
   保护优先）

## 23. 下一步建议

1. 收集用户端出现 warning 的真实 STL，用 t 测度复核（`scripts/p23_resolution_experiment.mjs`
   与 `tests/real-stl/_p23_warn_new.mjs` 可复用）
2. 若热结跨分辨率稳定性成为用户痛点，独立立项：细化 stride 自适应（refineMaxPoints 上限
   改为按区域尺寸动态分配）
3. 真薄壁模型（滑块x3/ALR2510）的"薄壁可靠性策略"：薄壁件本身热结意义有限，可研究
   明确提示"薄壁件热结分析参考价值有限"而非强行出结果

## 24. 结论

- **当前采样率足够**：不提高默认值（实验证据）
- **"局部特征过薄"根因 = 判定逻辑统计量错误**（p10 表面密度 ≠ 薄特征；estWallFloor/vs
  上限夹住触发），非主采样不足、非底层距离场错误、非真实几何（对正常模具）
- **修复 = 局部完整厚度 t 测度**（通用机制，30 模型 10× 判别余量），warning 16→2，
  真薄壁保持警告，热结计算零改动，全量回归通过
