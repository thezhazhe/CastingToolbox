### 其他条文确认（任务书 §三.4~7）

- **±half**：ISO 2007/2023 原文"默认对称分布，即正值一半/负值一半"→ ± = 总公差/2，保持现实现（VERIFIED）。
- **壁厚等级**：现行版机制 = 壁厚粗一级（DCTG1~15 壁厚按粗一级）+ 专用级 DCTG15wt（仅用于整体按 DCTG15 标注铸件的壁厚；数值=原 DCTG16 列）。代码 wallGrade = 一般级 +1、CT15 壁厚 → CT16 列（=15wt 列同值）、≤16mm 段无值 → 与现行机制一致，保持（VERIFIED）。
- **≤16mm 规则**（CT13~16 无表值）：1999 表注确认；现行版条文未独立确认 → 保留功能 + UI 明标"源自 1999 版表注，详见法规区"，**不写"现行标准明确规定"**（UNCERTAIN，如实）。
- **推荐等级表**（方法×材质）：保持"工程推荐口径"，不声称现行标准强制（61 已改，62 未动）。
- metadata 升级（任务书模板）：数据层/UI/registry/知识卡统一写"数据依据 ISO 8062-3:2023 Table 7（经独立公开资料交叉核验）"，**未声称"已直接核对 GB/T 42124.3-2025 官方全文"**。

### ×50% 特别核验（任务书 §四.3）→ 结论：代码方向正确，条件口径已在 UI 对准

标准条文（1991 第 4 章/2022 第 5 章，多源引述一致）：**自硬砂造型时，模样凹处内表面的起模斜度值"允许"按表3 所列数值再增加 50% 选取；凹处过深时可用活块或砂芯形成。**

| 核查点 | 标准实际 | 代码现状 | 判定 |
|---|---|---|---|
| 对象 | 仅"模样凹处内表面" | 工具输出行"内壁"——用户选内壁即对应凹处内表面；UI 行名已改「凹处内表面」 | 语义对准（本 Phase 改文案） |
| 基数 | 表3（自硬砂外表面） | 自硬砂分支 = DRAFT_SELF_OUTER ×1.5 | 一致 |
| 性质 | "允许…增加 50%"(上限授权) | 按上限取值作推荐（斜度宁大勿小，卡砂即废件） | 方向正确（UI 注明"允许上限，工具按上限取值"） |
| 黏土砂凹处 | **不走 50% 规则，查独立表2**（≈表1 的 1.7~2.0 倍，非 1.5 倍） | 黏土砂分支用独立 DRAFT_INNER（表2 值） | 一致 |
| 边界 | 凹处过深用活块/砂芯；加大不超表值一倍；机压 >700kPa 可再增（旧版上限 50%） | UI 说明区补齐（本 Phase） | 补充披露 |
| 木模 >1000mm | 1991 另有 >1000~2500 续档（0°20′/0°15′/0°15′） | 工具止于 1000、outOfRange 提示区分材料 | 未建档（2022 未核，按 LEVEL D 不猜不改），UI 披露"木模旧版另有续档、2022 修订未核" |

### JB 结论（任务书 §四.4/5/6 综合）

- 数值符合"多个独立可靠来源一致 + 无冲突 + 替代关系确认 + 未见新版修改该数据证据（2022 前言无数值修订条目）"→ **允许作为生产数据继续使用**；
