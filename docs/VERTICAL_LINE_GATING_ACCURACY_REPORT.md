## 1. 这是什么

一个**垂直造型线（竖型串）小件浇注系统**速算工具，实现三种浇注系统（加压式/减压式/混合式）的分层浇注系统设计：

- 输入：浇注系统、材料、单件重量、最薄壁厚、浇注时间依据（设备节拍或产品质量二选一）、内浇口引入方式（顶入/中入/底入）+ 每层 A（液面到内浇口距离）(+ C/B)、内浇口厚度（自动推荐可改）
- 输出：浇注时间 → 各层内浇口截面积与尺寸 → 垂直流道/层横浇道各段截面积与标准选型 → 铁水总重；配套布置示意图与位置标注图

## 2. 方法来源（不自行发明公式）

全部公式、系数、算例来自 **DISA 230 Application Manual（2003）第 6.8~6.12 节**（浇注系统原理/公式/四种系统计算），实现为"方法数字化"：

- 核心公式：`F = k·G/(m·t·√H)`，k = 铁 1036 / 铝 3100 / 铜 850（=1/(ρ√2g) 推导一致，≤0.1%）
- 静压头 H：顶入 H=A；中入 H=A−B/2；底入 H=A−C/2（A/C/B 定义已经工艺复核）
- 浇注时间：双标准取小——循环标准（3600/型数−3s，设备模式）与浇注不满标准 t=B√G（产品质量模式）
- 手册未明示或自相矛盾处：**全部如实披露（U1~U7 清单），不猜测、不悄悄修正**

## 3. 数据准确性证据（核心）

| 项目 | 手册值 | 程序值 | 误差 |

> 注：表中为 t=4s 对照；界面默认按手册双标准自动推荐 t=4.2s（可改），数字同源同公式。

### 3.2 独立数学验证（不依赖手册例）

- **质量守恒反推**：ρ·F·V = G/t 在每层成立（误差 <0.02%）
- 重量变 2×/0.5× → 面积线性；时间变 2×/0.5× → 面积反比；改单层 H → 仅该层变化
- k 常数与手册密度 ρ、g=9810 的推导关系逐一核对
- 极限输入（0.01~200kg、H=1~100000mm、1~8 层）无 NaN/除零/负值

### 3.3 界面改动验证

引入方式（顶/中/底）与 C/B 改动后：结果表、结果头、布置示意图三者数值**同步联动**（例：A=135、C=100 → H=85 → 单口 37.5mm²，手算一致）；门禁覆盖空值/0/负数/几何不成立。

## 5. 已知限制（如实列出，均已在界面"UNRESOLVED"清单披露）

1. **不加压式**已从界面移除（手册自身评价最差），引擎保留供研究；该方式手册文字与算例存在矛盾（两倍 vs 1.42）且含布置相关步骤，未达可用级——故不提供给用户。
2. 材料支持：灰铁/球铁/铝/铜。球铁手册无独立 k，按用户裁决沿用灰铁参数（限速取手册球铁 600mm/s）；铸钢等无手册系数暂不支持。
3. 手册自身矛盾 7 处（含：加压例"172 vs 192"面积标注、口长取整规则不一致等）全部记录在案并取保守/安全侧。
4. A（液面到内浇口距离）需用户按实际型板布置填写；C/B 按"产品+冒口"高度填写（同型各层一致）。
5. 结果属性：面积等为**计算值**；流道标准选型与口长度取整属**工程建议**（安全侧）。首次应用建议以一次浇注试验复核。
