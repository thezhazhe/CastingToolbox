### 3.3 冒口 / 浇注分模块 + 草稿与保存（D5/D6）—— 本轮语义变化最大处

- `#dc_params` 内分 **基础 / 冒口 / 浇注** 三个模块面板，**三个面板同时留在 DOM**，只用 `[hidden]` 切换。
  理由：① 切模块不丢输入与光标；② `#dc_params` 的 textContent 仍同时含 ①②③ 分组标题（既有断言依赖）。
- **草稿层**：`state.draft = { riser:{}, gating:{} }`；`DRAFT_MODULE` 映射 8 个参数
  （`hsPick` / `mcHotspot` / `wallHot` / `pourPos` / `Ho` / `ph` / `riserHeight` / `ratioKey`）。
- **真实保存**（不是空按钮）：`saveModule()` 是唯一把草稿写进 `CastingProject` 的入口，
  逐项 `proj.set()` → 落 localStorage → `markStale()` → 已有结果时走既有 600ms 防抖重算。
  `process.hsPick` 保留原 `USER_INPUT / USER_CONFIRMED` 来源语义，其余字段走 `proj.set` 既有规则
  （改自动值 → `USER_OVERRIDE` 并保留 `orig` 供 ↺ 恢复）。
- **基础模块保持即时写入**：材料/几何/STL 自动值是全局共享参数，且材料切换必须立刻联动密度与重量
  （既有行为，多处断言依赖）。这与 142 §四 D5「冒口参数 / 浇注系统参数」的界定一致。
- **未保存提示**（D6.1/D6.5/D6.6）：模块页签打 `●`、面板内 `● 未保存`、顶部常驻提示条
  「有未保存的参数修改：下方结果仍按『已保存』的参数显示」。
- **切换模块保留草稿**（D6.8，已实测）；**放弃修改**回到已保存值；**分析只使用已保存参数**。
