## 2. 核心公式

### 2.1 内浇口/截面速度（手册公式 2，p6.63）
```
V = m·√(2·g·H)          V [mm/s]，m = 损失因数（0~1），H [mm]
g = 9810 mm/s²（手册 6.9.2.2，p6.63）
```

### 2.2 截面面积（手册公式 8 程序化，p6.67-69）
```
F = k·G / (m·t·√H)       F [mm²]，G [kg]，t [s]，H [mm]
```
| 材料 | k | 手册 ρ [kg/mm³] | 推导关系 | 出处 |
|---|---|---|---|---|
| 铁（灰铸铁） | **1036** | 6.89×10⁻⁶ | k=1/(ρ·√(2g)) = 1036.2 | p6.69 |
| 铜合金 | **850** | 8.40×10⁻⁶ | = 850.0 | p6.69 |
| 铝合金 | **3100** | 2.30×10⁻⁶ | = 3103.9（手册取 3100，差 0.1%） | p6.69 |

> **范围**：手册仅提供铁/铜/铝三套系数。球墨铸铁/钢等**无手册 k 常数，本模块不支持**（UNRESOLVED-U1，宁缺毋猜）。

### 2.3 平均有效静压头 H（手册 6.9.2.3，公式 3/4，p6.65-67）
| 浇口位置 | 平均有效静压头 | 符号 |
|---|---|---|
| 顶部内浇口 | H = a（浇口杯液面→口的距离） | a |
| 底部内浇口 | H = a − c/2（c = 铸件高度） | a−c/2 |
| 侧面内浇口 | H = a − b/2（b = 口到铸件顶部高度） | a−b/2 |

**V1 输入约定**：本计算器直接输入每层"平均有效静压头 H（mm）"——按上式由型板布置换算（顶部层=a；底层=a−铸件高/2；中间层=a−口到铸件顶/2）。手册算例：三层 H=385/260/135 mm（p6.127）。

### 2.4 浇注时间（手册 6.9.2.7 + 6.11.3.1 流程，p6.71/6.125-127）
```
标准1 循环时间：tmax1 = 3600/造型速度 − 1.5（输送）− 1.5（浇注系统填充）   [s]
标准2 浇注不满：tmax2 = B·√Gc                                        [s]
推荐 t = min(tmax1, tmax2)（可改；手册例 4.2 → 取整 4 s 留余量）
总浇注时间 t0 = t + 1.5 s
```
B 因数表（Gc=单件重 kg；轻金属 ×1.5~2.0，V1 取 1.5）：

| 最薄壁厚 | Gc ≤ 1 kg | Gc ≥ 4 kg |
|---|---|---|
| 3–5 mm | 3 | 1.5 |
| 5–10 mm | 4 | 2.0 |
| 10–20 mm | 5 | 2.5 |
| >20 mm | 6 | 3.0 |

> 1 < Gc < 4 kg 区间手册未给插值 → **UNRESOLVED-U2**：V1 线性插值并在 UI 标注"非手册直接给出"。

### 2.5 损失因数 m（手册 6.11.3.1 / 6.11.4.1 取用值）
- 内浇口（窄流道）：**m = 0.5**
- 较宽流道：**m = 0.7**（手册明示"宽流道损失比窄内浇口小"）
- 图 6.38（p6.64）分散值 0.3/0.5/0.6 与形状对应关系无法逐格还原 → UNRESOLVED-U3

## 3. 四种浇注系统的计算流程（手册 6.11）

通用输入：每层件数 n_i（对称布置，例 2）、每层 H_i、单件重 Gc、t、s（口厚）、m。
型内铸件总数 = 每面 Σn_i × **2 面**（手册例 12 件 = 2×6，p6.129 浇口杯校核自洽）。

### 3.1 加压式（6.11.3）——节流 = 内浇口
- 各层**独立**计算单口面积：`F_i = k·Gc/(m_i·t·√H_i)`（例：31.2/22.5/18.5 mm²）
- 层总面积 = n_i × F_i；垂直流道 `F_v ≥ (1+15%)·Σ 层总面积`（每 90° 转弯另 +10~20%，6.8.1）
- 建议尺寸：厚 s × 长 l = ⌈F_i/s⌉（0.5 mm 网格，实际 ≥ F_i）
- 内浇口速度 V_i = m_i·√(2gH_i) 与 6.9.2.11 材料限速表对比 → 超限警告（加压竖排底部口速偏高为表 3 固有取舍）

### 3.2 减压式（6.11.4）——节流 = 通向减压段的截面
- 垂直流道按加压式**逐段**计算（m=0.7）：段 G = 该段供液下游全部铸件重
  （例：底部段 2 件→26.4；中段 4 件→64.3；顶段 6 件→133.8 mm²；自洽验证 ✓）
- 最小垂直流道 4/8×8 = 48 mm²（"不建议小于"，6.11.4.1）
- 底段流速 V1 = m·√(2gH底)；进腔前限 **1 m/s** → 层横浇道（每层两侧）与内浇口：
  `≥ ½·F1_std × (V1/1.0)`（例：½×48×1.9=45.6 → F8=5/10×10=75；内浇口 16×3）
- **内浇口全部层同尺寸**（手册明示：各型腔同时浇注，6.11.4.6）；水平流道最小 5/10×10=75

### 3.3 不加压式（6.11.5）——节流 = 上部水平流道
- 上部水平流道按全部铸件流量、m=0.7、保守小头（手册做法取 H≈40mm 级）计算
- 垂直流道 = 上横流道 × **1.42**（**手册算例比例**；手册文字"两倍"与之不符 → U4，按算例实现）
- 总内浇口面积 = F_v×1.2，全部层/腔**同尺寸**（例：468.75×1.2/6 = 93.75 → 31×3）
- 手册另按"实际/平均头比"（192.5/135）放大上横流道——布置相关，V1 未实现 → U7（差异见验证报告）

### 3.4 混合式（6.11.6）
- 浇口杯/上部水平流道/垂直流道/浇口窝/中间与下部流道 = **减压式**计算
- 内浇口 = **加压式**逐层计算（例：10.5×3 / 7.5×3 / 6×3，同加压 F1~F3）

### 3.5 浇口杯校核（6.11.3.4 等）
```
平均浇注速度 w = (型内铸件总重 ÷ 产出率)/t0   [kg/s]   （例：0.7×12/0.7 ÷ 5.5 = 2.2 → 3 号杯）
```

## 4. 几何与取型规则

### 4.1 标准梯形流道（手册图 6.49，p6.90）
- 简单梯形（垂直流道/水平流道）：标注 a/2a×2a，**F = 3a²**
- 细长/高梯形（上部水平流道）：约 **F = 6a²**
- V1 取型：a = 0.5 mm 网格向上取整，使 3a² ≥ 所需面积
  → 复现验证：133.8→a7(147)、230.9→a9(243)、322.5→a10.5(330.75)、300→a10 与手册选型全部一致

### 4.2 内浇口尺寸（手册 6.10.12，p6.111）
- 厚度 s = 铸件模数 Mc 的 25%~100%（**s < 1 mm 不可用**；手册例 Mc=0.67cm → 取 s=3mm）
- 长度 l = ⌈F/s⌉（0.5 mm 网格向上，工程安全侧；例 31.2/3 → 10.5）

## 7. 计算/推荐边界（Calculation vs Recommendation）

- **Calculation（手册公式直接结果）**：浇注时间、各层内浇口面积、垂直流道各段所需面积、内浇口速度、浇口杯平均浇注速度。
- **Recommendation（工程建议层，UI 已标注）**：流道标准梯形选型（a 取型）、内浇口长度网格取整、加压上部水平流道参考（a≈1.25×F4，手册例，布置相关）、浇口杯号（按手册图 6.46/6.47 选择额定 ≥ w 的杯号；手册例 2.2 kg/s → 3 号）。

> 手册自身还含"顶部连接段 F4（78 mm 处）"与"上横流道取保守头 40 mm + 实际/平均头比放大"两步布置相关计算，V1 未实现（U7）；首次应用请以浇注试验复核全部尺寸。
