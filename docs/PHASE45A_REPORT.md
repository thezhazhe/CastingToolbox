# PHASE 45-A 报告：Gating 输入可理解性 + 过滤网 UX（46.txt）

## 一、修改内容

**P0 —— 输入可理解性**
- 新增 `js/views/gatingDiagram.js`（纯函数 SVG 模块）：顶注/中注/底注三张浇注方向工程示意图
  - 每图含：上箱面/下箱面/铸件（ph）/冒口（rh）/内浇道/浇口杯/浇注方向
  - 尺寸线：Ho（内浇道→上箱面，两端基准短线+箭头）、rh（铸件顶→冒口顶）、ph（铸件底→铸件顶）、C=ph+rh
  - P 为计算值辅助标注（顶 P=0 / 中 P=C/2 / 底 P=C），不绘制物理尺寸线（原因见下"工程定义核对"）
  - 底部三行输入说明（Ho/ph/rh 测量基准）；无 3D 写实、无多余结构
- gatingView：浇注方向下拉下方随切换显示对应图；点击图放大（简单 overlay）；Ho/ph/rh 输入行加测量基准提示文字

**P1 —— 过滤网工艺条件 UX**
- 删除"型号下拉"（用户不再预选型号）；改为计算前单选：`不使用 / 使用`（唯一用户选择）
- 单选旁 ⓘ + 动态提示文案（结合材质/铸件质量要求/企业工艺规范，非绝对规则）
- **fv 企业规则"有过滤网 −0.1"实施**（工艺设计说明书 V3.2.2 参数运算表原文）：顶 0.8→0.7 / 中 0.6→0.5 / 底 0.45→0.35
  - 单点定义：`calcs/gating.js` runGating 内 `fv = filterUsed ? fvBase−0.1 : fvBase`，唯一消费处，无重复扣减
- 计算完成后自动推荐：`calcs/filter.js` 新增 `rankFilters(G, family)`
  - 筛选规则：先满足企业过流量（capacity ≥ G）→ 按 capacity 升序（越接近需求越优先，非"越大越好"）→ 型号顺序兜底
  - 推荐显示：🥇 推荐 / 🥈 可选 / 🥉 可选（允许过流量/本次需求/余量），更多规格提示
  - 无满足型号：如实显示"暂无满足当前计算条件的过滤网规格"+ 需求 vs 最大可用（不伪造推荐）
  - 铸钢/铝/铜（无企业标准）：明确提示无法推荐
- 结果区新增「本次计算条件」块：材质 / 浇注方向 / 浇注系统类型 / 过滤网使用与否 / 最终 fv（含 −0.1 说明）
