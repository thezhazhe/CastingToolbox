## 一、总体流程

```
输入（材料/单件毛重/一模件数/产品壁厚/出品率/浇注方向/Ho/ph/rh/比例/过滤网/内浇口形状·个数·厚度/横浇道条数·厚度/排气形式）
  → W_c=单件×件数（P47 时间公式 W）｜G=W_c÷出品率（浇注重量）
  → 浇注时间 t（材料分派公式）→ Hb → Hp → fv
  → 奥赞阻流面积 A → 三段参考面积（A_sp/A_run/A_gt 按比例）
  → 目标速度机制（A_target/A_rec；默认几何按 A_gt，P50 按钮后按 A_rec）
  → 内浇口几何（方形 L 或圆形 D，ceil 取整）→ Fg
  → 横浇道/直浇道几何 → 排气自动生成 → 流速/排气校核 → 综合判定
```

## 三、材料与查表数据（内部常量）

**材料表（ρ=液态密度 kg/dm³，fc 仅铝/铜 Dietert 用，yr 建议）**

| 材料 | ρ | fc | yr_sug | yr 区间 |
|---|---|---|---|---|
| 灰铁 | 7.0 | 1.00 | 75 | 65~85 |
| 球铁 | 6.9 | 0.85 | 65 | 55~75 |
| 铸钢 | 7.5 | 0.80 | 58 | 50~65 |
| 铝 | 2.6 | 1.20 | 80 | 70~90 |
| 铜 | 8.4 | 0.90 | 62 | 55~70 |

**目标速度 V_TARGET（工程设计目标，P48-B/P50）**：灰铁 t=1.00（仅上限）；球铁/铝 t=0.45、区间 0.40~0.50；铸钢/铜无目标。
**R7 审核红线 V_LIMIT**：封闭式 ≤1.5、开放式 ≤1.0 m/s（企业无缺陷工艺审核，提示性质非错误）。
**Hb 水口盆高度表（按浇注重量 G kg）**：<10→150、<50→200、<200→250、<1000→300、<3000→500、<8000→750、≥8000→1100 mm（D3 决定暂保持原表）。
**比例预设**：封闭式保守 1:1.5:0.8 / 常用 1:2:0.85 / 大件 1:2.5:0.9；开放式标准 1:2:2 / 宽大 1:2.5:2.5 / 铝 1:3:3（面积比；min 比值处=阻流）。
**fv 速度系数**：顶 0.8 / 中 0.6 / 底 0.45（企业参数运算表）；使用过滤网 −0.1。
**瓷管规格**：F25~F70（内径 22/32/37/47/57/67mm）。

## 四、计算链与公式

**1) 重量定义（P49 分离）**
```
W_c (castingMass) = pw × cav                    ← 浇注时间公式的 W
G  (pouringMetalMass) = W_c ÷ (yr/100)          ← 奥赞/流量/目标面积全部下游
```

**2) 浇注时间 t（P47，唯一入口 calc_t(mat, W_c, wall)，单位 s）**

| 材料 | 公式 |
|---|---|
| 灰铁 | W_c≤450kg：t = 0.70·(1.41 + wall/14.59)·√W_c<br>W_c>450kg：t = 0.70·(1.236 + wall/16.65)·∛W_c |
| 球铁 | t = K₁·√W_c；K₁ 分档：wall<10→2.080 / 10≤wall≤25→2.670 / wall>25→2.970（硬分档不插值） |
| 铸钢 | t = (2.4335 − 0.3953·log₁₀W_c)·√W_c（不依赖壁厚） |
| 铝/铜 | t = fc·(√W_c + ∛(wall·W_c/5))·2/3（原 Dietert 模型，保持） |

边界提示（不插值）：灰铁 W_c 在 450±5%、球铁 wall 在 10/25±1mm → 输出"接近公式分界点，请工程复核"。

**3) 平均静压头 Hp（mm，企业口径）**
```
C = ph + rh；P 值：顶注 0 / 中注 C/2 / 底注 C；Hb 查表（按 G）
顶注: Hp = Ho + Hb/2 − rh²/(2C)
中注: Hp = Ho + Hb/2 − (P + rh)²/(2C)      （企业 Excel 原式，28.3-B 方案 A）
底注: Hp = Ho + Hb/2 − Ho/2
```

**4) 阻流面积 A（奥赞，mm²）= 企业 Excel 22.6 式（mm 口径 71.47 = 22.6×√10）**
```
A = 71.47·G / (ρ·t·fv·√Hp) × 100
```

**5) 三段参考面积与阻流位置**：min=min(S直,S横,S内)；A_sp=A·S直/min；A_run=A·S横/min；A_gt=A·S内/min；瓶颈 cp=min 比值对应段（封闭式=内浇口）。

**6) 目标速度机制（P48-B 计算 + P50 交互）**
```
v_theory = fv·√(2g·Hp/1000)           内部诊断值（阻流处理论流速，不参与判定）
A_target = vTarget ? 1000·G/(ρ·t·vTarget) : 0      Q=v_target 反算
A_rec = max(A_gt, A_target)            只放大不缩小（公式层）
几何基准 geoArea = optimized ? A_rec : A_gt
   optimized=false（默认，P50）：几何按 A_gt → v_gate 超目标 → high 提示 + 按钮
   optimized=true（用户点击后）：几何按 A_rec → v_gate ≤ 目标
```

**7) 几何生成（用户 gc/形状/gt 不变，ceil 宁大勿小，实际面积≥目标）**
```
方形: L_g = max(5, ceil(A/(gc·gt)/5)·5) mm；Fg = gt·L_g·gc
圆形: D_g = max(3, ceil(√(4A/(gc·π)))) mm；Fg = gc·π·D_g²/4
横浇道: L_r = max(10, round(A_run/(rc·rt)/5)·5)；Fr_act = rt·L_r·rc
直浇道（1 根圆）: D_sp = max(5, round(√(4A_sp/π)))；Fs_act = πD_sp²/4
实际比例: rrv=Fr_act/Fs_act；rgv=Fg/Fs_act
```

**8) 流速与状态**
```
v (=vFinal) = Fg>0 ? 1000·G/(ρ·t·Fg) : 0     m/s（名义平均内浇口流速，=Q/Fg）
vState: rec 推荐 / high 偏高（>hi）/ low 偏低（<lo，不缩小）/ none 无目标
r7Exceed = v > V_LIMIT[type]                 仅提示（informational）
v_ok = vState!=='high'（兼容字段）
vL（液面上升速度，参考）= ph/t  mm/s
```

**9) 排气（自动生成，用户不填；企业 R7：1.5S阻 < S出气 < 4S阻）**
```
圆孔: d 从 3mm 起，数量>40 逐级升 4→5mm；vt = n·πd²/4
方片: 厚 t=min(3,壁厚)mm，宽 50mm；vt = n·50·t
vr = vt/Fs_act；vr_ok = 1.5 ≤ vr ≤ 4
```

**10) 综合判定**：allOk = vr_ok && vState!=='high'。
显示三态：✅ 合格 / 红色"需优化"（存在 ❌ 硬性问题，如排气不足）/ 橙色"设计可用·可选优化"（仅建议项）。

**11) 实际出品率**：ya = pw·cav/G×100（=设定 yr 的反算展示）。

**综合判定区**：三态判定 + 建议列表（sugs：偏高引导按钮/偏低可保留/超 R7 仅提示/自动放大说明/排气问题/尺寸提醒）+ [⚡ 按目标速度优化] 居中按钮（high 时）+ 优化后绿条（面积与速度变化，注明阻流/直浇道/横浇道/时间未变）。

## 六、交互特性（为何用户看到这些行为）

1. **出品率联动**：切材质自动填该材质建议 yr（用户手改后不再覆盖）。
2. **过滤网**：选"使用"→ fv−0.1 → A 全链增大；型号自动推荐（企业规格表按过流量，接近需求优先；无满足如实提示）。
3. **内浇口圆形**：自动反推直径 + 瓷管建议（规格固定，仅建议）。
4. **排气自动生成**：用户只选形式，面积由程序按 1.5×S直 生成并显示（企业 1.5~4 区间校核）。
5. **按目标速度优化（P50）**：仅"偏高"时出现；放大≥1.5×（界面提示阈值）先确认；执行后只变内浇口（数量/形状/厚度、choke/直浇道/横浇道/t/G/Q 全部不变）。
6. **v_theory 仅为诊断值**：不参与判定、不被 v_final 覆盖。

## 七、口径与边界声明（排查注意点）

1. **v 是"名义平均内浇口流速"**（全周期平均 = Q/Fg），非局部/瞬时速度；与 Campbell 临界速度（Fe 0.45/Al 0.50 m/s，内浇口出口液面行为）只能间接参考——平均≤临界保守安全，平均>临界仅提示复核。
2. **目标速度表**：球铁/铝 0.45 有材料临界值量级支持；灰铁 1.0 为工程经验目标（无文献数值依据）；铸钢/铜未设目标。
3. **放大后阻流位置可能迁移**：A_rec 超过直浇道参考面积时，系统最小截面不再是内浇口（一阶名义流量不变假设的前提变化），UI 未标注新最小截面位置。
4. **灰铁 450kg / 球铁 10·25mm 存在教材固有跳变**（已加工程复核提示，不插值）。
5. **Hb 低档表（<200kg 用 150/200/250mm）**与企业表（<1000kg 统一 300mm）不同，暂按决定保留（D3 待办）。
6. **G 为估算法**（pw×cav/出品率），企业为实物构成法（+浇道重+冒口重），差约 4% 量级。
7. 修正历史：P47 时间公式（材料分派）、P49 W 分离与取整 ceil、P50 优化按钮——均已按上述代码实现并通过 109/0 回归。
