### 5.2 ★ 几何 / 网格（PHASE 94 新增的坑）

7. **程序生成的测试件网格都不干净**：四面体 MC 在**网格点恰好落在等值面上**（`sdf == 0`）时
   会产出零面积三角形；它们被 `meshComponents` 的退化过滤剔除后，**邻居就丢了一条边**
   → 组件被判成"不闭合"。
   **这是夹具问题不是产品问题**（产品遇到不闭合本来就该拒绝给面积）。
   绕法：把包络整体平移一个小量（PHASE 94 用 `0.0173mm`），或调 `PAD`。
   实测同一组 3 个圆台：`pad=6/res=96 → closed=true,true,false`；`pad=10/res=96 → 三个全闭合`。
8. **MC 是内接多面体** → 表面积 A **系统性偏小**、且比 V 偏小更多 → **M=V/A 系统性偏大 0.5~1%**。
   断言应该判**偏差的方向**，而不是给一个宽容差。
9. **`principalAxis` 的 `|det|` bug 已修**（PHASE 94）。写几何代码时记住这条：
   **散度定理那套四面体求矩只有带符号体积才成立**；原点在实体外面时 `|det|` 会把主轴算错。
10. **`sliceArea` 的 `withPoly` 是 opt-in** —— 默认连 `repLoops` 这个键都不建。
    调用方没开就**别指望有形状数据**。

### 5.3 ★ 前端 / CSS

11. **`[hidden]` 会被 CSS 盖掉**：浏览器默认的 `[hidden]{display:none}` 是**元素选择器权重**，
    `.card.section-card` 之类的类选择器权重更高 → 元素照样显示。
    **本项目里凡是用 `hidden` 控制显隐的自定义区块，CSS 都要显式写一条 `[xxx][hidden]{display:none}`**。
    而且**断言查内容查不出这类问题**（内容在不在 ≠ 显不显示）—— 要按 `getComputedStyle` 核验。
12. **CDP `Page.captureScreenshot`**：
    - `clip` 用的是**页面坐标**不是视口坐标，滚动后要加回 `scrollY`；
    - **不要用 `captureBeyondViewport`** —— 会让 `position:fixed` 的侧栏/顶栏跑到页面中间（假象）；
    - 正确做法：把视口拉高到内容高度再普通截图。但**拍移动端不要这么干**（`vh` 尺寸会跟着变，
      比例不是真机比例），移动端要用真实视口（390×844）+ 滚动。
13. **CSS 会被浏览器缓存**。改了 `app.css` 后截图没变化 → 先删 `_edge_*` profile 目录再拍。
14. **写测试选择器时别把 class 当成 id**。本窗口在整个 PHASE 94 里踩了三次
    （`#pi_gtotal` / `#pi_gratio` / `#pi_gshare` 其实都是 class），每次的表现都是
    "断言失败但产品是对的"。**先 `querySelector` 确认拿到了再断言。**
