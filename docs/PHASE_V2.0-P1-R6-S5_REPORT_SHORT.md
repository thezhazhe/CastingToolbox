## 五、三项调查的结论

- **保温冒口 40%**：Campbell 书中指同高度圆柱绝热冒口直径 0.63D → 体积约为砂型冒口的 40%；是特定保温套/产品条件下的参考，**必须查制造商数据**，不能写成通用 `×0.4`。
- **冒口颈**：当前已有 `M_neck = Mc × neck_k`、`d_neck = 4 × M_neck`；缺颈长/连接形式。书中的 1.0:1.1:1.2、Sciama 的 0.5D/0.25D 长度限制只能作为未来可选模块依据，不能硬编码。
- **补缩长度**：当前没有可靠模型与输入。Pellini 4.5T、Johnson–Loper 公式仅适用于湿砂低碳钢；Al/Cu 及宽凝固区间合金需极谨慎。现阶段应显示“暂无法可靠估算”，不能用热点体积/整件净重替代 feeding zone。
