## 一批 A · 球化 / 金相补强（改动小、直接回应用户提问）

### A1. 给 6 个球铁牌号补「金相组织」段（修改）
`QT400-18 / QT450 / QT500-7 / QT600-3 / QT700-2`（+ 批 B 新增的 QT 牌号同样带）

每个文件 `content` 增加 `metallography` 组，字段按牌号填：

| 牌号 | 球化级别要求 | 基体组织（GB/T 1348） | 珠光体含量（工艺参考） | 硬度 HBW | 使用状态 |
|---|---|---|---|---|---|
| QT400-18 | 2~3 级 | 铁素体 | <20% | 120~175 | 铸态/退火 |
| QT450-10 | 2~3 级 | 铁素体 | <25% | 160~210 | 铸态/退火 |
| QT500-7 | 2~3 级 | 铁素体+珠光体 | 40~60% | 170~230 | 铸态 |
| QT600-3 | 2~3 级 | 珠光体+铁素体 | 70~85% | 190~270 | 铸态/正火 |
| QT700-2 | 2~3 级 | 珠光体 | >85% | 225~305 | 正火 |
| QT800-2 | 2~3 级 | 珠光体或索氏体 | 珠光体为主/索氏体 | 245~335 | 正火/等温淬火 |

> 球化级别按 GB/T 9441 判定；珠光体含量为《铸造手册》工艺参考值（标准不强制百分数），reference 区分标注。

### A2. 新增卡「球墨铸铁金相检验（GB/T 9441）」`data/process/nodularity_grade.json`
- **球化级别 1~6 级 + 球化率**：1 级 ≥95%、2 级 90~95%、3 级 80~90%、4 级 70%、5 级 60%、6 级 50%
- 2021 版要点：面积法（颗粒圆整度 ≥0.60），计算机图像分析评定
- **珠光体含量分级**：珠95(>90%) ~ 珠5(≈5%) 共 12 级，浸蚀 2~5% 硝酸酒精后对照图谱
- **检验方法**：抛光态看球化（100×），浸蚀后看珠光体；视场取 3 个最差视场多数判定
- **验收要求**：球铁件一般 2~3 级、球化率 ≥85~90%；高要求件（风电/压力件）≥90%（2 级以上）
- keywords 含：球化率、球化级别、金相、珠光体、GB/T 9441
- reference：GB/T 9441-2021
- 关联：`related_calcs: ["defect_finder"]`（球化不良/石墨浮渣可跳查）

### A3. 给 3 个灰铁牌号补「金相组织」段 + 新增卡「灰铸铁金相检验（GB/T 7216）」
- 修改 `HT150 / HT200 / HT250`：加 `metallography`（石墨形态 A 型片状为主、石墨长度、基体珠光体/珠光体+铁素体、共晶团数）
- 新增 `data/process/gray_iron_metallography.json`：石墨形态 A~F 六类（A 型最优）、石墨长度分级、基体组织评级
- reference：GB/T 7216-2023

### A4. 收尾
- `data/index.js` 登记 2 张新卡；`data/taxonomy.js` 挂到「工艺」→「球化孕育处理」「凝固与收缩」；`data/tags.js` 补"金相/球化率"标签
- 球铁/灰铁 doc 的 `keywords` 补 `球化率`、`金相`、`珠光体`，让缺陷查找和搜索能命中

## 三批 C · 型砂检验体系

> 现状：湿型砂有目标值（湿压 0.05~0.10MPa、透气 ≥60、水分 3~4.5%）和 DISA 测试方法，但**没有按 GB/T 2684 的检测方法+频率总表**，树脂砂/水玻璃砂/覆膜砂**完全没有指标卡**。

### C1. 新增卡「型砂检验项目与方法（GB/T 2684）」`data/process/sand_test_methods.json`
- **检测项目总表**（每项：方法 + 湿型砂典型指标 + 频率）：
  - 水分（红外快烘/105~110℃ 仲裁法）· 3~4.5% · 每班
  - 透气性（快速/仲裁法，试样高 50±1mm 测三次）· ≥60（垂直线可 ≥80）· 每班
  - 湿压强度（三个试样平均）· 0.05~0.10 MPa · 每班
  - 紧实率（锤击式制样 3 次，体积压缩%）· 40±2% · 每 2h
  - 含泥量 · 见 green_sand_control · 每周
  - 酸耗值 / 灼烧减量 / 发气量（树脂砂关注）· 补充项
- **检测频率**：原砂每批；型砂每班/每 2h；全面性能每周
- reference：GB/T 2684-2025 + 工厂脱敏资料（频率）

### C2. 新增卡「树脂自硬砂（呋喃）控制」`data/process/resin_sand.json`
- 树脂加入量、固化剂（对甲苯磺酸）比例、可使用时间/脱模时间、终抗拉强度、透气性、存放要求
- reference：《铸造手册 第4卷 造型材料》+ 采购技术要求（脱敏）

### C3. 新增卡「水玻璃砂（CO₂ 硬化）控制」`data/process/water_glass_sand.json`
- 水玻璃模数/加入量、CO₂ 吹气时间、抗压强度、可使用时间、溃散性
- reference：《铸造手册 第4卷》

### C4. 新增卡「覆膜砂（壳型/热芯盒）控制」`data/process/shell_sand.json`
- 常温抗拉、热态强度、发气量、熔点/固化温度、可使用期
- reference：《铸造手册 第4卷》+ 采购技术要求（脱敏）

### C5. 收尾
- `data/index.js` 登记 4 张；`data/taxonomy.js` 挂到「型砂与造型」→「配方与控制」；`data/tags.js` 补"树脂砂/水玻璃砂/覆膜砂/检测"标签
- `sand_recipe.json` / `green_sand_control.json` 各加一条"检验方法见 GB/T 2684"互相链接

### 数据可信度（已核实/已标记）
- 吸收率主源《铸造工程师手册 第3版》表3-316（无芯感应炉），中频炉取中值：C 增碳 85%、Si 硅铁 85%、Mn 锰铁 82%、Mg 球化 45%
- 开箱温度/冷却时间表《实用铸造手册》+ 多来源交叉；**"凝固系数 k"（灰铁0.7/球铁2.0）各手册矛盾 → 弃用**，仅用经验表
- **可疑值已标记**：网络"Cr 烧损 39.4%"与惯例矛盾不用；库内 FeMo"吸收 50~55%"偏低未纳入（待扩展 Cr/Mo 平衡时复核）；吸收率全部 UI 可改并按本厂实测覆盖
