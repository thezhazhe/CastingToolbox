## 1. 当前问题

### 1.1 页面最终用的是哪个坐标（86.txt 三 要求明确回答）

```
STL → hotspot detection（js/engine/v3/）
    → peak（峰值点，M 最大处）
    → region（BFS 生长出的连通区域）
    → representativePoint() = 区域质心（isInside 校验，失败回落峰点）→ hs.x/y/z  ← 引擎输出
    → v3ViewAdapter.toViewResult()   只改字段名，不改坐标（mc/regionVolumeCm3…）
    → designCenter.toViewHotspot()   = 居中平移 + displayCenterFor(中面修正)
    → displayPosition                ← **页面 H1/H2 标签就放在这里**
    → modelView3D：marker 球 + sprite 文字位置 + 相机聚焦目标
```

**答案：页面用的是 `displayPosition`**（= 引擎代表点 + ≤3mm 的中面修正，再减去模型中心）。
`hotspots.items`（写进 CastingProject、供工艺计算报告打印坐标）用的仍是**引擎原始** `hs.x/y/z`。

### 1.2 漂移的成因（PHASE 84/85 已定量）

代表点取的是**区域质心**，而区域是用**未封顶原始 V/A** 生长的（`peakRegion.js:127`；
PHASE 24 为修 ALR2510 板/肋漏检而引入），峰值却用**封顶 M**。两把尺子 → 区域会顺着
凸台/底板交界一路长下去，质心被拽离峰点。

PHASE 85 实测：47 个热点里 **10 个飘出自己声明的厚区**、**1 个飘进别的热点厚区**。

## 2. 实验候选（86.txt 五）

全部按 86.txt 要求只测**极简单**的规则，不做连续优化：

| 代号 | 规则 |
|---|---|
| **S0 current** | 现状：代表点（+ 中面修正） |
| **S1 peak** | 直接用峰点 |
| **S2 α** | `α×peak + (1−α)×rep`，α ∈ {0.25, 0.50, 0.75} |
| **S3 Dmax=k×M** | 保持 rep→peak 方向，但最多拉近 `k × Mpeak`，k ∈ {1, 2, 3} |

**统一护栏**：候选点若不在材料内（`isInside` 6 射线，与引擎同一个判定）→ 回落当前代表点。
（这一步必须有：不加护栏时 S1 有 2 例、S2 各档 3 例、S3 k=3 有 4 例候选点落到材料外。）

**判据（86.txt 七 的优先级，不用 PASS 率）**：
① 有没有跑到无关结构 → ② 是否在 hotspot region 尺度内 → ③ 是否更靠近峰点 → ④ 有没有破坏原本合理的模型。

## 5. 最终选择（86.txt 十五.5）

> **采用 S3，k = 1：显示点 = 代表点朝峰点拉近，最多拉 1×Mpeak；出材料则回落代表点。**

理由（对照 86.txt 七 的四级优先级）：

| 优先级 | S3 k=1 的表现 |
|---|---|
| ① 有没有跑到无关结构 | **0 例**（材料外 0 / 别的热点厚区 0，S0 是 1） |
| ② 是否在 region 尺度内 | 26/47 → **34/47** |
| ③ 是否更靠近峰点 | 中位 24.7 → **15.2** |
| ④ 有没有破坏原本合理的模型 | 护栏 A 四个全部保持"在材料 ✅ + 在自己厚区 ✅"；**唯一退化是 t08#1 的 4mm 边界抖动** |

**并且满足 86.txt 十 的"停止条件"**：一个极简单规则（一个常数 k=1）已经做到
"大部分热点落在合理区域 + 明显漂移明显减少 + 原本正确案例没有明显退化"。
→ **停止，不再加参数、不做连续优化、不追求理论完美。**

## 9. 结论（86.txt 十六）

> **问题**：现在页面上的热点标签，能不能以一个简单、稳定、肉眼合理的方式显示在热点附近？
>
> **答案：可以。**

- 用一个常数（k=1）的极简规则，把"飘出自己厚区"从 **10 降到 5**、"跑到别的热点厚区"从 **1 降到 0**、
  到峰点距离中位从 **24.7 降到 15.2**，全程 **0 例**落到材料外；
- 原本代表点更准的 4 个模型（t01/t02/t09/t11）**全部保持在自己厚区内**；
- 唯一一处退化（t08#1）是 4mm 的环带边界抖动，仍在材料内，**不为它加规则**。

**未做**：没碰 hotspot 算法、没碰 region growth、没碰 peak、没碰 GT、没碰 legacy 口径、
没加任何第二参数、没做连续优化、没引入尺寸分级或自适应权重。
