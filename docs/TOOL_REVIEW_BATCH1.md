## ① 冒口设计（riser）

**入口**：计算工具 → 冒口设计（🏗️）。内部模块 `calcs/riser.js` + `js/views/riserView.js`。

### (a) 用户输入
| 字段 | 含义 | 默认/选项 |
|---|---|---|
| 材质 | 冒口补缩用材料库 | 灰铁/球铁/铸钢/铝/铜（显示各材质体收缩率） |
| 铸件重量 cw | **体积校验用**（可不填=0） | Kg，默认 10 |
| 热节模数 Mc 输入方式 | 四种任选其一 | 直接输入 Mc / 热节圆直径 d（Mc=d/2）/ 壁厚 t（Mc=t/2）/ 热节处 V 与 A（Mc=V/A） |
| 冒口形状 | 模数几何库 | 圆柱形（明）/ 球顶圆柱暗冒口 / 球形（暗）/ 正方柱 |
| H/D 比 | 冒口高径比 | 0.8 / 1.0 / 1.2 / 1.5（默认 1.0） |
| 补缩效率 | 四种形状默认值**可修改** | 明顶圆柱/方柱 14% · 暗侧圆柱 20% · 球顶柱暗冒口 25% · 发热保温 35% |

### (b) 结果输出
- 推荐冒口规格（如 ⌀D×H，球形=球⌀D，方柱=a×a），D/H/H-D 比
- 模数放大系数 f（从 1.10 迭代的最终值）、Mc、所需模数 Mr_需、实际模数 Mr_实（带 ✓/✗ 判定）
- 体积校验组：冒口体积 Vr、补缩效率、有效补缩量 effV、铸件体积 Vc、收缩率、所需补缩量、补缩判定（充足/不足）、工艺出品率
- 冒口颈：颈模数 M_neck、圆形颈 ⌀d、方形颈 a×a（两值相同）、颈长建议（0.5~1.0 倍颈径）、颈径占冒口直径 %
- 校核结论（两个 chip：模数 ✓/✗、体积 ✓/✗）+ 可生成计算记录（报告/打印/下载/复制）

### (c) 中间计算过程
1. **Mc 求取**（按输入方式）：
   - direct：直接用 Mc；hot_spot：Mc=d/2（圆柱热节）或 t/2（板状热节 wall）；volume：Mc=V/A（散热面积法）
2. **迭代寻尺寸**（核心）：f 从 **1.10 起、每轮 +0.05**，上限 50 轮：
   - 所需冒口模数 Mr_need = Mc × f（模数放大原则：冒口凝固慢于热节 → 模数必须放大）
   - 由形状库反推：圆柱/方柱 `D = Mr×(2+4·hd)/hd`；球形 `D = 6·Mr`；球顶圆柱先按上式 ÷0.92 得初值，再做 20 次迭代 `D *= Mr / M(D, D·hd)` 收敛到目标模数
   - `H = round(D × hd)`，`D = round(D)`（制造取整）
   - 实际模数 `Mr_act = 形状模数公式(D,H)`：
     - 圆柱/方柱：`M = D·H/(2D+4H)`（全表面散热=明冒口）
     - 球顶柱：半球头+柱体 `M = V/A`，A 计半球曲面+柱侧+柱顶（**底面不散热**≈接铸件）；H≤r 时退化为 `M=D/6`
     - 球形：`M = D/6`
   - 校核 `modOk = Mr_act ≥ Mr_need × 0.99`（取整误差容忍 1%）
   - 体积校核（仅 cw>0）：铸件体积 `Vc = cw×10⁶/ρ`（mm³，ρ=固态密度 28.7-A 定稿），所需补缩量 `needVol = Vc×shrink`，有效补缩 `effV = Vr×eff`，`volOk = effV ≥ needVol`
   - 两项都过 → 停止（final_f=当前 f）；50 轮未过 → 输出未达标状态（模数/体积 chip 显红）
3. **冒口颈**：颈模数 `M_neck = Mc × neck_k`（材料系数：灰铁 0.75 / 球铁 1.0 / 铸钢 1.1 / 铝、铜 1.0——冒口颈只须比热节"略快凝固"但比冒口晚，故取 Mc 的 0.75~1.1 倍）；按圆颈 `M=d/4` 反推 `d_neck = round(M_neck×4)`；方颈同尺寸（`M=a/4` 等价）；颈长建议 = 0.5~1.0×d_neck（标准经验）
4. 工艺出品率 = `Vc/(Vc+Vr)×100`（%）

### (d) 输出逻辑（为什么）
- **模数放大系数 f 迭代而非直接取 1.2**：f 是"冒口模数/热节模数"的安全倍数；放大多少还取决于形状取整、体积能否满足补缩——直接给固定 f 可能体积不足或过度设计，故程序从小放大逐步试到「模数 ✓ 且体积 ✓」双通过，给出**最小可行冒口**；f 会因形状不同而不同（明冒口效率低→体积所需更大）
- **明冒口 vs 暗冒口效率默认不同**（14 vs 20~25%）：明顶散热大、金属利用率低；球顶柱暗冒口被砂型包覆散热慢、效率高；发热冒口 35% 最高——效率直接决定「同样补缩量需要多大冒口体积」（effV=Vr×eff 必须 ≥ 铸件收缩量）
- **体积校验与模数校验双轨**：模数保证"凝固顺序"（冒口最后凝），体积保证"补缩量够"（收缩多少补多少）。只过模数可能缩孔（量不够），只过体积可能冒口早凝（补不进）——两者必须同时满足，这是冒口设计的两个独立必要条件
- **体收缩率 shrink 是冒口专用口径**（灰铁 2%/球铁 3%/铸钢铝铜 4.5%），与"线收缩率"完全不同：补缩补的是凝固收缩的体积差
- **铸件重量填 0 时只做模数校核**（视图提示"输入铸件重量后可做体积校验"）——防止用户没有可靠重量时给出虚假的体积结论
- 取整采用 round + 1% 容差：冒口尺寸以 mm 制造取整，微小负偏差由 1% 容差吸收（属本工具口径，与 gating 的 ceil 规则不同源）

## ② 线收缩率（shrinkage）

**入口**：线收缩率（📏）。模块 `calcs/shrinkage.js` + smallCalcs 视图。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 材质 | 灰铁/球铁/铸钢/铝/铜（下拉旁提示三档值与区间） |
| 收缩档位 | 自由收缩（开放结构）/ **常用值（生产·模具缩尺，默认）** / 受阻收缩（筋板/法兰/型芯/复杂） |
| 方向 X/Y/Z 尺寸 | 三个方向的铸件尺寸（mm，≥1 个有效即可；默认 500/300/150） |

### (b) 结果输出
- 每个有效方向一行：该方向推荐收缩率 % + 放尺后的模型尺寸（原尺寸×(1+率)）
- 档位说明（三档区间，如灰铁 0.9~1.1%）+ 该材质机理注释（石墨化膨胀等）
- **两个出口之一**：
  - 方向均衡（各方向率差 < 0.2 百分点）→ 给「综合比例（整体放尺）」= 档位上限值
  - 方向悬殊（率差 ≥ 0.2 点）→ 红色提示「不宜用统一综合比例，请分方向放缩水」
- 档位使用提示（如受阻时局部再多放 0.1~0.2%）

### (c) 中间计算过程
1. 查材质三档基础值（SHRINKAGE 表）：
   - 灰铁 free 1.0 / common 0.85 / restrained 0.8；球铁 1.0/0.8/0.6；铸钢 2.2/1.8/1.5；铝 1.1/1.0/0.8；铜 1.4/1.3/1.2（%）
2. 档位 → 取值带：free=[common,free]、common=[restrained,common]、restrained=[restrained,restrained]（受阻滞档内不再浮动）
3. 每个方向**按绝对尺寸线性插值**：`t = clamp((size−100)/(1000−100), 0, 1)`，`rate = lo + (hi−lo)×t`——即 ≤100mm 方向取下限、≥1000mm 方向取上限
4. 放尺量 `amount = size×rate/100`；模型尺寸 `pattern = size×(1+rate/100)`
5. `spread = 最大率 − 最小率`；`directional = spread ≥ 0.2`；`combined = directional ? 无 : hi`（档位上限）

### (d) 输出逻辑（为什么）
- **为什么按"绝对尺寸"而不是按比例浮动**：收缩率是同材同约束下的物理常数（1500mm 与 10mm 都约 1%），率的微小差别本身意义不大；但**放尺量是尺寸×率**——大方向多放十几 mm、小方向放 0.1mm，模具才必须区别对待。因此程序不夸大"率差"，只在放尺量差异真实显著（率差 ≥0.2 点）时才强制分方向
- **同一合金三个值、选档即选条件**：自由收缩只在无阻碍开放结构成立；实际生产铸件总有筋/芯/法兰阻碍收缩，所以"常用值"已比自由小（灰铁 0.85 vs 1.0），复杂结构用"受阻"最小档
- **分方向判据 0.2% 的工程含义**：率差 <0.2 点时，即使最大 1500mm 方向两者放尺也只差 3mm，综合比例误差可接受；超过则必须 X/Y/Z 分别放尺，否则一个方向留量不足或过大
- 数据为参考值、UI 注明"以试制修正为准"——放尺最终以实际首件修正，工具给合理起点

## ③ 机械加工余量（machining）

**入口**：加工余量（🛠️）。模块 `calcs/machining.js`（GB/T 6414-1999 数据表）。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 铸造方法 | 砂型·手工造型 / 砂型·机器造型·壳型 / 金属型（重力·低压）/ 压力铸造 |
| 材质 | 灰铸铁/球铁/铸钢/铝合金/铜合金（**球铁与铜合金按灰铸铁档查**——GB 表只列三材） |
| 铸件最大轮廓尺寸 | 最终加工后最大尺寸（mm，默认 300） |

### (b) 结果输出
- 单侧余量范围（如 1.4~2.8mm，等级 E~G、尺寸档说明）
- 推荐取值（中档 mid）、砂型时另给顶面单侧（等级粗一级、余量更大）
- 圆柱/双侧加工 = 单侧 ×2
- 无标准组合时诚实提示（如 压铸×灰铁/金属型×铸钢：GB/T 6414 未给等级 →「宁缺毋滥」提示按厂工艺定）
- 尺寸超表（>10000mm）提示

### (c) 中间计算过程
1. 「方法 × 材质」→ 推荐等级区间（METHOD_GRADES 表，如 砂型机器造型×灰铸铁 → E~G）：
   - 砂型·手工：铸钢 G~K / 灰铁 F~H / 铝 F~H
   - 砂型·机器/壳型：铸钢 F~H / 灰铁 E~G / 铝 E~G
   - 金属型：铸钢 —（无）/ 灰铁 D~F / 铝 D~F
   - 压铸：仅铝 B~D（铸钢/灰铁无）
2. 按最大轮廓尺寸查 RMA 表（≤40 → ≤10000 共 13 档 × A~H 8 级，单侧 mm）：区间规则=上一档 max 与本档 max 之间开区间（首行即 ≤40）；J/K 级未收录（特殊场合）→ 解析 'G~K' 时实际只有 G/H 参与取值
3. `rmaRange`：解析区间串取所有有效等级 → 各等级查表值 → min/max/mid（中值=（min+max）/2）；显示中档等级
4. 顶面（仅砂型）：中档等级再粗一级 `nextCoarserGrade`（A→…→H 封顶）→ 再查表得顶面单侧值

### (d) 输出逻辑（为什么）
- **等级自动、不给用户选**：GB/T 6414 的等级是"按工艺水平选"，铸造方法+材质已基本决定合理等级带；工具直接把区间转成**余量范围**输出，避免用户误选过小等级（余量不足留黑皮）
- **为什么是"范围"**：推荐等级带跨多级（如 E~G），对应余量是一段而不是单值——输出 min~max + 中档推荐值，供工艺按本厂水平取
- **顶面粗一级**：砂型顶面（浇注位置朝上）易气孔/夹杂/浮渣，GB 惯例顶面 RMA 比底/侧面粗一级（代码对任何砂型方法都应用此规则）
- **球铁/铜合金映射灰铸铁档**：GB/T 6414 原表仅列铸钢/灰铸铁/铝合金三类，球铁与灰铁、铜与灰铁同表是标准通行做法
- **无组合 → 不猜**：金属型×铸钢、压铸×灰铁等组合 GB 无等级依据，工具明确说"无标准等级，按本厂定"而非给伪数值；界面表格附完整 RMA 表供人工查阅
- 实战提示（UI 文案）：RMA 是**标准最小**余量，工厂常按 1.5~2 倍留，重要面放大 1~2 级——属工程提示，不参与计算

## ④ 出品率与铁水重量（yield）

**入口**：出品率与铁水重量（📊）。模块 `calcs/yield.js` + smallCalcs 视图。

### (a) 用户输入
**第①步 预估出品率**（用于给参考区间，选得越细越准）：
- 产品类型（10 种：刹车盘/缸体/变速箱壳/泵阀/法兰/管件/飞轮/轴承座/排气管/轮毂铸铝；可不选）
- 铸造工艺/产线（垂直线/水平线/手工造型/壳型/金属型/低压/重力；可不选）
- 材质（灰铁/球铁/铸钢/铝/铜；可不选）

**第②步 现场实测 → 铁液重量**：
- 单件毛重（Kg，默认 50）、一模件数（默认 2）
- 现场实测出品率 %（**默认自动预填第①步预估中值**，用户手改一次后不再被覆盖）

### (b) 结果输出
- 预估出品率区间 + 依据说明（如「缸体×水平线」55~70%）+ 回退级别
- 铁液重量组（按现场实测值算）：单件铁液重量、一模铁液总重、一模浇冒口重量、材料密度（参考行）
- 用途提示：估算一炉铁液用量/熔炼配料/浇包容量

### (c) 中间计算过程
1. **多级回退解析**（只取最具体一级）：
   - ① 产品类型×工艺（PRODUCT_YIELD，如 缸体×垂直线 [52,62]）
   - ② 材质×工艺（MAT_PROCESS_YIELD，如 灰铁×水平线 [68,80]）
   - ③ 工艺 only（PROCESS_YIELD，如 垂直线 [45,65]）
   - ④ 材质 only（= gating MATERIALS 的 y_min~y_max，如 灰铁 [65,85]）
   - ⑤ 通用 [40,60]
2. 实测出品率默认 = 预估区间中值（按 0.5 步进取整），用户可改；手改后以用户值为准
3. `G_单件 = 单件毛重 ÷ (实测出品率%)`；`一模总 = G×件数`；`浇冒口 = 一模总 − 单件毛重×件数`

### (d) 输出逻辑（为什么）
- **为什么预估与实测分开两步**：出品率受浇冒口设计/工艺水平/设备影响，行业区间只是参考，各厂差异大——预估区间帮助判断"自己厂水平在区间内还是外"，而**一切重量计算只按实测值**，杜绝拿参考区间去配炉料
- **为什么默认预填中值且允许改**：用户没数据时给一个合理起点（预估中值），但有实绩的厂必须能覆盖——"改一次即记住"避免每次计算被预估中值覆盖
- **五级回退只显示一个最准结果**：不叠加显示多个可能区间（避免"到底哪个对"的困惑），依据文本明示回退链
- **口径注意（供排查）**：第②步的"单件毛重"若指**铸件成品重**，则浇冒口重量计算 G−毛重 成立（毛重=铸件重）；若用户输入的是**带浇冒口的毛重**则口径需澄清——当前代码与 UI 文案按前者（毛重=铸件重量）使用
- 垂直线偏低、水平线/金属型偏高为表内事实，UI 明示

## ⑤ 冷铁计算（chill）

**入口**：冷铁计算（❄️）。模块 `calcs/chill.js` + 数据 `data/chill_calc.js`（《铸造工艺设计及应用》CNKI 冷铁词条）。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 铸件材质 | 灰铸铁/球墨铸铁/可锻铸铁/铸钢/铝合金/铜合金 |
| 冷铁类型 | 外冷铁·直接 / 外冷铁·间接(隔砂) / 内冷铁 |
| 热节壁厚 T | 被激冷热节处壁厚（mm，默认 40） |
| 冷铁材料 | 按铸件材质列出可用组合并默认推荐（如灰铁默认铸铁冷铁，铸钢默认钢板冷铁） |

### (b) 结果输出
- 外冷铁：**厚度范围 δ**（mm）+ 系数式（如 0.25~0.5×T）+ 推荐取中值；内冷铁：**直径范围**（≈0.3~0.5×T）+ 中值
- 当前冷铁材料/推荐材料行
- 警告组（红）：壁厚 >100mm 外冷铁失效、激冷饱和（二分之一原则，超过约 hi 倍后不必更厚）、隔砂挂砂层 10~15mm（>40mm 失效）、冷铁材料搭配回退提示
- 布置规则组：外冷铁 ≤300mm/块间 10~30mm/45° 过渡薄口/表面涂料/放底侧/不阻补缩/复用失效判据（按类型给子集）

### (c) 中间计算过程
1. 内冷铁：`d = 0.3~0.5×T`（圆杆定直径），mid=0.4T——直接返回，不查系数表
2. 外冷铁：查系数表 `CHILL_COEF[铸件材质][冷铁材料]` → δ = 系数×T（1 位小数取整显示）。系数表要点：灰铁 铸铁/钢板 0.25~0.5、铜 0.2~0.4；球铁 0.3~0.8（铜 0.25~0.6）；可锻 1.0~1.0（仅铸铁）；铸钢 0.3~0.8（铜 0.25~0.6）；铝 铸铁 0.8~1.0、铝冷铁 1.2~1.5；铜合金 铸铁 1.0~2.0、铜 0.8~1.0
3. **搭配回退**：若所选冷铁材料不在该铸件材质表内（如灰铁×铝冷铁）→ 自动改用 `CHILL_DEFAULT_MAT[材质]`（灰铁/球铁/可锻/铝/铜→铸铁冷铁，铸钢→钢板冷铁）计算并出警告——**绝不返回空**
4. 失效/饱和检查（上述 4 类警告）
5. 规则按类型切分：内冷铁取规则 5~8 条，外冷铁取规则 4~8 条

### (d) 输出逻辑（为什么）
- **外冷贴板定"厚度"、内冷圆杆定"直径"**：几何对象不同，单位量纲不同——两者都由热节壁厚 T 按比例定（激冷需求随热节大小线性缩放）
- **系数按"铸件材质×冷铁材料"双维**：冷铁靠自身吸热/导热激冷——铜吸热最强可做薄（0.2~0.4×T），铸铁/钢板次之，铝蓄热差必须做厚（铝件配铝冷铁 1.2~1.5×T）；同样厚度不同材质激冷能力不同，故切材质时厚度跟着变（UI 说明行原文）
- **为何铝件推荐用铸铁冷铁而非铝冷铁**：铸铁冷铁蓄热系数适中、成本低、可重复用——下拉默认推荐即常用搭配；需要更强激冷时手动选铜冷铁（系数更小=更薄即可）
- **失效警告是"防止盲目加厚/用错类型"**：>100mm 壁厚外冷铁几乎无效（激冷深度有限）→ 改内冷/强制冷却；挂砂层 >40mm 激冷丧失；超过饱和厚度继续加厚无收益（二分之一原则）——提示而非硬禁止
- **搭配回退绝不返回空**：防御设计——避免视图因无数据崩溃或残留旧结果，用户看到的永远是"用推荐材料算的结果+为什么"（警告里说清）
- 内冷铁附带工艺警告（须熔合/除锈镀锡/过多致组织异常）——内冷铁残留在铸件内，风险高于外冷，必须提示
