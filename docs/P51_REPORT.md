## B. 工程逻辑（52.txt §2-9）

**阻流位置按最终实际几何面积判定**（取整/ceil 后），非理论比例、不按 ratioKey/材料判断：

```
A_choke = min(Fs_act, Fr_act, Fg)   （三段缺一 → 'unset' 不判定）
chokePosition: sprue / runner / ingate / boundary（相对差 ≤1% 并列，CHOKE_TOL=0.01，纯判定不改面积）
systemType: 内浇口→封闭式（加压式）；直浇道→开放式（非加压式）；横浇道→横浇道阻流（上游控制）；boundary→临界（需复核）
```

**优化门禁规则**（calc 标记 + UI 执行）：

| 实际阻流位置 | v 偏高 | 自动优化 |
|---|---|---|
| 内浇口 | 是 | ❌ 不提供（显示"内浇口承担流量控制，因此不提供自动放大优化"） |
| 直浇道 | 是 | ✅ 提供 |
| 横浇道 | 是 | ✅ 提供 |
| 临界/并列 | 是 | ❌ 不提供（"阻流位置接近临界状态，请工程复核"） |
| 无目标速度 | — | ❌ 不提供 |

**优化后二次 choke 验证**：试算 optimize 结果 → `Fg≤Fs_act 且 Fg≤Fr_act`（内浇口成为新 choke）→ **拒绝提交**，
弹窗"目标速度无法在保持当前阻流位置的情况下达到…建议重新调整浇注比例或上游截面"，[返回原设计] = 不提交任何修改；
不提供"继续强制优化"。

**如实声明（52.txt §21 冲突处理）**：放大内浇口在几何上只会增大 Fg——从非内浇口初始态**不可能**反向迁移到
"内浇口成为新 choke"（T6 按字面"放大导致 ingate 迁移"无法构造，phase51-T6 已改测防御标记与几何事实一致性，
测试注释说明）。二次验证保留为理论安全网（若未来出现缩小上游类优化才可能触发）。

## C. UI 信息减法（52.txt §11-15）

**第一屏（#g_summary，默认可见）**：
- 结论三态：🟢 浇注系统设计可用 / 🟠 建议关注内浇口速度（或排气/超 R7）/ 🔴 需要调整浇注系统（存在 ❌ 硬问题）
- 核心数据：总浇注重量 G｜浇注时间｜平均压头 Hp｜阻流面积 A_choke｜阻流位置｜系统类型
- 最终尺寸：直浇道 ⌀｜横浇道 厚×长×条｜内浇口 厚×长×个数（或 ⌀×个数）
- 校核：内浇口平均速度 + 🟢正常/🟠偏高/🔴明显偏高（超 R7 红线→🔴）/ℹ️偏低；排气面积比 + 🟢/🟠/🔴
- 优化按钮（仅 sprue/runner 阻流且偏高时）或阻流说明（ingate/boundary）或优化成功绿条
