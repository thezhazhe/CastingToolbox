## 三、中注 Hp 公式专项调查（P0-2，C 输出）

### 1. 当前代码（gating.js:67-71 + calcManifest.js:83）

```
Hp(顶注) = Ho + Hb/2 − rh²/(2C)               ← rh 恒 0 → Hp = H0
Hp(中注) = Ho + Hb/2 − (Pv + Cmm − rh)²/(2Cmm)  ← rh 恒 0 → P 项 = 1.5×Cmm
Hp(底注) = Ho + Hb/2 − Ho/2
```

### 2. 历史来源四条证据链

**① 历史 Excel（源头，决定性）**——`工艺设计说明书-V3.2.2-2.xlsx` `浇注系统尺寸计算`!K7（V1.7_20160302）：

```
=IF(COUNTIF(F5,"中注")=1, F7+F10/2-(F9+F8-K6/10)*(F9+F8-K6/10)/2/F8,
   IF(COUNTIF(F5,"底注")=1, F7+F10/2-F7/2,
      F7+F10/2-K15/10*K15/10/2/F8))
```
变量：F7=Ho、F10=H水口盆、F8=C=铸件高+冒口高、F9=P（注释原文"底注 P=C；中注 P=C/2；顶注 P=0"）、**K6=铸件高度（浇注方向）、K15=冒口高度**。

**② Python 历史版**：v35/v36 `calc_Hp(pos,Ho,Hb,P,C,rcm)`（rcm=冒口高，注释"Ho+Hb/2-冒口高2/2C"）→ v37 公式与当前一致，docstring 定义 **rh=冒口高度**（语义在此漂移）。
**③ HTML v3.8**（gating.js 声明的提取源）：公式与当前逐字一致。
**④ 单位换算验证**：Excel 奥赞常数 22.6（Hp cm 体系），代码 71.47 = **22.6×√10**（mm 体系）——证明移植做了正确的单位转换，公式同一。

### 3. 数学等价性分析

```
Excel 中注修正项 = F9+F8−K6/10 = C/2 + C − H件 = C/2 + H冒
代码 中注修正项 = Pv+Cmm−rh   = C/2 + C − 0   = 1.5C = 1.5(H件+H冒)
```
仅当 H件=0 时相等。数值实例（C=100、Ho=150、Hb=200）：Excel 无冒口 **237.5mm = 文献式 H0−P²/2C** ✓；Excel 有冒口 74mm（可信）；代码 rh=0 → **Hp≤0 → A=0 无结果**。

### 4. 与文献比较

| 模型 | 中注 Hp | 说明 |
|---|---|---|
| 文献（奥赞法） | H0 − C/8（P=C/2） | 内浇口在型腔中部 |
| 历史 Excel | H0 − (C/2+H冒)²/2C | **无冒口时=文献 ✓；有冒口时加冒口项（企业修正，方向合理）** |
| 当前代码（rh=0） | H0 − (1.5C)²/2C | 与两者均不等价（变量合并+未接线） |

### 5. 结论与建议（修复方案待人工批准，本阶段不修改）

| 方案 | 内容 | 建议 |
|---|---|---|
| A（推荐） | 中注 (Pv+rh)、顶注 −rh²/2C（rh=冒口高度），rh 接 UI（可由 riser D/H 反推）；无冒口时自动退化文献式 | 先做 Excel 真实案例数值回归再实施 |
| B | 中注直接用 Pv（=C/2），删冒口修正 | 完全回归文献 |
| C | 维持现状 | 不推荐（中注保持失效） |

**附带溯源确认（同 Sheet）**：t=f×(√G+∛(wG/5))×2/3=Excel K11 同构（f=灰铁 1.0/球铁 0.85）✓；fv 0.8/0.6/0.45=参数运算表速度系数（**"有过滤网-0.1"缺失**）✓；ρ=Excel F13 注释"**液态**金属密度，灰铁 7.0/球铁 6.9" ✓（铸钢 7.5/铝 2.6 为后加）；流速 10G/(tρFg/100)=Excel K16 同构 ✓；Hb 表=Excel F10 注释（1T-30/3T-50/8T-75/20T-110/40T-110 cm）✓。
