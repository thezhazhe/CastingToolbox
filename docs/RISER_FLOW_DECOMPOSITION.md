## 〇、工具在系统中的位置（两形态 + 三回写）

冒口不是孤立计算器，有**两个入口、三条回写链**：

```
┌─ 入口 A：工艺设计中心（工作流）───────────────────────────┐
│  STL 热结分析 → mcHotspot / wallHot → 自动冒口建议 →       │
│  门禁矩阵（分析失败/低置信度绝不静默）→ 结果回写项目参数       │
└────────────────────────────────────────────────────────┘
┌─ 入口 B：独立计算器「🏗️ 冒口设计」（知识页入口）───────────┐
│  手动填全部参数 → runRiser 同引擎 → 校核 + 计算记录报告      │
└────────────────────────────────────────────────────────┘

回写①：riser.H → process.riserHeight → gating 中注 Hp 方案 A（冒口高参与压头）
回写②：riser.Vr×ρ → riserWt(kg) → yield 出品率与铁水总重
回写③：geometry / hotspots 状态 → chill（T_hot 已独立，不再读 riser）
依赖序（RUN_ORDER）：… → riser → gating → yield → …
```

两形态共用同一个纯引擎 `runRiser(input)`；差异只在「Mc 从哪来、形状/效率是否开放、结果写哪」。

## 一、用户输入什么

### 入口 B（独立计算器）—— 4 张卡、6 组输入

| 组 | 字段 | 选项 / 默认 | 语义与边界 |
|---|---|---|---|
| ① 材质 | 材质下拉（5 材料） | 灰铁 / 球铁 / 铸钢 / 铝合金 / 铜合金（选项文字自带缩率） | 决定 ρ 固态密度、体收缩率、颈系数；球铁默认 |
| ② 铸件重量 cw | 数值 | 默认 **10 kg（示例值，已标记）**，可填 0 | **仅体积校核用**；填 0 = 只做模数校核（UI 明示） |
| ③ 热节模数 Mc | 输入方式下拉 + 参数 | **四种任选一**（切换显隐） | 见下表 |
| ④ 冒口形状 | 下拉 | 圆柱形(明) / **球顶圆柱暗冒口** / 球形(暗) / 正方柱 | 形状决定几何公式 + 默认效率键 |
| ⑤ H/D 比 | 下拉 | 0.8 / **1.0** / 1.2 / 1.5 | 离散四档非连续 |
| ⑥ 补缩效率 | 4 个数值框（**可修改**） | 明顶 14 / 暗侧 20 / 球顶柱 25 / 发热保温 35 % | 源自《铸造手册》第5卷典型值；默认随形状自动对应 |

**Mc 四种换算输入（calcMc）**：

| 方式 | 用户填 | 换算 | 几何口径（RISER_AUDIT_56 表 1/2） |
|---|---|---|---|
| 直接输入 | Mc | Mc 原样 | — |
| 热节圆直径 d | d | **Mc=d/2** | 等效板厚口径（圆棒 d/4 为另一体系，代码偏保守，56 记录） |
| 壁厚 t | t | **Mc=t/2** | 无限大平板 M=0.5t（教材标准定义） |
| 体积 V + 面积 A | V, A | **Mc=V/A** | 散热面积法 |

> 门禁（PHASE 63 镜像）：空/0/负/NaN → 显示中文错误**绝不静默给结果**；每卡字段均过 checkNum。

### 入口 A（工艺设计中心）—— 自动为主、人工放行

| 场景 | Mc 来源 | 门禁行为（calcManifest calculate） |
|---|---|---|
| STL 分析成功、有热结 | `hotspots.status=ok` → 最大热结 M → mcHotspot | 直接建议 |
| STL 分析**失败**（INSUFFICIENT_RESOLUTION） | — | **BLOCK_AUTO_RECOMMEND**：不给建议，提示人工输入 Mc |
| 候选**低置信度**（LOW_CONFIDENCE） | — | 同上，blocked（避免偏小误导） |
| **真均匀件**（NO_HOTSPOT） | wallHot=主体壁厚/2 兜底 | 建议 + note「保守性估算，建议结合工艺经验复核」 |
| 手动模式（无 STL） | wallHot / 用户填 | 用户显式 Mc 放行；自动 mc 标记 WARNING_REVIEW |
| 用户**人工输入 Mc** | USER_OVERRIDE/INPUT | 最高优先（28.4-3：输入不再被静默忽略） |

> 设计中心固定参数（不可改）：形状=球顶柱暗冒口、H/D=1.0、效率=按形状默认 25%（PHASE 29 P1-40：scope=calculator 的完整参数只在独立工具开放，设计中心不渲染不存储）。

## 二、中间计算过程（公式全链）

### 五步链（对应 runRiser 实际执行顺序）

**Step 1　材料取数与 Mc**
```
md = 材料表[mat]（未知材料 → 球铁兜底 + mdFellBack 标记，绝不静默）
ρ  = input.rho ?? md.rho     ← 设计中心在项目 solidDensity=USER_OVERRIDE 时显式传入（28.6）
Mc = 按输入方式换算（见上）
sd = 形状库；hd = H/D；eff = input.eff ?? 形状默认效率 /100
```

**Step 2　f 迭代寻最小可行尺寸（核心循环，≤50 轮，从 f=1.10 每轮 +0.05）**
```
Mr_need = Mc × f                      ← 模数放大原则：冒口须比热节晚凝
D  = 形状反推（圆柱/方柱 D=Mr(2+4hd)/hd；球 D=6Mr；
     球顶柱初值 ÷0.92 → 20 次牛顿迭代 D*=Mr/M(D,D·hd) 收敛）
H  = round(D×hd)；D = round(D)        ← mm 制造取整
Mr_act = 形状模数公式(D,H)
  · 圆柱/方柱：M = D·H/(2D+4H)        （全表面散热=明冒口）
  · 球顶柱：M=V/A（半球+柱体，**底面不散热**≈接铸件；H≤r 退化 D/6）
  · 球形：M = D/6（数学恒等）
Vr = 形状体积；effV = Vr×eff          ← 有效补缩量
模数校核 modOk = Mr_act ≥ Mr_need×0.99   （取整误差容忍 1%）
体积校核 volOk（仅 cw>0）：
  Vc = cw×10⁶/ρ (mm³)；needVol = Vc×shrink；volOk = effV ≥ needVol
两校核都过 → 停在当前 f（=最小可行冒口）；不过 → f+=0.05 继续
50 轮不过 → 输出未达标态（chip 显红，不造假）
```

> **f 迭代的真实机制（探针实测）**：f=1.10 的冒口若体积已够（如铸钢 Mc=30、50 kg：effV 0.85 L ≥ need 0.29 L），f **不会**继续放大；只有当体积不足（轻材料/大重量/低效率形状）f 才上涨（实测球铁 Mc15×10kg 恒 1.10；铝 10kg→1.15；铸钢 Mc30×200kg→1.25）。即「f 由体积约束驱动，不是重量越大 f 越高」——56 审计所述「大件 f 1.35~3.5」是同一机制在不同 Mc/效率组合下的表现。

**Step 3　冒口颈（体积主判据之后独立计算，不迭代）**
```
neck_k：灰铁 0.75 / 球铁 1.0 / 铸钢 1.1 / 铝·铜 1.0（56.txt 表 1/2：ASM/Karsay 印证——
  skin 合金通则 1.1Mc；石墨铸铁 0.67~1.1Mc 区间；铝铜 1.0=区间内工程值）
M_neck = Mc × neck_k
d_neck = round(M_neck×4)      ← 圆颈 M=d/4 → d=4M；方颈 a×a 同值（M=a/4 等价）
颈长建议 = 0.5~1.0 × d_neck（标准经验）
```

**Step 4　工艺出品率**：`yieldPct = Vc/(Vc+Vr)×100`（仅 cw>0；Vc 用固态密度换算）

**Step 5　设计中心接线**（仅入口 A）：`H → process.riserHeight`（→ gating 中注 Hp 方案 A）、`Vr×ρ/1e6 kg → riserWt`（→ yield）、可靠性标签 `level`（reliabilityLevel：geomStatus+hsStatus → SAFE/WARNING_REVIEW/…）

### 全参数出处分级（56.txt 双源核验汇总）

| 类别 | 参数 | 出处 | 核验结论 |
|---|---|---|---|
| B 公式 | 圆柱/方柱/球/球顶柱模数公式、Mc 换算、体积补缩模型 | 《铸造工艺学》/《铸造手册》模数法（Wlodawer 体系） | 保留，数学恒等/教材同式 |
| C 经验 | 效率 14/20/25/35%、体缩 2/3/4.5%、颈系数 0.75/1.0/1.1/1.0/1.0 | 《铸造手册》第5卷 + ASM/Karsay | **全落权威区间**（表 1 13 项 + 表 2 5 项有差异但不影响判断；表 3 人工项 = 0） |

## 五、打磨观察点（仅供决策，未改任何代码）

按 20% 原则排出「值得讨论 vs 不建议动」：

**值得讨论（影响使用质量/判断正确性）**
1. **f=1.10 起步与「cw 轻/0 时停在材料因子下沿」**：56 表 2 已记录钢惯例 1.2 起步、材料因子分列（钢 1.1~1.25 / 球铁 1.0~1.1 / 灰铁 0.8~0.9 / 铝 1.1~1.2）。当前代码唯一 f 源=体积约束，cw=0 或轻件时薄壁处可能偏小——打磨方向：按材料设 f 下限，或 cw 为空时 UI 更强提示（现状仅有灰字提示）。
2. **颈径/冒口径无合理区间提示**：实测球顶柱 Mc15 颈径比达 61%（业内常见 40~60% 内可接受，但代码不设上限、超界无警告）。
3. **热节圆 d 输入口径（d/2=等效板厚）** 与部分现场用户预期的 d/4（圆棒）不同——建议 UI 微文案点明「d 按等效板厚理解」（56 §四.5 记录过，尚未落地到输入 hint）。
4. **体积校核=单冒口整体件简化**：feeding-zone 说明已在结果区，但入口 A 的自动建议对多热节件只按最大热结出一个冒口——与 gating/chill 的联动结论需在报告/产品层明确「多热节分别校核」边界。
5. **设计中心固定形状/效率不可调**（球顶柱 hd1.0 eff25）vs 独立工具完整可调——两入口结果在特殊形状需求下会不同，产品语义上建议写明「中心建议=默认形状」，或开放形状选择。

**不建议动（稳定且已双源验证）**
- 效率 14/20/25/35、缩率、颈系数四表（56 已全区间验证，再调需重走核验）
- 迭代取整 round+1% 容差、50 轮封顶（80 组收敛实验锁定）
- ρ 固态密度表（28.7-A 人工批准，勿与 gating 液态值合并）

## 六、结论

冒口工具 = **「模数放大 + 体积补缩」双轨迭代的经典冒口设计法**（Wlodawer 体系教材化），全参数有出处、C 类经验参数经双源核验全部落权威区间、门禁纪律完整、冻结后零逻辑漂移（测试链锁死）。算法层无需要修的"错误"；值得打磨的是**边界语义呈现**（f 起步材料因子、d 口径文案、颈比提示、多热节边界、两入口一致性）——均属显示/提示/策略层，不触碰冻结数值。
