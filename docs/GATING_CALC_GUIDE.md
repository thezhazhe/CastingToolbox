## 一、工具现状（输入 / 计算 / 输出 / 检验全解）

### 1.1 输入（17 项）

**基本参数（9 项）**

| 字段 | 标识 | 单位 | 默认值 | 说明 |
|---|---|---|---|---|
| 材质 | mat | — | 灰铁(HT) | 5 种：灰铁/球铁/铸钢/铝合金/铜合金 → 查 ρ、f、出品率区间 |
| 单件毛重 | pw | Kg | 46.8 | 含加工余量（设计中心=blankWeightKg，STL 净重在自动参数区） |
| 一模件数 | cav | 件 | 2 | |
| 产品壁厚 | wall | mm | 37.5 | 用于 Dietert 浇注时间公式 |
| 预估出品率 | yr | % | 材料默认 y_sug | 灰铁 75、球铁 65、铸钢 58、铝 80、铜 62 |
| 浇注方向 | pos | — | 顶注 | 顶注/中注/底注 → 决定 P、fv、Hp 分支 |
| Ho | Ho | mm | 180 | 内浇道至上箱面距离 |
| 产品高度 | ph | mm | 76 | 浇注方向高度 |
| 冒口高度 | rh | mm | 171.5 | riser 结果自动回写；无冒口=0（Hp 方案 A 用） |

**比例预设（1 项）**：6 预设 + 自定义
- 封闭式：保守 1:1.5:0.8 / 常用 1:2.0:0.85 / 大件 1:2.5:0.9（阻流在内浇口）
- 开放式：标准 1:2:2 / 宽大 1:2.5:2.5 / 铝合金属 1:3:3（阻流在直浇道）
- 材质+重量智能推荐（>200kg 升档大件型）

**组元尺寸（6 项，改厚度/个数自动算长度）**：内浇道个数 gc/厚度 gt、横浇道条数 rc/厚度 rt、排气圆孔 vr/vrc、方片 vs/vst/vsc

**可选**：过滤网型号（折叠区，仅灰铁/球铁有企业过流量标准）

### 1.2 计算过程（10 步链）

```
① 查表：材质 → ρ(液态企业值) / f / y_sug        （rho 可被项目 liquidDensity USER_OVERRIDE 覆盖）
② G 浇注重量 = pw × cav ÷ (yr/100)
③ Hb 水口盆高度：G 分段查表（<10→150, <50→200, <200→250, <1000→300,
                              <3000→500, <8000→750, ≥8000→1100 mm）
④ C = ph + rh；P 值：顶注=0 / 中注=C/2 / 底注=C
⑤ Hp 平均静压头（PHASE 28.3-B 企业 Excel 原式）：
   顶注：Ho + Hb/2 − rh²/(2C)
   中注：Ho + Hb/2 − (P+rh)²/(2C)      ← 企业 Excel 原式（已批准，真实案例 100% 复现）
   底注：Ho + Hb/2 − Ho/2
⑥ fv 流速系数：顶 0.8 / 中 0.6 / 底 0.45（企业参数运算表）
⑦ t 浇注时间（Dietert）= f × (√G + ∛(wG/5)) × 2/3
⑧ A 阻流截面（奥赞）= 71.47 × G / (ρ×t×fv×√Hp) × 100
⑨ 面积分配：取比例最小值 min_r → 各参考面积 = A × (该比/min_r)；瓶颈=最小比值处
   内浇道长 L_g = round(A_gt/(gc·gt)/5)×5（min 5mm）；横浇道长 L_r（min 10mm）；
   直浇道 D = √(4A_sp/π)（1 根圆形）
⑩ 校核链 → 输出
```

### 1.3 输出（28 字段）

| 分组 | 字段 |
|---|---|
| 中间量 | rho、fc、mdFellBack（未知材料标记）、G、Cmm、Hb、Pv、Hp、fv |
| 核心结果 | t（Dietert）、A 阻流截面、cp 瓶颈位置、A_sp/A_run/A_gt 三参考面积 |
| 组元尺寸 | L_g/Fg（内浇道）、L_r/Fr_act（横浇道）、D_sp/Fs_act（直浇道）、rrv/rgv 实际比例 |
| 校核 | v/v_ok（流速）、vL（液面上升，仅参考）、vr/vr_ok（排气比）、ya（实际出品率） |
| 判定 | sugs（建议列表）、allOk = v_ok && vr_ok |

### 1.4 检验逻辑

| 检验项 | 标准 | 当前行为 |
|---|---|---|
| 内浇口流速 v=10G/(t·ρ·F/100) | 封闭≤1.5 / 开放≤1.0 m/s（企业 R7 审核标准，28.3-C 落地） | v_ok，不通过进建议 |
| 排气面积比 S出/S直 | ≥1.5 倍 | vr_ok，不通过进建议 |
| 内浇道面积 | 参考 A_gt 的 0.7~1.3 倍 | 警告 |
| 横浇道面积 | 参考 A_run 的 0.8~1.2 倍 | 警告 |
| 液面上升速度 vL=ph/t | 无企业标准，仅参考 | 不判定 |
| 过滤网（可选） | 企业过流量表（灰铁/球铁） | 超限提示+推荐型号，不自动改 |

### 1.5 设计中心接线（calcManifest）

- 输入映射：blankWeightKg→pw、cavities→cav、wallUsed→wall、pourPos→pos、Ho/ph/riserHeight→Hp 链、liquidDensity USER_OVERRIDE→rho
- **组元尺寸在设计中心硬编码**（gc=2/gt=15/rc=2/rt=25/vr=15…），独立视图才可调 ← P1 遗留
- RUN_ORDER：riser 前置 gating（Hp 方案 A 回写闭环）

### 3.2 其他条目（简表）

- 直浇道：双曲线锥形、入口面积 +20%、下落临界高度（铝 13mm/铁钢 8mm）
- 直浇道窝：作者放弃 2×2 规则（仅参考，可加警示注释）
- 转弯圆角：内角 ≥ 出口直径（~2 倍最佳）
- 横浇道：面积 = 直浇道出口 +20%（2 倍已偏大，4 倍浪费）；锥度减到 50% 厚度即可
- 浇注比：自然加压 1:1:n（n=4~10）；1:2:4 仅限直浇道 ≤200mm
- 过滤器：过流量 90% 来自流动改善而非过滤本身
- 上升速率：铝 <60mm/s 表面条纹（浇注时间反查）
- 排气：无"≥1.5"判据；出气孔 ~3mm 铁丝即可；芯头通气孔降压 5~10 倍
- 接触浇口：重叠 0.8~1.2mm（>2.5mm 难敲落）
- 薄壁压头：1mm 截面 ≥80mm（铝）/60mm（钢）压头，安全系数 2

### 3.3 ⚠️ 重要提示

书**明确否定奥赞局部阻流口**（主张整根直浇道控流），而**企业 Excel 仍在用奥赞式**——学术前沿与企业实践正面冲突。建议：**以企业体系为主（实用优先），书作校验/参考**，不因书推翻企业已验证公式。
