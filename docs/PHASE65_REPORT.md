## 3. 二十一-A：关于 1:1（原文 vs 产品化解释边界）

1. **Campbell 原文为什么 1:1**：13.4 —— 横浇道面积=直浇道出口面积，"避免了对该连接处损失的任何选择（这些损失无论如何都不精确是 20%）"；横浇道在满足流量下**尽可能小**（金属液立即充满，像活塞推空气）；弯角摩擦降速 ~20% 时只需 ×1.2。核心动机=防"面积大放大的横浇道只被高速射流填一半→射流反弹卷吸"（无压系统被否）。
2. **"摩擦/持续节流"原文含义**：13.4 原文"我们摒弃局部节流口的概念。充型系统的整个长度都应使其壁面与液态金属保持永久接触……一种连续节流原理"——指系统全长持续微加压（处处充满、排净空气），**不是**逐段算摩擦系数（11 章明言拒绝水力学损失系数累加法）；"1:1"与连续节流是配套表述，不是"1:1 即逐渐加压"。
3. **产品化解释（非原文）**：V1 结果行措辞"使流动全程存在持续的摩擦/节流作用，避免不受控高速"为任务书核准的通俗转述；"自然摩擦不能替代专门减速"为该句的工程限定（Campbell 有对应原意但说法为产品化）；V1 的"每单位 = 直浇道出口面积、n=内浇口数量、隐含出口流速 n·v"是**速算器约定**（把 1:1:n 的 n 与内浇口数量绑定、S_sprue=A/n）——原文 1:1:n 的 n 是减速倍率/数量区间（4~10、带过滤器 1:1:4），V1 简化已在知识卡与结果备注中明示"速算 V1 约定"。
