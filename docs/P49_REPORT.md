## 第一部分：已修改内容（4 项）

### 1. P47 浇注时间公式的 W 定义修正（最重要）

**问题**：W 误用了"浇注重量 G = 铸件重量×型腔数÷出品率"。

**修正**：重量变量职责分离，禁止同一变量承担两个物理定义：

```
castingMass (W_c)   = 单件铸件重量 × 型腔数    → P47 浇注时间公式的 W（不出品率）
pouringMetalMass G  = W_c ÷ 出品率             → 奥赞阻流面积 / 流量 Q / A_target / v_final 全部下游
```

- 灰铁 450kg 分档改按 **castingMass**（W≤450 用 √W 式、W>450 用 ∛W 式）；球铁 K₁ 分档仍按壁厚
- 与企业 Excel 口径对齐：Excel 理论时间用"毛重×件数"（案例 93.6kg），阻流/查表/流速用"浇注重量"（120.22kg）——我们此前统一用浇注重量是偏差，现已修正
- 效果：t 与出品率彻底解耦；t 系统性变小 ~13%（√出品率）→ 奥赞面积相应增大（∝1/t）

### 2. 经验公式分界点工程提示（保留分段，不插值）

| 触发 | 提示 |
|---|---|
| 灰铁 \|W_c−450\|≤22.5kg | "接近灰铁 450kg 分界点（±5%），请工程复核" |
| 球铁 \|壁厚−10\|≤1mm 或 \|壁厚−25\|≤1mm | "接近 K₁ 分档点（10/25mm ±1mm），请工程复核" |

UI 黄色行提示，不消除跳变。

### 3. 内浇口长度取整 round → ceil

目标面积驱动的尺寸不得因 round 使实际面积不足（原最坏 F/参考=0.73，流速被顶高 +36%）；圆形原即 ceil。未加硬性上限。

### 4. 报告表述修正

删除"放大内浇口后实际浇注时间必然变长"的一般性结论，改为：**增大内浇口面积主要用于降低内浇口处平均流速；只要阻流截面仍控制系统流量，它并不自动改变名义流量与浇注时间**（一阶口径）。

## 第三部分：内浇口速度学术审计（只研究不改，结论见文末）

### 8.1 v = Q/A 是否合理？—— 合理，属一阶名义口径

v_gate = Q/A_gate = (G/ρt)/A_gate：全充型周期、全部内浇口上的**体积平均流速**。
适用条件：流量近似恒定、多口同时进流、忽略局部收缩（一阶假设）。单位 m/s 验证闭合
（与企业 Excel K16 公式同形）。与"局部/瞬时速度"（口内中心射流、型腔液面前沿）不是同一量。

### 8.2 G 用什么？—— castingMass 给时间公式、pouringMetalMass 给流量（P49 已实施）

教材与企业实践均是双口径：时间公式回归对象是铸件质量；流量/面积公式对象是实际浇入型腔的总金属。
企业 Excel：理论时间 K11 用毛重×件数，阻流/查表/流速用浇注重量 K22。**本项已闭环，无需再议。**

### 8.3 t 用什么？—— 浇注时间（pour time），名义口径可用

一阶 Q=G/(ρt) 中 t = 从开浇到充满的总浇注时间（P47 经验公式回归对象）。注意与"型腔充型时间"
的秒级差异（浇道系统填充时间），一阶设计通常不区分；因此 v_final 是**名义平均流速**。

### 8.4 ρ 用什么？—— 液态密度（当前 7.0/6.9/7.5/2.6/8.4，企业值）正确

流量/体积计算需要浇注温度下的液态密度；固态密度（球铁 7.1）归补缩/模数模块（28.7-A 双表已定稿）。
温度修正 ±1~2% 一阶忽略可接受。

### 8.5 A_gate 用什么？—— 内浇口几何总面积（当前正确）

差异两点：①几何面积 vs 有效流通面积（边界层/表面膜，一阶忽略）；②多口同时进流假设
（远端口滞后 ⇒ 单口瞬时速度高于平均）。若未来做"防卷气严格校核"需加不均系数——属 RE-DESIGN 选项。

### 9. Campbell "critical velocity" 到底是什么？（核心）

**原文要点**（Campbell 翻译版摘录）：
1. 定义（第 2 章，式 2.3）：临界速度 V_crit = 2(γg/ρ)^(1/4)，**表面湍流（碎波、表面卷吸）开始的流速**；
2. 物理场景（图 2.18）：**"金属液通过垂直内浇口上升进入铸型"**——零速安全、临界速由表面张力支撑
   （座滴）、更高速呈射流并卷折表面。→ **针对内浇口出口的液流/液面前沿行为**；
3. 数值表（Runyoro 1992 实验）：Ti 0.50 / **Al 0.50** / Mg 0.42 / **Fe 0.45** / Ni 0.43 / Cu 0.40 / Zn 0.37…
   → **0.5 m/s 不是普适常数，是按材料（ρ、γ）计算的值**；
4. 设计引用（第 5.1.5 节）："进入铸型的初始速度控制在约 **0.5 m/s** 以下，**以避免通过内浇口产生喷射**"；
5. 膜类型分级（图 2.51）：无膜/液态膜（可球化浮出，如脱氧钢低熔点氧化物）/部分固态/完全固态脆膜
   （Al₂O₃ 类最危险）。铸铁表面膜为硅酸盐类——铁基对表面湍流损伤敏感度整体低于铝系，但 Campbell
   未给"铸铁可放宽至 1.0"的数值依据。

**与 v_gate 的关系判定**：
| | Campbell 临界速度 | CT v_gate |
|---|---|---|
| 位置 | 内浇口出口液面前沿（瞬时） | 全周期平均（Q/A） |
| 性质 | 材料量（Fe 0.45/Al 0.50） | 名义平均 |
| 结论 | — | 平均≤临界 ⇒ 保守安全；平均>临界 ⇒ 只能提示复核，不能判缺陷 |

**裁决：只能间接参考（保守方向可直接用），不能直接等同。**

### 10-11. 目标速度表文献依据分级

| 目标 | 值 | 分级 |
|---|---|---|

### 12. R7 = 1.5 m/s 的性质

企业审核红线（无缺陷工艺审核 B7/C7，内浇口流速，变径前），与 Campbell 临界是**两个层级**：
R7=流程管理上限（宽于物理临界 2~3 倍）；Campbell=物理卷气起点（0.45~0.5 量级）。48-B 已把 R7 降为提示
（r7Exceed），层级分工与审计结论一致，保留不删。

### 13. v_theory = fv·√(2gHp)

来源：奥赞体系推导（Excel 22.6/71.47 溯源闭合）；fv=企业速度系数（顶 0.8/中 0.6/底 0.45+过滤网−0.1）；
Hp=企业平均静压头。它是**阻流处理论流速**（未放大时的内浇口参考面），与 v_gate **不在同一参考面、
不能直接比较**——48-B 已定位为"内部诊断值"保留，正确；它同时是放大机制的反推基准
（v_theory>目标 ⇔ 需要放大）。

### 14. 1:2:0.85 审计（只审计不改）

- 含义：S直:S横:S内 **面积比**（三段 = 奥赞 A_choke×比值/最小比值，最小者=阻流）
- 封闭式（0.85 最小）⇒ 阻流=内浇口（与 Excel K23=IF(封闭式,内浇道总面积,直浇道) 一致）
- 0.85 来源：落在企业审核表 C5「（封闭）1:1.5~2:0.8~0.95」区间内 ✓；横浇道 2 落在 1.5~2 上沿 ✓
  ——**有企业依据，非纯历史遗留**（企业另有"含瓷管变径四段式"文本表述，工具未建模变径段，属简化非错误）
- 作为 P48-B baseline：合适（A_gt 阻流参考 = 放大前基准，"只放大不缩小"语义自洽）

round 曾致实际面积 < 目标（最坏 F/A=0.73）；**已修复为 ceil**（49-W5 测试锁定 Fg≥A_rec）。

## 审计总结论：**KEEP**（附文案澄清建议，本阶段不执行）

- 公式/变量/单位全部验证正确（一阶名义口径）；48-B 机制与 Campbell"内浇口控速"用途同向；
- 球铁/铝 0.45 有材料临界速度的保守量级支持；灰铁 1.0 属工程经验（建议确认取值版本）；

## 最关键发现（一句话版）

Campbell 临界速度是按材料计算的表面湍流阈值（**Fe 0.45 / Al 0.50 m/s**，式 2.3），针对金属液经
内浇口进入型腔的自由表面行为；工具 v_gate 是全周期平均名义流速——**平均口径达标可保守判安全，
超标只能提示复核**；灰铁 1.0 超出 Fe 临界 2 倍，属"铁基膜损伤敏感度低"的工程经验范畴，
与球铁/铝 0.45 系列依据层级不同，应分别对待。
