## 3. 铁律（历史踩坑换来的）

1. **证据分级**：LEVEL A（官方标准正文）/ B（高可信交叉验证：ISO 对应标准、
   独立多来源一致、行业权威；**不允许因缺官方 PDF 使工具失效**）/
   C（行业经验 → 必须标注"工程经验参考"，绝不伪装成"标准强制"）/
   D（来源冲突 → **不猜、不改**，保留工作值 + 标 UNCERTAIN）。
2. **报告三态**：VERIFIED / ENGINEERING REFERENCE / UNCERTAIN，逐项标清。
3. **UI 诚实标注**：绝不写"已直接核对 GB/T 42124.3-2025 官方全文"这类没做的事；
   宁说"经独立公开资料交叉核验"或"条文状态未独立确认"。
4. **回归纪律**（用户指示）：只跑计算器套件，**跳过 STL/engine 测试**
   （真实 STL 慢 ~5 分钟）；过滤串见 §1。全量 240 项在 28 系列时代，现基线口径是
   过滤回归 188/0。
5. **改动红线**：未经批准不改公式/密度/企业参数/冻结模块；"另一篇文章数值不同"
   不是改的理由（先判版本代际 vs 抄错 vs 来源冲突，61/62 经验）。
6. 先理解影响范围再改；不为小问题重构；对照测试用非对称模型。
7. 旧标准被代替后数值可能换代微调（0.02mm 级）——逐格核验必须全表 + 结构不变量，
   不能只查常用段。
