## 3. §四/§五 Product↔Gating 连接区域

**不命名**，统一叫 flow connection（§五）。

```
对每个 gating 三角形质心，量它到产品表面的最近距离（meshDistance.distanceToMesh）
  → 距离 ≤ tol 的三角形，按**浇注系统内部邻接**聚成连通区域
  → 每个区域 = 一个 candidate gate
```

**为什么按邻接聚合而不是空间聚类**：空间聚类会把交汇处挨得很近的两条流道并成一个口。

### tolerance（§四：与尺度相关 + 有上限 + 可在诊断显示 + 不能无限扩大）

| | |
|---|---|
| 主判据 | `clamp(产品包围盒对角线 × 0.004, 0.05mm, **5mm**)` |
| 放宽 | 主判据一无所获时放宽一次（×2，仍受 10mm 封顶），**并在 diagnostics 与 UI 上如实报出** |
| 显示 | 结果区诊断块："连接判据 0.90 mm"；用过放宽值时额外显示"实际用了放宽值" |

**分离轴预筛**：先判 gating 三角形的 AABB 与产品包围盒在任一轴上是否分得比 tol 还开，
是则必然不近接，直接跳过昂贵的逐格查询。这个下界是严格的，不会漏判。
**实测：一份 10916 面的浇注系统，连接检测 8288ms → 584ms（14×）。**

### 起始方向（§六：从 Product 指向 Gating 内部）

1. **首选**：指向本浇注系统连通分量的质心（一条减法，最稳）
2. 退化时（连接口正好在分量质心附近）回落到 **−面积加权法向**
3. **再退化就不给方向、报 WARNING**，不硬算（§十三）

## 4. §六/§七/§八 单路径截面追踪

### 核心循环

```
P ← 起点，D ← 起始方向
每一步：
  1. 在 Q = P + h·D 处、以 D 为法向切一刀（**只切本连通分量**）
  2. 挑离预测点最近的那个闭合环
  3. 记录 {distance, area, centroid, direction, confidence}
  4. 方向更新：D ← 单位向量(本刀形心 − 上刀形心)     ← §十二「相邻截面中心变化」
  5. 收敛不了就停（§十二：不稳就明说，不硬算）
```

步长 `h = clamp(上刀等效半径 × 0.6, 0.4mm, 8mm)` —— 截面大就步子大，弯曲处又不会跨过头。

### ★ 与 PHASE 89 最大的不同：一刀不合规**不再**判整条路径死刑

§七 明说："不要因为某一个截面不满足非常苛刻的条件，就直接让整条路径：无法可靠计算。"

所以：

| 情况 | PHASE 90 的做法 |
|---|---|
| 这一刀切不到闭合环 | 先试**相邻位置**（同向 / 半程 / 1.6 倍），仍不成只标该 sample `no_loop` 并继续 |
| 切到多个环且离预测点差不多近 | 标 `ambiguous`（不猜），继续 |
| 环的形心离预测点太远 | 标 `off_axis`，继续 |
| 该刀存在未闭合环 | 记 low confidence，**仍然采信**（§七 不苛刻） |
| 连续 3 刀完全切不到 | 才认定**流道到头**，正常收工 |

**无效样本必须带原因**（测试 90-I 强制），且 `area` 必须是 `null`（测试 90-N 强制）。

### §八 输出：不追求"最小有效截面积"这个严格判定

改成优先输出四项：

```
最小测得截面积  最小截面积位置  截面积-距离序列  有效采样率
```

**只有当有效样本 < 3 时**才说"截面积不足以计算"。

### ★ 端面伪影（实测踩到）

流道到头时，**最后一刀切到的是端面（含 MC 倒角），不是流道截面**。
实测：⌀20 直管沿程全是 312，最后一片报 **267**（真值 314）—— 那个数会让整条结论失真。

处理：**只把它从 headline 的最小/最大值统计里摘出去**，
序列里仍然保留并标 `terminal: true`（§十三：不掩盖，只如实标注）。

### ★ 起步方向校正（实测踩到）

初始方向只保证"从产品指向浇注系统内部"，**不保证是局部流向**。
实测某浇注系统：内浇口在 x=−45、而整个浇注系统质心在中央，
于是粗估方向偏离管子轴线 **41°**，头两刀成了斜切、面积虚高（258 / 264，真值 201）。

处理：拿第一刀的**截面形心**反推一次局部流向（只多切一刀），随后自动收敛。
实测首刀从 258 → **197**（解析 201，−2%）。

## 5. §九 截面积突变

最朴素的变化检测，没有机器学习、没有黑箱阈值（全部集中在 `FLOW_CONFIG`）：

```
前后各取 2 个有效样本的中位数 → ratio = 后/前
ratio ≥ 1.6（或 ≤ 1/1.6）才算候选
```

### ★ 光看比值会被单个噪声点骗过去（实测踩到）

序列 `[100,100,100,900,100,100,100,100]`：尖峰把只有 2 个样本的前窗中位数
从 100 拽到 500，于是在尖峰右侧比出 0.2，**被误判成一次收缩**。

修正：加一道"两个窗口必须真的分开"的检查 ——
涨的时候后窗**最小值**要显著高于前窗**最大值**（阈值取 √ratio），跌的时候反过来。
§九 的"考虑连续几个 sample，避免单个噪声点触发"落在这里。

实测：阶梯管 ⌀20→⌀30 检出 1 处扩张，ratio **2.26**（解析 2.25），位置落在变径面附近。

## 6. §十 分叉：两条判据

### 判据①：截面闭合环数 1 → ≥2（§十 字面）

**两环必须既分得开、又挨得近**（一个区间，不是单边阈值）：

```
(r1+r2) × 0.6  ≤  两环形心距  ≤  (r1+r2) × 2.0
   太近 → 同一条流道被网格噪声切成两半
   太远 → ★切面顺带切到了旁边另一条互不相干的流道
```

**上界是实测补的**：一个两条并排内浇口的浇注系统（相距 90mm、各 ⌀16），
追踪从其中一条转向竖直后切面把另一条也带了进来，**曾被误判成分叉**。
回归守卫见测试 `90-C4`。

### 判据②：交汇处（覆盖 §十 字面规则够不到的垂直 T 型）

**为什么需要它**：垂直 T 型交汇处，沿原方向切**永远只有 1 个闭合环** ——
切到的其实是横向通道的纵剖面（一块板），故判据①永远不触发。

三条同时成立才算：

1. 截面在平面内被横向拉长（长宽比 ≥ 2.0）—— 板状
2. 面积比上一刀涨了 ≥ 1.5 倍
3. ★ **沿原方向继续走，这种板状在半个横向跨度内就消失**

第 3 条是决定性的：

```
真·交汇处 → 横通道在纵向只有那么厚，穿过去就没了（实测 T 型夹具里板状撑了 19mm 就没）
均匀件突然变宽 → 板状会一直维持下去（不判交汇）
```

再加一道几何验证：**只有沿 ±横向两个方向都能找到干净的单一闭合环**才算数。
单纯变宽时往横向切到的是纵剖面（切不到环或不闭合），两个方向都会失败。

### ★ 支路起点必须取**截面形心**，不能取探针位置（实测踩到）

实测：探针落在 (x, 37, 0) 而横浇道轴线在 y=40 —— 用探针位置当起点等于让支路
从偏轴 3.8mm 处出发，起步校正随即把方向拧了 29°，那个斜切面一路伸进旁边的直浇道，
**切出 1782mm² 的假截面（真值 707）**。改用形心起步，方向自然落在管轴上。

## 7. §十一/§十二 底层数据结构与主方向

底层**只认**（§十一）：

```
FlowConnection  →  FlowSegment  →  FlowBranch  →  FlowSegment  →  …
```

`sprue / runner / ingate` **不作为底层算法的前提**，只在最后贴标签（§十二）。

早先把它们混用，UI 上出现过"这一段写着'在此分出支路'、总览却写'分叉 0'"的自相矛盾。

主方向来自**相邻截面形心位移**（§十二 的「相邻截面中心变化」），
转角 > 75° 记一次"不稳"，累计 3 次就明说方向不稳并收工，不硬算。

三条工程约束（都踩过或明确规避）：

## 14. 已知局限

### 14.1 交汇处判据依赖切面方向，**斜交 T 可能漏判**（主要局限）

判据② 的支路探针沿切面内的横向 `±majorDir` 走。当**入流方向与横向通道明显不垂直**时，
切面本身是斜的，探针可能落空 → 那一侧找不到干净截面 → `arms.length < 2` → **该处不判分叉**，
该段以"流道到头"结束。

**实测**：一个「中央直浇道 + 横浇道 + 两端内浇口」的浇注系统，
一条内浇口成功判出交汇并展开 2 条支路（都正确追踪到真实流道）；
另一条（镜像位置）因该处方向偏了 20° 而没有判出，以"流道到头"收工。

**它是诚实降级，不是错误输出**：漏判时给的是"流道到头"+ 已有的截面积序列，
不会编一个不存在的分叉。对称 T 稳定（`90-C` 全过）。

### 14.2 圆头末端会让倒数第二刀偏小

端面伪影只排除**最后一刀**。若流道末端是球冠/大圆角，倒数第二刀也可能偏小
（实测 Y 型 45° 斜臂末端 168 vs 沿程 199，−16%）。
序列里看得见（`最小位置` 会显示在段末附近），但 headline 的最小值会偏低。

### 14.3 分叉后不切分三角形子集

子段仍在整个连通分量上切片。正常情况靠"挑离预测点最近的环"处理，
但交汇处几何占比大时，切面可能同时切到别的流道（`isFork` 的上界挡住大部分，
但它是阈值判断，不是拓扑判断）。

### 14.4 其余沿用 PHASE 85~89 的未决项（本阶段只报告不处理，§二十）

Hotspot 真值套件 9/20 的位置定义问题、clean mesh fixture、geometrySource 技术债、
非核心页面英文覆盖、新的物理模型 / 凝固模拟 / 缩孔预测。

## 15. 与 PHASE 89 的差异

| | PHASE 89 | PHASE 90 |
|---|---|---|
| 入口 | 用户点选入口面（或自动取最上端） | **全自动**：找产品连接区域 |
| 追踪方向 | topmost → 向内 | **Product → connection → 向外** |
| 核心方法 | 测地距离场 + 波前分叉 + 递归分段 | **单向推进 + 逐刀独立判定** |
| 主方向 | 窗口重心的最长连续共线段 | **相邻截面形心位移** |
| 分叉 | 波前壳层连通分量数 | **截面闭合环数**（+ 交汇板状判据）|
| 失败处理 | 四道闸门，一刀不合规整段作废 | **只标该 sample 无效，继续走** |
| 默认状态 | 大量"无法可靠计算" | **给出面积-距离曲线；只有数据完全不足才说算不出** |
| 输出 | 直浇道/横浇道/内浇口三张卡片 | **先几何事实（连接数/流道数/分叉数/面积序列），语义只是辅助标签** |
| 底层数据结构 | segment 带 sprue/runner/ingate 语义 | **connection → segment → branch，无语义** |

## 16. 是否达到下一阶段可用状态

### 判据

§二十二 定的成功标准是：

> 对一个普通浇注系统 STL，程序能够从产品连接处出发，自动找到流道，
> 并给出**连续、可解释的截面积-距离数据**。
> 只要做到：产品连接在哪里 / 从哪里开始 / 沿哪个方向 / 截面积是多少 /
> 哪里发生明显变化 / 哪里发生分叉 —— 这套基础能力可靠。

逐条对照：

| 要求 | 状态 | 证据 |
|---|---|---|
| 产品连接在哪里 | ✅ | §3；浏览器实测自动找到 2 个连接口 |
| 从哪里开始 | ✅ | 连接区域形心，实测落在管轴上 |
| 沿哪个方向 | ✅ | 相邻截面形心位移；不稳就明说不硬算 |
| 截面积是多少 | ✅ | 圆/方/椭/锥/阶梯全部对解析值，误差 0.09%~1.7% |
| 哪里发生明显变化 | ✅ | 突变检测，阶梯管 ratio 2.26 vs 解析 2.25 |
| 哪里发生分叉 | ⚠️ | 对称 T / Y 型稳定；**斜交 T 可能漏判**（§14.1，诚实降级）|

| 硬约束 | 状态 |
|---|---|
| §十九 `js/engine/` 不修改 | ✅ 零改动 |
| §十九 Hotspot V3 冻结 | ✅ 不退化 |
| §十九 Design Center 不变化 | ✅ |
| §十八 几何真值测试 | ✅ 22 项全过，全部对解析值 |
| §二十 不扩大范围 | ✅ 冷铁/凝固动画/CFD/新热点算法/V4 一项没碰 |

### 结论

> ## **PHASE 90 达到下一阶段可用状态。**

§二十二 的六条基础能力里五条完全达标，**"哪里发生分叉"在斜交 T 上会漏判**，
但漏判时给的是"流道到头"而不是错数（§十三）。

§二十 的立场——**几何事实 > 算法复杂度 > 工程命名 > UI 美观**——已经落地：
底层数据结构里没有 sprue/runner/ingate，工艺语义只是最后贴的辅助标签，
几何不支持时写"几何通道"。

**本阶段不自行进入 PHASE 91。**
