## 四、实施的修改清单

### P1
1. **shakeout（calc+data+view）**：风险"易裂"拆为「冷裂/变形敏感」×1.15（低温开箱+缓冷警告）与「热裂敏感(红热打箱)」×1.0——仅铜合金触发 800~900℃ 特例（文献配套条件写进警告）；其余材质不自动给高温值（人工确认+机理警告，铝补 660℃ 熔点提示）；铸钢 warn"热裂"改"冷裂/变形"语义；灰铁 warn 与实际 ≤200 一致；自定义温度不再被特例静默覆盖（目标框在特例下禁用+说明）；>100t 空态文案修正；大件时间不再显示伪区间 "10.0~10.0 h"；risk 变化触发目标框重填。
2. **charge（view+data）**："铁液总重=目标出炉铁液量"字段提示+说明区条款（实投>总重=炉损、成分按出炉铁液计）；P/S 超差单独警示（不再被"✅ 无需补料"掩盖）；CE 行按灰铁=成铁/球铁=成铁(含处理带入 Si)口径对照、HT150 类不自洽给警示行（数值不自动改）；回炉料吸收率 0.95 常量归位数据层 `CHARGE_RET_ABS`；头部"confidence 标注"虚假声明改正。
3. **CT（data+view+registry+知识卡）**：标准引用全链更新为 GB/T 42124.3-2025（官方全称/实施日/代替关系/采标关系，镜像批1 machining 口径），等级沿革（CT1~16→DCTG1~16→现行 DCTG1~15+DCTG15wt）入注记；标注示例 `−0.8` 硬编码 bug 修复（对称 ±half 计算值）；自适应小数精度（0.09/±0.045 不再截成 0.1/±0）；空值归因三分（超表/≤16mm/大尺寸低精度）；CT16+壁厚 越界提示改"现行体系壁厚用 DCTG15wt"；方法×材质推荐表改"工程推荐口径"标注；≤16mm 规则如实标注来源（1999 表注）与未核验状态；**CT_TABLE 数值与 CT_GRADES 结构零改动**。

### P2
4. **sandbox（calc+data+view）**：表5 上限 4000 落地（>4000 → 不静默给值+告警）；三概念（可制造/结构下限 vs 非承重设计值 vs 承重查表）UI 分层说明+行提示区分；表3"组合空洞"与"真超表"告警文案分离（保守取值逻辑不变）；裸浇压头低于铸件高时负中间值不再裸显示+口径说明；**表值零改动**。
5. **castability（calc+view）**：SIZE_BUCKET 标签改单值口径；>1000mm 起模高度超表标记（末档仅参考）；分档简化披露（手册四档→工具三档）；圆角下限（2/3mm）行内提示+说明区；拔模文案按 金属/木模 双列准确范围重写+上限条款（不超过表值一倍；压实比>700kPa +≤50%）；临界壁厚/铸孔"1°~4°"补"工程经验参考"（去 JB/T 错误挂靠）；**数值零改动**。
6. **defect_finder（view+2 知识卡）**：可信度图例改诚实语义（人工分级、均出版物整理、非一手/官方）；列表出处显示补章节；air_hole/slag_inclusion 卡 0.5m/s 判语补材质限定（铝/球铁口径，灰铁按 gating ≤1.0）；GB/T 5611 补年份 2017。
7. **标准引用横扫（知识层）**：`process/ct_tolerance.json`（曾引 1999！）、`process/inspection_dimension.json`、`process/machining_grade.json`（曾引 1999 A~H）、`scenarios.js`×5、`registry.js` ct 条目 → 全部更新为 42124.3-2025 现行表述（含 machining_grade 补 J/K 十级与现行值）。
