## 3. 三档选择理由（§四 D/F、§五）

**静态预测**（`stride = ceil(gs / cbrt(R))`，thickEnd 的 8 个 refine 区 refGs ∈ {45,31,23,21,20,16}）：

| refGs | R=8000 | R=32000 | R=128000 |
|---|---|---|---|
| **45**（主区） | 3 | 2 | **1** |
| 31 / 23 / 21 | 2 | 1 | 1 |
| 20 / 16 | 1 | 1 | 1 |

- **LOW = 8000**：当前默认（§五 强制包含）✓
- **MID = 32000**：主区 3→2，另 5 个区 2→1 ✓
- **HIGH = 128000**：主区 2→1，**全部 8 区 stride = 1** ✓

**§四 F —— 128000 是否有实际意义？有。**
主区（refGs=45）要降到 stride=1 需 `R ≥ 45³ = 91125`。
`32000 < 91125` → MID 时主区仍为 stride 2；**`128000` 是能令最大区域触底的档位**。
且 128000 之后无法更细 —— **spacing 地板 = `vs` = 4.792 mm**（`vs` 是体素尺寸，refine 只能采样不能细分）。

### ★★ 为什么 Mc 不变 —— 机理（本次最重要的产出）

**全部 8 个 refine 区的 `refField.maxM` 三档逐位相同**：

```
R=  8000  [9.6181, 9.6181, 6.2847, 6.2847, 6.2847, 6.2847, 6.4540, 6.2847]
R= 32000  [9.6181, 9.6181, 6.2847, 6.2847, 6.2847, 6.2847, 6.4540, 6.2847]
R=128000  [9.6181, 9.6181, 6.2847, 6.2847, 6.2847, 6.2847, 6.4540, 6.2847]
```

**但同一批区域的 `peaks` 列表变了**：

```
R=  8000   [0] peaks M = [9.6181, 6.2847]
R= 32000   [0] peaks M = [9.6181, 6.4236, 6.2847]     ← 更密的采样多找到一个局部极大
           [1] peaks M = [9.6181, 5.5903]             ← 同上
R=128000   [0] peaks M = [9.6181, 6.4236, 6.2847]
           [1] peaks M = [9.6181, 5.5903]
```

**⇒ 采样确实生效（多找到局部极大），但场值本身一位没变。**

**代码级原因（`hotspotV3.js:115-118`）**：

```js
// M 场统一用全局网格（coarse.vox）：块边界 = 模型表面……
//   细化只提供更密的采样点（stride 1）与 char。
const refField = buildModulusField(coarse.vox, ref, o, 1.0);
```

**M 场的 V/A 在 `coarse.vox`（全局体素网格）上计算；refine 阶段只改变"在哪些点去读这个场"。**

**⇒ `refineMaxPoints` 是"场的采样密度"旋钮，不是"场分辨率"旋钮。**
**Mc 由场分辨率决定，而场分辨率 = coarse 体素尺寸 `vs`。**

**⇒ 这同时解释了 05C**：`experimentalGs` 之所以能改变 Mc（10.38%），
是因为它改变的是 `coarse.vox` —— **真正的场分辨率**。

**§九 A/B 区分**：
- **A. 数值采样变化：确实发生**（主区 spacing 14.375 → 4.792，点数 ×21）
- **B. hotspot detection / peak selection 变化：局部极大集合变化了**（peaks 列表多出项），
  但**主峰（最大值 9.6181）未被取代** → Mc 不变。**代表点位置变了**（H1 漂 13.7 mm）。

## 14. 判定

# PARTIAL

**采样轴成立（§13 全部条件满足），但它对 Mc 零响应** —— 正是 §十二 B 所列的
"**Mc 不表现出明显收敛趋势**"。

**注意：这不是"轴坏了"，而是"轴选错了对象"。** `refineMaxPoints` 控制的是
**场的采样密度**；Mc 由**场分辨率**（coarse `vs`）决定。二者已被本次实验**分离**。

**§十二 B 指定的后续动作是"先分析 hotspot detection 问题"** ——
本次分析表明**问题不在 hotspot detection**（数量恒 2、主区可追踪、H2 逐位不变），
而在**轴与量的对应关系**。据此给出 §15 的建议。

## 附：顺带纠正 05C 的一项表述

05C 报告写"`experimentalGs` 扫错了轴"。**更准确的说法是**：
`experimentalGs` 扫的是**对的**轴（场分辨率 = coarse `vs`），
但它**同时把 refine 采样搞粗了**（`stride` 随 `gs` 增长），形成混淆。
05D 恰好提供了**消除这个混淆的工具** —— 见下。
