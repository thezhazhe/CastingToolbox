### 2.10 ★ 残留非单调：**不是 C′ 引入的**，且 C′ 使其减少

**逐例证据**（每个"回退点"都把修复前同点的值列出来）：

```

cyl hd=1.0 cw=20：mc=4.36  C′: D 93→92 |  修复前同点 D=92  ⇒ 两版同值（非 C′ 引入）
sphere_head hd=0.8 cw=0：mc=0.60 C′: D 5→4 | 修复前同点 D=4 ⇒ 两版同值（非 C′ 引入）
```

**两个可分离的成因**【解析 + 实测】：

1. **`hd ≠ 1` 时的"独立取整冲突"**：`D = round(raw)` 与 `H = round(raw·hd)` 从**同一个 raw 独立取整**，
   当 `hd≠1` 时两者可能落到"倒霉组合"（如 `d` 进位而 `h` 舍去）⇒ 该档不满足判据 ⇒ C′ 只把 `d` 加 1 而
   `h` 由新 `d` 重算 ⇒ **D 比前一个 Mc 点更小**。这是**取整口径的既有性质**，两版都有。
2. **体积区的 `f` 步长量化**：`cw > 0` 时 `f` 以 0.05 步进，`Mc` 以 0.01 步进；`Mc·f` 的乘积会产生
   非单调微扰 ⇒ `round(6·Mc·f)` 摆动 1~数 mm。**该区 C′ 是恒等变换**（§6.2：D 有变 0 点）⇒ 全属既有行为。

**幅度**：`cw=0` 时残留回退恒为 **1mm**；`cw=77.56` 时最大 **5mm**（`cyl hd=0.5 mc=11.61 186→181`，既有）。

### 5.3 为什么抬高上限不是解 —— 解析 + 实测【解析】

夹具：`cw=77.56kg` 球铁 `cyl hd=1` ⇒ `Vc = 10,923,944 mm³`，需补缩 `327,718 mm³`，`eff = 14%`。
`Vr = πD³/4` ⇒ **体积所需 `D_req = ∛(needVol / eff / (π/4)) = 143.91 mm`（与 Mc 无关）**。
【实测·脚本】N=800 时 D 恰饱和在 **144** ✓ —— 解析与实测吻合。

模数路径 `D ≈ 6·Mc·f` ⇒ **`f_req = D_req / (6·Mc) ∝ 1/Mc`**：

| Mc | f_req | 需要的 N |
|---|---|---|
| 0.5 | 47.97 | **939** |
| 1 | 23.99 | **459** |
| 3 | 8.00 | **139** |
| 5 | 4.80 | **75** |
| 8 | 3.00 | 39（现行够） |
| 20 | 1.20 | 3（现行够） |

**⇒ `f_req` 在 `Mc → 0` 时**发散**。抬高上限对小 Mc 永远不够** ——
这不是"上限设小了"，而是**"体积约束在当前冒口形状下无解"在搜索空间里换了个说法**。

### 5.5 ★「算法声明的约束未满足」≠「真实铸件必然失败」（125.txt §三.7）

| | 含义 | 本项目的对应 |

**【实测·脚本】退出码泄漏（探针 `out/phasev2014_exitcode_proof.log`）：**

```
$ node --input-type=module -e "await import('.../tests/hotspot_v2_test.mjs'); console.log('exitCode =', process.exitCode)"
结果：41 通过 / 1 失败
导入完成后 process.exitCode = 1 （runner 若此时无失败会以此码退出）
该进程真实退出码 EXIT=1
```

**`runner.mjs` 只在有失败时 `process.exit(1)`，成功路径从不显式置 0**

**这是既有事实（V2.0-09 已记录），本阶段复现并定案。**
