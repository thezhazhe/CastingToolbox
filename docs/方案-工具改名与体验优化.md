# 方案：工具改名 + 体验优化（v1.17 讨论稿）

> 用户反馈：「铸件结构工艺性」名字很多人不明白；「相邻两壁厚度均值」看不懂。
> 本方案只给建议与影响面，**本轮不改名**，确认后再执行。

## 一、为什么要改名

- 「结构工艺性」是铸件设计工程师的术语，但铸造车间/采购/工艺员常不熟——名字没说出"这是干什么的"。
- 工具本质是：**输入铸件尺寸参数 → 给出设计合不合理的参考（壁厚/圆角/拔模/铸孔）**，偏"检查/校核"。

## 二、候选名字

| 候选 | 通俗度 | 建议 |
|---|---|---|
| **铸件设计检查** | ⭐⭐⭐ | 最直白，一眼懂"查设计合不合法" |
| **可铸造性检查** | ⭐⭐ | 工程常用语 castability，比现名好懂 |
| **铸件结构检查** | ⭐⭐⭐ | 直白，但"结构"略抽象 |
| 铸件工艺性审查 | ⭐ | 仍带"工艺性"，改得不够 |

**推荐**：「铸件设计检查」（如用户嫌俗可换"可铸造性检查"）。

## 三、影响面（改动清单，确认后执行）

1. `calcs/registry.js`：name 字段
2. `js/views/calculators.js`：DEDICATED_VIEWS key 保持 `castability` 不变（内部 id 不改）
3. 首页 tool-card 自动取 registry.name → 无需另改
4. 搜索 `#/search`：工具名/关键词匹配自动生效
5. `scripts/browser_test.mjs`：castability 断言 title 断言处改
6. `scripts/screenshot.mjs`：截图标题 03b 改
7. `data/tags.js` / 知识卡 castability_design：keywords 里"结构工艺性"可加新名
8. README：工具表

## 四、本轮已完成的体验/数据优化（不等改名）

| 项 | 改动 |
|---|---|
| 相邻两壁厚度均值 | 标签改「相连两壁的厚度均值（算圆角）」+ 依据加"T 字筋"示例解释 |
| 拔模斜度 | 加「造型方式」选项：粘土砂/自硬砂（JB/T 5105 表3，自硬砂外壁 0°20′~3°30′、内壁 +50%） |
| 铸出孔 | 补全球铁/球铁/铸钢/铝/铜 三档批量（原只有灰铁/铸钢） |
| 加工余量 | 自动推荐从"范围下限"改为"范围中值"（手工砂型 F→G），依据加"工厂实际按 RMA 1.5~2 倍留余量" |
| 出品率+铁水重量 | 已合并为「出品率与铁水重量」一个工具（用户已确认） |
| 冷铁计算 | 新工具（外冷铁/内冷铁厚度 + 失效规则，数据 CNKI 权威） |
| 3D砂型吃砂量 | 新工具（埋箱表3 + 裸浇原则 + 最小壁厚，3D打印砂型专用） |

## 六、v1.20 追加优化（box补充0807 副本-副本）

| 项 | 改动 |
|---|---|

| 3D吃砂量 | 裸浇按资料公式 `溃散层5+(静水压头−铸件高)` 最低40、底面1.5×；埋箱超表退取同尺寸段承重上限；说明区渲染 表3+公式+表5 |
| 结构工艺性 | **两壁各自填 w1/w2 自动取均值**；临界壁厚≈3×最小壁厚加解释+最小壁厚材质表；型砂选项加"湿型按粘土砂/自硬类按自硬砂"提示 |
| 缺陷查找 | **修返回 bug**（详情返回→回缺陷查找而非首页，sessionStorage 记来源+状态，恢复搜索词）；20 张缺 reliability 的缺陷卡补 B/C（`scripts/add_reliability.mjs`） |
| 加料计算 | 牌号显示一致（QT450→QT450-10）；生铁 Z 系列核对 GB/T 718-2005 正确；**自定义打开预填参考值**（可改）；球化/孕育已计入成铁维持 |
| 开箱时间 | 讲清"热时效=去应力退火，做退火可放宽开箱温度"——影响不小故保留该选项 |
| 新增工具 | **尺寸公差 CT 查询**（id `ct` 📐，第 12 个）：GB/T 6414 CT1~16 全表 16 段 + 方法×材质推荐等级 + 基本尺寸查公差± + 壁厚粗一级；数据三源交叉核对 |

## 七、v1.21 追加优化（用户对 5 项的复核意见，v0.14）

| 项 | 改动 |
|---|---|
| 线收缩率 | 分方向从"按 maxDim 归一"改为**绝对尺寸锚定**（≤100mm 取下限、≥1000mm 取上限，之间线性）；1500 vs 10 的率差真实拉开（铸钢 free 触发分方向），并讲清**率 vs 绝对放尺量**（1500×1%=15mm、10×1%=0.1mm） |
| 出品率 | **现场实测出品率默认预填预估中值**（0.5 步进），用户可改；改过即记住不再被覆盖（yieldTouched 标记） |
| 冷铁 | 修崩溃 bug：灰铁切到铝冷铁等无数据组合 → `thickness:null` → 视图崩溃停留旧值（"看着厚度一样"）。现在**自动回退推荐冷铁材料并提示**；下拉按铸件材质过滤可用冷铁材料；补说明"铜>铸铁>铝 激冷能力不同，同厚度效果不同" |
| 结构工艺性 | 型砂从只列 粘土砂/自硬砂 改为**常用砂种下拉**（潮模/干型→粘土砂；树脂/水玻璃/覆膜壳型→自硬砂；其他→粘土砂取小值），自动归类，结果标注归入类别 |
| CT 公差 | **重构主输入**：图纸已标 CT 等级直接选（CT1~16）→ 基本尺寸 → 公差±值；方法×材质推荐降为辅助（一键"填入推荐"）；数据升级标注 **GB/T 6414-2017**（代替 1999，对应 ISO 8062-3:2007，等级 CT/DCTG 数值一致，完整表逐值核对）；**分材质不换标准**（灰铁 GB/T 9439、球铁 GB/T 1348、铝压铸 GB/T 15114、铜 GB/T 13819 均引用 GB/T 6414，差异仅在可达到等级） |
