## 2. 当前 warning 与触发机制

- warning：`resolution`（"采样率不足"），layers=1.79（bodyRef=3.6 / vs=2.01）
- 触发链：bodyRef = max(bodyWallOf→wallAvg=2.3, tP50=3.6) = 3.6 → 3.6/2.01 = 1.79 < 2 → resolution
- **结论：warning 对主体是"真实"的**——主体壁 2-3mm 在 vs=2.01 下仅 1.2-1.5 层，确实欠采样

## 7-11. 根因判断（32.txt 七）

**分类：B + 独立检测缺陷（D 类通用错误）**

1. **warning 本身正确（B 类）**：主体 2-3mm 欠采样属实；但热结区域（厚大轨）采样充分。
   旧文案"热结分析结果仅供参考"把"主体薄"错误等价为"热结结果不可靠"——warning 语义问题。
2. **0 热结的根因（通用性错误，已修复）**：
   - `modulusCeilRatio=(1/3)×d` 物理上限把厚大轨的真实 M（原始 V/A≈4.7）压制到 2.83
     （板/肋状结构 M_true=t/2 被 (1/3)×d 压制 3×——上限按"表面嵌入半球"校准，对板状结构错误）
   - 上限随 d 线性收缩 → M 场 0.8×peak 平台塌缩成 ±1.7mm → `extractRegion` 区域体积 49mm³
     < regionMinVolumeMm3=100 → **tiny_region 拒绝全部厚大结构峰**（audit: tiny_region×10）
   - 峰值检测（prominence）正常——厚大轨 M=2.83 vs 薄壁 1.3，显著性充足；**漏检在区域层**
3. **修复前实验排除项**：改变 d 上限系数（0.45-0.65）或改用 t 上限/混合上限均破坏 14.txt
   均匀件校准（cube/plate/cyl/tube 出现边缘/端面伪峰，实测）——d 上限是校准承重墙。

## 12. 是否属于全局采样不足 / 热结局部采样不足

- **不属于全局采样不足**：192/256/384 实验无单调改善（PHASE 23 §7 已证）
- **不属于热结区域采样不足**：厚大轨 7.9 层（§3）
- **属于 warning 语义问题（B）+ 区域提取对封顶 M 场的通用性缺陷（D）**

## 13-15. 修改内容（32.txt 十，通用机制非特例）

### 修改 1：extractRegion 用未封顶原始 V/A 生长区域（peakRegion.js）

```
区域生长阈值 = regionGrowRatio × max(封顶 M[peak], 原始 V/A[peak])
区域单元判定 = 原始 V/A[nb] ≥ 阈值（field.V/A 数组，buildModulusField 已产出）
```

- **根因**：M 场物理上限压缩板/肋状厚结构的 0.8×peak 平台 → 区域塌缩 <100mm³
- **机制**：区域是"物理 V/A 结构核心"的度量，用未封顶 V/A 提取；峰值检测/报告仍用封顶 M
- **为什么通用**：不改变峰值语义、不改变 M 场、不改变任何阈值；只让区域提取不受上限压缩影响
- **影响评估**：28/28 真实 STL 热结数量零变化（仅 ALR2510 v1 从 0→5）；均匀件 NO_HOTSPOT 保持；
  工程件 4/4（bossOnPlate 1、pvpPair 2、multipleBosses 4、thinShell 0）保持

### 修改 2：resolution warning 文案区分"主体薄"与"热结可用"（v3ViewAdapter.js）

```
有热结时：⚠ 模型主体为薄壁结构（约 X mm（Y 层，低于 2 层采样下限）），
          薄壁区域厚度测量精度有限；已检出 N 个热结（厚大区域采样正常），热结分析结果可用。
无热结时：⚠ 当前模型存在局部区域采样不足，热结分析结果仅供参考。（原文案保留）
```

- **根因**：warning 语义混淆（"模型整体薄" ≠ "热结结果不可靠"）
- **机制**：按热结检出情况分支；热结能通过 tiny_region/置信度门槛即证明其采样层数充足

### 未修改（实验排除）

- `modulusCeilRatio` d 上限：校准承重墙（放宽任何比例破坏均匀件测试，实测）
- vs 选择/采样公式/其他阈值：零改动

## 21. 剩余风险

1. **细化 stride 随分辨率退化**（PHASE 23 §7 已知）：384³ 下热结漂移/丢失——生产不使用
   384，但未来提高默认分辨率前必须解决（refineMaxPoints 动态分配）
2. **ALR2510 壁峰（M≈1.3）与厚大轨（M≈2.7）同出**：薄壁件壁峰的热结意义有限——是否在
   薄壁件场景过滤壁峰属产品决策，需用户确认
3. **wallMain 直方图退化**（=wallMax）在此模型复现：bodyWallOf 已用 wallAvg 兜底 + tP50
   校验，结果正确；但 wallMain 本身的可信度问题（PHASE 17 遗留）未根治
4. **t 测度在轨心过估**（t=24 vs 实际 17，斜向穿越）：不影响本修复（区域用原始 V/A），
   但 t 测度的边界使用（tP50 校验）需注意该偏差方向（过估 → 保守）
