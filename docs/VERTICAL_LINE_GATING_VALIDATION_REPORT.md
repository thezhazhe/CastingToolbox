## 2. 四种浇注方式独立性（S1/S2）

| 检查 | 结果 |
|---|---|
| 节流截面各自不同（内浇口/减压段/上横流道/平衡处） | ✅ |
| 加压/混合 = 各层不同面积；减压/不加压 = 各层同尺寸（手册明示） | ✅ |
| 混合管道=减压值、口=加压值（逐项数值比对） | ✅ |

| 方向性：H 大 → 口面积小，F_i/F_j = √(H_j/H_i) 精确 | ✅ |

## 9. 最终结论

**CONDITIONALLY VERIFIED（条件性验证通过）**

- **已验证**：加压式、减压式、混合式三种系统的主计算链与 DISA 手册算例一致（误差 ≤0.4%，仅浮点/手册舍入差异）；分层有效静压头→分层面积逻辑正确；边界/单位/门禁/隔离性全部通过；未破坏既有 14 个计算器（回归 154/0）。
- **明确限制（判定为 CONDITIONAL 的原因）**：
  1. **不加压式**上横流道因手册布置相关步骤（实际/平均头比 192.5/135）无通用公式而采用直接公式，结果低于手册例约 24% —— 使用时应偏保守校核；
  2. 材料仅**灰铸铁/铝合金/铜合金**（手册仅此三套 k）；
  3. 层输入为"平均有效静压头 H"，需用户按手册公式 3/4（顶部=a、底部=a−c/2、侧面=a−b/2）由型板换算；
  4. 全部结果为计算参考值，尺寸建议属工程推荐层 —— **首次应用请以浇注试验复核**。
- **不属于 NOT VERIFIED**：主链无公式冲突或不可复现项；所有差异项均能定位到手册自身印刷/表述矛盾并已在 UI + 本报告如实披露。
