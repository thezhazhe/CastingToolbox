## 1.1 gating — 浇注系统设计 ★ 最高优先级

**① 工程目的**：给定铸件重量、材料、浇注方式，算出浇注重量 G、浇注时间 t、阻流截面积 A，按浇道比分配直/横/内浇道尺寸，校核流速与排气。

**② 当前输入**（runGating，gating.js:86-97；参数来自 calcManifest.js:55-62）：

| 参数 | 变量 | 单位 | 来源 | 合理性 |
|---|---|---|---|---|
| 材料大类 | mat | — | 项目 material.family | ✓ |
| 铸件重量 | pw | kg | **geometry.weightKg（STL 净重）** | ⚠️ 应为"含加工余量毛坯重"（P0-4） |
| 一模件数 | cav | 件 | production.cavities | ✓ |
| 主体壁厚 | wall | mm | process.wallUsed=bodyRef（PHASE 26） | ✓ 比 wallMain 可信 |
| 浇注方向 | pos | — | process.pourPos | ✓ |
| 内浇道至上箱面距离 | Ho | mm | process.Ho | ⚠️ 定义需核对（底注 Hp 依赖 Ho≈C） |
| 铸件高度（浇注方向） | ph | mm | process.ph | ✓（可由 bbox 自动建议） |
| 预估出品率 | yr | % | material.yieldSug（默认 70） | ✓ |
| 内浇口位置 rh | rh | — | **硬编码 0**（calcManifest.js:83） | ⚠️ UI 无此输入 |

**③ 当前公式**（全部还原自 gating.js）：

```
G     = pw × cav ÷ yv                                          (gating.js:109)
Cmm   = ph + rh
Hb    = 查表(G)：<10→150 / <50→200 / <200→250 / <1000→300 / <3000→500 / <8000→750 / else 1100  (gating.js:51)
Pv    = 顶注 0 / 中注 Cmm/2 / 底注 Cmm                          (gating.js:114)
Hp    = 顶注: Ho+Hb/2 − rh²/(2C)                               (gating.js:68)
        中注: Ho+Hb/2 − (Pv+Cmm−rh)²/(2Cmm)                    ← 与文献不符，P0-2
        底注: Ho+Hb/2 − Ho/2                                    ← 隐含 Ho≈Cmm 假设，P1
fv    = 顶注 0.8 / 中注 0.6 / 底注 0.45                         (gating.js:117)
t     = fc × (√G + ∛(w×G/5)) × 2/3   [Dietert 变体]           (gating.js:63)  ← 来源未确认，P1
A     = 71.47 × G / (ρ×t×fv×√Hp) × 100                        (gating.js:74)  ← 数值验证 ✓
A_sp/A_run/A_gt = A × (该组元比/最小比)                         (gating.js:123-126)
v     = 10×G/(t×ρ×Fg/100)，校核 ≤1.8 m/s                       (gating.js:81,158)
排气  = (π·vrd²/4·vrc + vsw·vst·vsc) / Fs_act ≥ 1.5            (gating.js:163-165)
```

**④ 公式正确性**：
- **G**：数学正确（G=铸件重/出品率是出品率定义式），见 P0-4 口径错位。
- **t（Dietert）**：经典 Dietert 为 `t=S·√G`（S 按壁厚 1.63/1.85/2.2，适用 ≤450kg），另有中大型件 `t=S₁·∛(δG)`（S₁=2 或 1.7~1.9）。**代码的 √G+∛(wG/5)×2/3 形式多源检索未见原形**，且 f 为"材质系数"（0.8~1.2），与经典公式中 f/S 作为"壁厚系数"（1.63~2.2）语义完全不同。数值对照（100kg 铸铁、壁厚 10mm）：代码 10.6s vs 经典 S√G=18.5s vs 经验表 4~6s——差 2~4 倍，属宽范围工程估算，但代码形式无出处。**【存在问题】**
- **Hp 顶注**：rh=0 时 =Ho+Hb/2=H0，与文献 Hp=H0−P²/2C（P=0）一致 ✓。
- **Hp 中注**：代码 P 项=(Pv+C−rh)，默认 rh=0、Pv=C/2 时 P 项=1.5C；文献中注（内浇口在型腔中部）P=C/2。**实测（C=100、Ho=150）：Hp 代码 137.5mm vs 文献 237.5mm → A 偏大 31%**；当 Ho<1.125C 时 Hp≤0，calc_A 直接返回 0（gating.js:75）→ 全结果清零。**【存在问题：P0-2】**
- **Hp 底注**：代码=H0−Ho/2，文献=H0−C/2。仅当 Ho≈C 时一致（实测 C=100、Ho=150 时差 25mm，A 差 6.5%）。底注时通常 Ho≈铸件高度 ✓ 近似成立。**【基本正确但有条件】**
- **A（奥赞）**：与文献通式 A=m/(ρμt√(2gHp)) 及铸铁简化式 A=G/(0.31μt√Hp)（Hp 以 cm）**数值交叉验证一致**（实测 1404 vs 1402 mm²，±0.2%），常数 71.47 在 Hp 用 mm 时正确。**【正确】**
- **v 校核**：v=10G/(tρFg/100) 与常用式 v=G/(ρtΣF) 的倍数关系**待人工复核**（见 §8 待验证 3）。流速校核误差不影响 A 主计算。

**⑤ 工程合理性**：
- **适用性**：奥赞公式与 Dietert 法主要用于铸铁件封闭式浇注系统。代码对球铁/铸钢/铝（推荐开放式）也用同一奥赞式算阻流——文献明确奥赞式适用于封闭式；开放式阻流在直浇道底部，公式可延伸但 fv、Hp 含义需调整，代码未区分。**【P1】**
- **fv**：文献铸铁湿型 μ=0.35~0.50（按砂型阻力大/中/小），干型 0.41~0.60，顶注 +0.10~0.20、底注 −0.10~0.20，封闭式 μ 上限 0.75。代码 fv={顶 0.8/中 0.6/底 0.45}——顶注 0.8 超出文献上限 0.75；A∝1/fv → A 系统性偏小 20~50%。同时文献指出奥赞计算值本身偏小，生产中常乘 1.1~1.3 增大系数——代码没有，与 fv 偏大叠加。**【P1】**
- **G 语义**：pw 来自 STL（零件净重），出品率表按"含余量毛坯"统计——偏小 3~8%。见 P0-4。
- **S直:S横:S内**：预设（封闭 1:1.5:0.8~1:2.5:0.9、开放 1:2:2~1:3:3）在常见范围；推荐逻辑（灰铁封闭、球铁/钢/铝开放）与文献一致 ✓。**【OK】**
- **v≤1.8 m/s**：未在权威文献检索到 1.8 出处；对所有材料统一，铝/铜应更低。**【P2】**
- **未校验液面上升速度 vL=C/t**（文献要求 ≥0.8~3.0 cm/s 按壁厚）——大平面铸件可能冷隔/结壳。**【P2】**
- **排气 ≥1.5 倍**：经验规则，作参考提示可接受（D 级）。

**⑥ 系数审计**：

| 系数 | 当前值 | 来源 | 判断 |
|---|---|---|---|
| 材质系数 f | 灰铁1.0/球铁0.85/铸钢0.8/铝1.2/铜0.9 | 【来源未确认】 | 语义与经典 Dietert 壁厚系数（1.63~2.2）冲突 |
| 流量系数 fv | 0.8/0.6/0.45（按位置） | 与文献（0.35~0.50+修正）不符 | **系统性偏大** |
| 出品率区间 | 灰铁65-85/球铁55-75/钢50-65/铝70-90/铜55-70 | gating.js MATERIALS | 与 yield.js 表（灰铁60-75等）不一致——同参数两表并存 |
| 密度 ρ | 灰铁7.0/球铁6.9/钢7.5/铝2.6/铜8.4 | — | 铸铁 7.0≈液态 ✓；铸钢 7.5 偏高（液态 7.0~7.2）；见 §五 |

**⑦ 当前最大风险**：① 中注 Hp 公式错误（A 偏大 30%+，Hp≤0 时全 0）；② fv 偏大 + 无增大系数（A 偏小 20~50%，与①方向相反，净偏差不可预测）；③ Dietert 变体来源未确认（t 直接决定 A）。

**⑧ 改进建议**：P0 中注 Hp 改文献式 + pw 语义提示；P1 fv 改文献表 + t 公式出处/替换 + 开放/封闭分流；P2 流速分材料 + 液面上升速度校核 + Hb 表标注来源。

## 1.2 riser — 冒口设计 ★ 最高优先级

**① 工程目的**：按铸件模数 Mc 用模数法设计冒口尺寸（D/H），迭代满足"模数条件 Mr≥Mc×f + 体积条件 eff×Vr≥缩量"，并给冒口颈直径。

**② 当前输入**（runRiser，riser.js:75-82；calcManifest.js:91-99）：

| 参数 | 变量 | 单位 | 来源 | 合理性 |
|---|---|---|---|---|
| 材料 | mat | — | 项目 | ✓ |
| 铸件重量 | cast_wt | kg | geometry.weightKg | 同 P0-4（净重问题） |
| 热节模数 Mc | mc | mm | process.mcUsed | ✓ 链正确（无热结=bodyRef/2，有热结=最大热结 M） |
| 冒口形状 | shape | — | **硬编码 sphere_head** | P1（PHASE 27-A 已列） |
| 高径比 | hd_ratio | — | **硬编码 1.0** | P1 |
| 效率 | eff | — | 未传→用形状默认 | ✓ |

**③ 当前公式**：
```
Mr_need = Mc × f（f 从 1.10 起，+0.05 迭代，≤50 轮）            (riser.js:85-105)
D 由形状 DfromM(Mr_need, hd) 求（圆柱 M=DH/(2D+4H)、球 M=D/6、球顶柱 V/A）(riser.js:28-59)
H = round(D×hd)
Vr = 形状体积(mm³)；effV = Vr×eff
volOk = effV ≥ Vc×shrink，Vc = cast_wt×1e6/rho (mm³)            (riser.js:100-101)
冒口颈：M_neck = Mc×neck_k；d_neck = 4×M_neck                  (riser.js:109-110)
yieldPct = Vc/(Vc+Vr)                                          (riser.js:117)
```

**④ 公式正确性**：
- **Mr=Mc×f 迭代**：文献模数法要求 M铸件:M颈:M冒 = 1:1.1:1.2（顶明冒口）/1:1.1:1.25（侧暗冒口），f 从 1.10 起步 ✓ 与文献下限一致。**【正确】**
- **形状模数公式**：圆柱 M=DH/(2D+4H) ✓（《铸造工艺学》）；球 M=D/6 ✓；球顶柱按 V/A 数值积分 ✓。**【正确】**
- **体积校核**：文献为 **εv(V件+V冒) ≤ η×V冒**；代码为 effV ≥ Vc×shrink——**漏掉冒口自身收缩 Vr×εv 项**。量级：Vr≈0.2Vc、shrink=0.03 → 漏项≈0.6%Vc vs 总缩量 3%Vc，约 20% 低估。模数条件通常主导，影响有限。**【基本正确但有条件：P2】**
- **Vc 单位**：cast_wt×1e6/rho → mm³ ✓（kg→g ×1000、cm³→mm³ ×1000），与 Vr(mm³) 可比 ✓。**【正确】**
- **riserWt（yield.js 消费）**：`Vr(mm³)×rho(g/cm³)/1000` —— 量纲结果 = Vr×rho/1000 **g**（1cm³=1000mm³），**不是 kg**。实测：Vr=80000mm³（80cm³）→ 代码 560，UI 显示 560kg，真实 0.56kg。注意同屏"冒口体积"展示（Vr/1000 cm³）是正确的——**同一 Vr 在冒口视图与出品率视图换算不一致，用户会看到"体积 80cm³ 却重 560kg"的荒谬组合**。**【P0-1：1000 倍错误】**
- **d_neck=4M**：圆颈 M=d/4 → d=4M ✓。**【正确】**

**⑤ 工程合理性**：
- **Mc 语义切换**（calcManifest.js:108-112 → designCenter 回写）：无热结 Mc=bodyRef/2（板件精确、柱/梁类低估——保守侧冒口偏大，安全）；有热结=最大热结 M（局部 V/A）✓ **切换逻辑工程上合理**；风险在热结漏报时（非 90° 退化）回退 bodyRef/2 → 冒口可能不足。**【基本合理，边界 P1】**
- **球铁适用性**：球铁靠共晶膨胀自补缩，常规模数法冒口会过度设计；《铸造手册》球铁冒口普遍建议缩小模数比（f 可至 1.05~1.1 甚至无冒口工艺）。代码 shrink=0.03 忽略"膨胀补偿"机制——铸态球铁偏保守（冒口偏大），高牌号（QT700）又偏低。**【P1】**
- **体积校核用整件体积**：无热结时保守做法 ✓；有热结时应按热结区域体积校核（STL 已算热结区域体积，未接入）。**【P1】**
- **冒口效率**：eff_open 14%（文献 12~15 ✓）、eff_blind 20%（文献 15~20 ✓ 上限）、eff_sph 25%（**文献球形 15~20，略高**）、eff_heat 35%（文献发热保温 25~30%，铸钢实践 30~60%——取中上）。**【P2：25 偏乐观→冒口偏小风险】**
- **冒口颈**：neck_k 铸钢 1.1 ✓（文献 1.1~1.25）、球铁 1.0 ✓、灰铁 0.75（灰铁膨胀补缩可细颈——合理）。**【OK】**

**⑥ 系数审计**：f 起步 1.10 ✓ / 效率 14~35 基本 ✓ / neck_k ✓ / shrink 见 §五。

**⑦ 当前最大风险**：① riserWt 1000 倍单位错误（跨到 yield 与报告）；② 球铁冒口未区分（模数法硬套冒口偏大 20~50%）；③ 体积校核漏冒口自身收缩（冒口偏小 ~20% 方向）。

**⑧ 改进建议**：P0 riserWt 除 1e6；P1 形状/高径比生效 + 球铁无冒口工艺提示 + 热结区域体积接入；P2 补 Vr×εv 项 + eff_sph 下调至 20。

## 1.3 shrinkage — 线收缩率

**① 工程目的**：按合金与收缩状态推荐模具放尺。

**② 输入**：材料大类 + 三方向尺寸（STL 自动 ✓）+ 收缩方式（free/common/restrained）。

**③ 公式**（shrinkage.js:46-64）：
```
档位率：free=[restrained, free] / common=[restrained, common] / restrained=固定
t = clamp((size−100)/(1000−100), 0, 1)          ← 按绝对尺寸线性插值
rate = lo + (hi−lo)×t
SPLIT_RATE_DIFF=0.2 → 方向率差≥0.2% 则分方向放缩水
```

**④ 正确性**：数学正确 ✓。**⑤ 工程合理性**：**【存在问题】**——代码注释已承认"收缩率是'率'，与尺寸大小关系不大，真正拉开差距的是绝对放尺量"（shrinkage.js:8-9），但实现却按绝对尺寸取不同率（100mm→lo、1000mm→hi）。**线收缩率由合金种类+受阻程度决定，与绝对尺寸无直接关系**；同一铸件 50mm 与 1000mm 方向收缩率应基本相同（除非各方向约束不同）。当前实现把"率"当"随尺寸增长的量"——1000mm 方向取 hi（如铸钢 2.2%）恰恰可能反向（大方向约束点多，通常受阻更大、率更小）。实际影响：差 0.2 个百分点 × 1000mm = 2mm 放尺差——有工程意义。**【P1：算法逻辑与注释矛盾，应按方向约束分档】**

**⑥ 系数**：灰铁 0.8~1.0 / 球铁 0.6~1.0 / 铸钢 1.5~2.2 / 铝 0.8~1.1 / 铜 1.2~1.4（%）——全部在常见手册范围 ✓（铸钢 2.2 为上限）。

**⑦ 最大风险**：方向率取错导致放尺偏差 ~0.2%×尺寸；combined=hi 偏大方向安全侧。**⑧ 建议**：P1 按约束分档；P2 文案修正。

## 1.4 machining — 加工余量 RMA

**① 工程目的**：按 GB/T 6414 给机械加工余量等级与数值。

**② 输入**：材料 + 基本尺寸（STL ✓）+ 铸造方法（**声明了但 calculate 硬编码"砂型·机器造型/壳型"，calcManifest.js:203**）。

**③ 公式**：RMA_TABLE 13 档 × A~H 级查表（machining.js:11-25）+ METHOD_GRADES 推荐等级（machining.js:62-67）+ rmaRange 范围合成。

**④ 正确性**：表数值与 GB/T 6414（1999/2017 RMA 数值一致）逐档核对吻合 ✓；单侧余量语义 ✓；顶面 nextCoarserGrade 降一级 ✓（标准要求）；"K 级未收录止于 H"有注释 ✓。**【正确】**

**⑤ 工程合理性**：
- METHOD_GRADES：砂型手工 铸钢 G~K、灰铁 F~H、铝 F~H ✓（GB 表 A.2 一致）；金属型灰铁 D~F ✓。**【OK】**
- **球铁→灰铁、铜→铝近似映射**（calcManifest.js:202）：GB/T 6414 RMA 等级按铸造方法/尺寸，不按铸铁牌号细分——球铁→灰铁同档合理（影响极小）；铜→铝基本成立。**映射影响小，但无 UI 提示属 UX 缺陷**。**【P2】**
- **method 不生效（硬编码机器造型）**：用户选金属型/熔模/压力全部按砂型机器造型出 RMA——金属型余量应更小（D~F 而非 E~G）。**【P1】**

**⑥ 系数**：标准表，无自定义系数 ✓。**⑦ 风险**：method 失效导致余量偏大 1 级（安全侧，浪费材料）；无提示。**⑧ 建议**：P1 接 method；P2 映射提示。

## 1.5 yield — 出品率与铁水重量

**① 工程目的**：按产品/工艺/材料查出品率区间，算铁水总重并分解。

**② 输入**：材料 + 铸件重量（STL ✓）+ 造型线（可选）。

**③ 公式**（calcManifest.js:129-143）：
```
y = resolveYield(五级回退：产品×工艺→材料×工艺→工艺→材料→通用[40,60])   (yield.js:45-60)
pourWt  = gating.G（已算）否则 wt/(yieldSug/100)
runnerWt = G − wt                    ← 实际是"浇冒口总重"，与 riserWt 概念重叠（P2）
riserWt = riser.Vr×rho/1000          ← P0-1 单位错误
```

| 铝 | 2.6 | 2.6 | 2.6 | 2.6~2.7 | 2.35~2.4 | **gating 用固态值 2.6 偏高 8~10%**（应液态 2.4） |
| 铜 | 8.4 | 8.4 | 8.4 | 8.2~8.9（锡青铜 8.8） | ~8.0 | 大体 ✓ |

**结论**：密度问题的本质是**液态（浇注质量流）与固态（体积/重量）两个物理量被合并**；gating 应接液态密度（灰铁 7.0 ✓ 但铸钢 7.5 ✗、铝 2.6 ✗），riser/重量链应接固态密度（铸钢 7.8 ✓ 但球铁 6.9 ✗）。**修正=项目级两个密度字段或每材料表加液态密度**。P0。

riser 材料表 shrink（体收缩率）：灰铁 2%（石墨化膨胀补偿后 ✓）、球铁 3%（视 CE，3~6% 常见，取低值）、铸钢 4.5%（碳钢 4~5.5% ✓）、铝 4.5%（4~7% ✓）、铜 4.5%（4~6% ✓）——合理。
