## 1. 任务 A · 浮点边界修复

### 1.1 问题与原理

`Mr_target = Mc × 1.2` 与 `M(D,H)` 都是浮点计算的结果。当**数学上恰好相等**时，浮点可能低几个 ULP：

```
球顶柱 / Mc = 25 → Mr_target = 30
H = D = 180 时理论模数恰为 30（M = r/3 = 90/3）
实测 sd.M(180,180) = 29.999999999999996   ← 少 4e-15
严格 `>=` 判为"不足" ⇒ 多升一档 ⌀181（多 1mm，体积多 ~1.7%）
```

### 1.2 修法（最小改动，**不恢复 0.99**）

```js
export const FLOAT_REL_EPS = 1e-12;                                   // 相对量容差
export const meetsTarget = (mAct, mTarget) => mAct >= mTarget * (1 - FLOAT_REL_EPS);
```

`meetsTarget` 成为全模块**唯一**的达标判据，三处共用：尺寸搜索 `okAt`、返回守卫、`modOk`/`converged`。
（两处口径若不一致，会出现"搜索接受、守卫拒绝 ⇒ 合法输入返回 `null`"的自相矛盾。）

**未改动**：`MODULUS_TARGET_RATIO = 1.2`、四形状几何公式、`hd_ratio` 处理、目标模数定义、
取整/上探/下探规则、`js/engine/**`、`calcs/riserDreq.js`。

### 1.3 容差取值的依据（实测，非估计）

扫描 `4 形状 × hd∈{0.5,0.8,1,1.2,1.5,2} × 3000 档 Mc` = **71,760 个"被上探拒绝的候选"**，
记录其相对欠缺 `rel = (Mr − M(D−1)) / Mr`：

| 群体 | 条数 | rel 范围 |
|---|---|---|
| **浮点噪声**（数学上其实达标） | 255 | **3.7e-16 ~ 6.2e-14** |
| 灰带（既非噪声也非真实不足） | **0** | — |
| **真实不足**（离散档距造成） | 71,502 | **6.9e-7 ~ 1e-1** |

⇒ 两侧相差 **1.1e7 倍**，中间是一段**空的**数量级鸿沟。取 **1e-12**：
高于噪声上界 **16 倍**、低于真实不足下界 **6.9e5 倍**。

★ 噪声的主要来源已定位：**`Mc × 1.2` 自身的舍入**（例：`M(D−1)` 恰为 71.4，而 `Mr` 算出 71.40000000000444）。

⚠ **唯一的理论代价（如实披露）**：若把 `Mr_target` 设成比 `M(D,H)` 高出**不到 1e-12 相对量**的数，
该尺寸会被接受。这个量在 30mm 模数上 = **3e-11 mm**，比 `Mc` 输入本身的精度（1 ULP ≈ 2.2e-16 相对）
大 4 个数量级，但工程上等于"恰好等于目标"。**这不是工程容差，是浮点比较的必要下限。**

### 1.4 影响面（实测）

| 项 | 结果 |
|---|---|
| 全域 72,024 点中尺寸变化 | **7 点**（全部变小，**0 点变大**） |
| 变化点位置 | 全部是 `sphere_head` 且 Mr 为整数：hd=1 的 Mc=12.5/25/37.5/42.5/50；hd=1.5 的 Mc=20/40 |
| 变化点性质 | 7/7 满足边界判据（新档与目标相对差 < 1e-11，且 D−1 真实不足 > 1e-6） |
| 真实不足是否被放行 | **否**：目标抬高 1e-3 / 1e-6 / 1e-9 / **1e-11** 倍时，受限档**全部被拒**、尺寸照常升档 |

**案例前后**：球顶柱 / Mc=25 → `D: 181 → 180`（`Mr_target=30`，`Mr_act=29.999999999999996` 判为达标）。
