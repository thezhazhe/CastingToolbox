## 1. 当前架构最终判断

**结论：现有架构（项目级参数 CastingProject + calcManifest 声明 + calcs 纯函数）合理且可持续，不重构。**

理由：
- 架构分层正确：纯计算（calcs/）与 UI（views/）分离、参数有来源标记（P(v,src,conf)）、计算器统一声明（manifest）
- PHASE 28.1 调查确认：问题集中在**参数语义归并**（密度/重量/Mc 双语义）与**"声明≠实现"接线缺口**（machining/shakeout 选项失效），均为修补级问题，不是架构缺陷
- 历史 Excel 是"表格+公式"混合体，其工程价值应在**知识层**吸收（标准化为参数/规则），而非把 Excel 结构搬进 UI

**架构原则（后续所有阶段遵守）**：
```
历史 Excel / 文献 / 企业经验
        ↓
   工程知识层（参数/规则/标准，含可信等级）
        ↓
  产品核心算法（calcs 纯函数，单一语义输入）
        ↓
   简洁 UI（隐藏复杂度，不暴露中间量）
```
禁止 `Excel → UI` 直搬；一切 Excel 数据先入知识层再决定是否进产品。

## 5. 过滤网产品形态：方案比较与推荐

### 方案 A：固定校核项
```
浇注系统设计 → 过滤网：□ 不使用  □ 使用
  使用 → 推荐规格 100×100（按 G+材质查表）
        理论允许通过：XXX kg（灰铁 400 / 球铁 200…）
        当前铁水量：XXX kg → 结果 ✓ / ⚠
```
优点：入口固定、逻辑直白；缺点：常显占用版面，对不使用过滤网的用户是干扰。

### 方案 B：轻量折叠区域（**推荐**）
```
浇注系统设计 → 「过滤网校核」折叠区（默认收起）
  展开 → 自动显示：推荐规格 / 过流量 / 当前铁水量 / ✓⚠
  用户操作：0（全自动，仅一个"使用/不使用"开关）
```
优点：**隐藏复杂度而不是删除工程能力**；默认不展开不增加干扰；自动推荐零输入；符合"独立计算器=简单"的产品定位。缺点：多一个折叠控件（成本极低）。

### 推荐：方案 B
依据：产品 80/20 原则（不增加复杂输入项）；"隐藏复杂度"核心原则；数据完全可自动化（G 已有、材质已有、查表简单）；两种方案功能等价，B 的交互成本更低。

**实现要点（PHASE 28.3）**：数据表照 Excel 过滤网标准（碳化硅/氧化锆/莫来石 8 规格 × 灰铁/球铁过流量）；按 G 与材质自动推荐最小可用规格；过流量不足时 ⚠ 提示换大规格或增加片数；**只作校核提示，不阻断**。

## 9. Hp 最终验证结果（真实案例）

**案例**：海德曼基座 147-01-00033-0（HT300，机床类，三铸铸造）——Excel 中唯一完整案例：铸件高 76mm、冒口高 171.5mm、Ho=18cm、Hb=30cm（G=120.22kg）、顶注。

### 有冒口场景（Hp mm）

| 浇注位置 | Excel 原式 | 当前代码（rh=0） | 方案 A（rh=冒口高） | 方案 A 复现 |
|---|---|---|---|---|
| 顶注 | **270.6** | 330.0（+59.4） | **270.6** | ✓ |
| 中注 | **153.9** | 51.6（−102.3） | **153.9** | ✓ |
| 底注 | **240.0** | 240.0（=） | **240.0** | ✓ |

### 无冒口场景（Hp mm，C=76mm）

| 浇注位置 | Excel 原式 | 文献式 H0−P²/2C | 当前代码 | 代码差 |
|---|---|---|---|---|
| 顶注 | 330.0 | 330.0（P=0） | 330.0 | 0（=文献 ✓） |
| 中注 | **320.5** | **320.5**（P=C/2） | 244.5 | −76.0 |
| 底注 | 240.0 | —（底注 Ho≠C，P1-6） | 240.0 | = |

### 奥赞全链（真实案例）

t(理论)=13.75s（Excel 同构公式）；A：Excel 22.6 式 678.3mm² = 代码 71.47 式 678.4mm² ✓（单位换算再次确认）。

### 结论

**方案 A（中注 (Pv+rh)、顶注 −rh²/2C、rh=冒口高度接 UI）在真实案例与无冒口场景下 100% 复现 Excel 原式**；当前代码在顶注 Hp 偏大 22%（→A 偏小 ~10%）、中注 Hp 偏小 66%（→**A 偏大约 70%**，真实案例 51.6 vs 153.9mm）。
Excel 公式本身成立：无冒口时=文献式（320.5=320.5），有冒口时是"阻流以上液柱含冒口"的企业修正。
**最终修复建议：采用方案 A。**【需要人工批准】批准后实施步骤：① 接 canonical `riserHeight`（riser 输出回写或 UI 输入）；② 中注/顶注公式按方案 A 改；③ 用本案例（270.6/153.9/240.0）与无冒口案例（330/320.5/240）建回归测试。

## 10. 13 计算器与工艺设计中心的边界

```
独立计算器（13 个）= 独立可用
  - 自带完整输入（手填或项目参数），不依赖 STL
  - 不因设计中心存在而失去独立能力

工艺设计中心 = 自动串联层
  - STL → 几何分析 → 项目参数 → 调用计算器 → 结果汇总
  - 只负责"自动填入"与"串联"，不改变计算器本身
```
- 禁止：把 13 个计算器全部改造成依赖 STL（castability/ct 接 STL 属于"自动填入"，保持手填可用）
- 禁止：独立计算器反向依赖设计中心状态
- 边界验证：PHASE 28.3 之后每个计算器仍可用纯手填跑通（现有 Node 测试保证）
