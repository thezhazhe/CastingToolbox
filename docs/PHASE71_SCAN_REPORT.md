`calcs/castability.js`（结构工艺性计算器数据）已内置板块 B 所需的全部**可追溯工程参考表**（与 74.txt 例中 "≥3.5mm" 同类）：

## 三、74.txt 五项扫描问题 —— 直接回答

1. **当前 STL 已可靠得到哪些基础信息？** —— 尺寸（长宽高）/体积/表面积/净重+毛坯重（材料后）/主体壁厚/最大壁厚/壁厚分布直方图/热节数/每热节 Mc·区域体积·位置·置信度/分析状态与可靠性等级。全部带 SRC+CONF 元数据，且已有冻结的门禁纪律（分析失败绝不冒充结果）。
2. **是否已具备壁厚、孔、圆角、拔模分析能力？** —— 壁厚：**有**（采样+距离场，半距×2 与局部完整厚度双体系，经 P23/26 修正）；孔：**无**；圆角：**无**（曲率分析不存在）；拔模：**无**（无方向分析）。引擎目录扫描确认：无任何 fillet/draft/hole 特征识别代码。
3. **哪些工艺性信息已有数据基础？** —— 薄区定性（thin/tP10）、厚大区（热结）、厚薄差异（wallHist/wallMax/bodyRef 关系）。加上 castability.js 整库参考数据。
4. **哪些只能作为固定工程参考？** —— 拔模斜度（分型面未知，只能参考档）、最小铸出孔径（无孔检测，只能参考）、圆角（无尖角定位，只能按主体壁厚给参考）、最小壁厚（参考档给"建议值"，检测侧只有定性薄区）。
5. **哪些目前完全不能可靠判断？** —— "当前零件的精确最小壁厚"（伪精确禁止）、"尖角位置/圆角偏小位置"（需曲率场，V1 不做）、"实际拔模斜度/方向"、"铸件上的孔及其直径"、"多热节件的分区补缩边界"（feed-zone 说明已在 riser 结果区声明）。

## 六、结论

- **引擎侧零缺口**：板块 A 10/11 项可直接展示，唯一"最小壁厚"按 74 精神只能给定性薄区信号；
- **数据侧零开发**：板块 B 全部参考表已在 calcs/castability.js（铸造工程师手册 / JB/T 5105-2022 / GB/T 9439 / 机械设计手册，文件头注出处），直接 import；
- **需要增加的只有"胶水逻辑"**（≤1 个纯函数 + 状态文案）：薄区定级、厚薄比启发、三信号组合摘要——全部基于已有检测信号，不新建任何检测算法；
- **明确不做**：曲率/尖角/孔/拔模方向识别（74 明示 + 现状无基础 + 防伪数据纪律）。
