## 2. S1：底部状态栏异常（根因与修复）

### 2.1 根因（实测）

`.dc-ws` 使用：

```css
grid-template-rows: auto auto auto minmax(0, 1fr) auto auto;
```

结果视图下：
- `.dc-chrome` 被 `display:none`（结果视图规则）；
- `.dc-stale-bar` 可能 `hidden`。

隐藏元素不参与 Grid 布局，后续子元素自动前移：
- `.dc-body` 从第 4 行（1fr）前移到第 3 行（auto）；
- `.dc-statusbar` 从第 6 行前移到第 4 行（1fr），被拉成整行剩余高度。

实测 page1：状态栏 `height = 150.2px`，而子 chip 每个仅 20.8px；冒口/浇注页因内容更长，异常不明显。

### 2.2 修复

在 `.dc-ws` 下显式固定直接子元素的行号：

```css
.dc-ws > .dc-topbar   { grid-row: 1; }
.dc-ws > .dc-flowbar  { grid-row: 2; }
.dc-ws > .dc-chrome   { grid-row: 3; }
.dc-ws > .dc-body     { grid-row: 4; }
.dc-ws > .dc-stale-bar{ grid-row: 5; }
.dc-ws > .dc-statusbar{ grid-row: 6; }
```

隐藏的 chrome / stale bar 现在只让自己的行高度为 0，不再让后面元素换行。没有隐藏整个状态栏。

### 2.3 验证

- page1：状态栏 **58.9px**（修复前 150.2px），`.dc-body.bottom` 在状态栏上方；
- 切到冒口页、浇注页：状态栏仍 <80px；
- 桌面 1366×900、移动端 390×844 无横向溢出；
- S5/UI 浏览器专项含三项状态栏高度检查，全部通过。

## 7. S9/S10：冒口颈与补缩距离调查（只方案，未实现）

### 7.1 冒口颈

**当前代码事实**：
- `calcs/riser.js:11-15`：`neck_k` = 灰铁 0.75 / 球铁 1.0 / 铸钢 1.1 / 铝合金 1.0 / 铜合金 1.0；
- `calcs/riser.js:292-294`：`M_neck = Mc × neck_k`，`d_neck = round(4 × M_neck)`；
- 独立计算器给出“颈长建议 ≈0.5~1.0 倍颈径”，但**没有颈长输入**，没有连接形式/热节校核；
- 没有显式“铸件:颈:冒口 = 1.0:1.1:1.2”校核。

**资料依据**：
- Campbell《Complete Casting Handbook》中译本 `translated.md:9351`：铸件:颈:冒口模数比常取 **1.0:1.1:1.2**（Beeley 1972）；
- 同段 Sciama（1975）：钢颈径可到 **0.5D**（颈长 ≤0.1D）；外推到 0.25D 时颈长 ≤0.03D；铜/铝 0.25D 时颈长 ≤0.06D；Washburn 芯典型厚 0.1D、孔 0.4D；
- 这些是特定材料/实验条件下的结果，书中明确提醒 Sciama 结果可能偏乐观。

**最小可行模型建议（后续单独授权）**：
1. 保持当前“颈模数/颈径”作为**计算结果**；
2. 新增独立“冒口颈经验参考”模块，不覆盖现有结果；
3. 先支持一种几何：**圆形直颈、无 Washburn 芯**；
4. 输入：材料、冒口 D、Mc、颈长 L、连接形式（直/圆角/座）；
5. 输出：`M_neck/Mc`、`d_neck/D`、`L/D`，并给出“在已验证范围/超出范围”的提示；
6. 若模数目标与直径比例约束冲突，明确报告冲突，不静默改结果；
7. 不把 0.25D/0.5D 写成所有材料通用最佳值。

### 7.2 补缩距离

**当前代码事实**：
- 没有补缩距离/feeding zone 模型；
- 旧体积校核按整件净重折算，不是 feeding zone；
- 当前没有合金凝固区间、温度梯度、铸型/冷铁条件、允许疏松水平等输入；
- `docs/PHASE_V2.0-02_VOLUME_CHECK_AUDIT.md` 已明确：热点 region ≠ feeding zone，不能用热点体积替代。

**资料依据**：
- Campbell 中译本 `translated.md:9375-9423`：Pellini 湿砂低碳钢板 `L = 4.5T`（2.5T 边缘激冷 + 2.0T 冒口）；冷铁增加约 50 mm；Johnson–Loper 12.5mm+ 平板/棒材公式；数据主要适用于湿砂低碳钢；Al/Cu 可很长甚至“几乎无限”，宽凝固区间合金可能相反；补缩距离定义对允许疏松水平敏感。
- 现代 SFSA / Carlson–Beckermann–Hardin 体系（Beckermann Lab 资料）以 **W/T 多项式**给出钢铸件平板补缩距离；例如端部效应 `FD/T` 和侧向 `LFD/T` 为 W/T 的四次多项式，**FD 从冒口边缘测量**；资料给出的适用范围为 T=1–12 in、W/T≤15，超过 W/T=15 取 `FD/T=9`；冒口直径另行用模数法确定，不由该多项式给出。
- 影响因素包括局部截面厚度 T、宽度/厚度比 W/T、合金与凝固区间、型砂/铸型、浇注过热度、冷铁与冒口布置。**从冒口中心测量与从冒口边缘测量的定义不能混用**；本方案明确采用边缘定义，进入正式计算前必须与原文口径一致。
- 来源：
  - Beckermann Lab, “Relationship between Casting…” PDF:
    https://beckermann.lab.uiowa.edu/sites/beckermann.lab.uiowa.edu/files/2023-10/1999-4.5%20Relationship%20between%20Casting.pdf
  - Beckermann Lab, “Feeding and Rising of High Alloy Steel Castings” PDF:
    https://beckermann.lab.uiowa.edu/sites/beckermann.lab.uiowa.edu/files/2023-10/2003-4.5%20Feeding%20and%20Risering.pdf

> 上述现代多项式在进入正式计算前必须回到原文核对系数、单位、W/T 定义和适用钢种；本阶段不把它们写成生产代码。

**最小可行模型建议（后续单独授权）**：
1. 只做**钢铸件平板**参考模块，明确限定湿砂型/低合金钢/无冷铁或有冷铁；
2. 输入：板厚 T、板宽 W、钢种/凝固区间类别、铸型、冷铁、浇注过热度；
3. 输出：从**冒口边缘**起算的 FD、最大补缩长度、所需冒口数量；超出公式范围时显示“超出适用范围”；
4. 非钢材料、缺少 W/T、宽凝固区间或数据不足时显示“当前条件不足，暂不可靠估算”；
5. 与现有冒口模数/尺寸计算保持清晰接口：只做“经验参考”，不覆盖现有结果；
6. 不以该模块自动改变冒口尺寸；需要真实件基准后再考虑集成。

### 7.3 S11 设计原则（后续实现必须遵守）

- 计算结果与经验参考分开显示；
- 必要输入校验；不满足适用条件不输出假精确值；

- 不用单一比例冒充所有材料通用值；
- 不改现有冒口核心算法，不以新模型覆盖旧结果。
