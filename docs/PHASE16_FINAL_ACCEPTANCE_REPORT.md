## 4. STL 生命周期结果（20.txt 二.10）

- 替换：解析成功→清旧 STL 绑定（几何/热结/STL 派生/旧结果/USER_OVERRIDE 强绑定项）→新分析；USER_INPUT 保留
- 删除：清绑定+结果+会话+sessionStorage 指纹→手动模式（界面明确"未导入 STL"）
- 刷新：stlSessionCheck 检测失效会话→清理+提示重新导入；**物理上不存在"无 STL 但有 STL 参数"**
- localStorage/sessionStorage：指纹只做会话标记，跨会话（新开浏览器）→ 指纹缺失即清理；无污染路径
