## 2. `低压压力` 逐项梳理（全部已复算）

### 2.1 输入 / 输出 / 公式链

| 输入（表内标"需要输入"） | 值 | 单位 |
|---|---|---|
| h1 金属液面→砂箱底部高度 | 68 | cm |
| h2 砂芯高度（砂箱底→顶） | 60 | cm |
| 增加值（结晶增压） | 15 | kPa（表注 10-18） |
| t3 保压时间 | 1200 | s（表注"按照模拟结果"） |

| 公式链 | 表内值 | 复算 | 结论 |
|---|---|---|---|
| `P1 = h1·ρ·K/10200` | 0.018 MPa | 68×2.7×1/10200 = 0.018 | ✅ 0 误差 |
| `p1 = P1×1000` | 18 kPa | 18 | ✅ |
| `t1 = p1/V1` | 15 s | 18/1.2 = 15 | ✅ |
| `ΔP2 = h2·ρ·K/10200` | 0.0190588 MPa | 60×2.7×1.2/10200 = 0.0190588 | ✅ |
| `p2 = p1 + ΔP2` | 37.0588 kPa | 18+19.0588 | ✅ |
| `t2 = ΔP2·1000/V2` | 23.8235 s | 19.0588/0.8 | ✅ |
| `P3 = p2 + 增加值` | 0.0520588 MPa / 52.0588 kPa | 37.0588+15 | ✅ |
| `t3提升 = 增加值/V3` | 12.5 s | 15/1.2 | ✅ |
| `型顶压力(参考) = p2` | 37.0588 kPa | — | ✅ 口径一致 |
| `最终压力(参考) = 5 + p2 + 15` | 57.0588 kPa | — | ✅ |
| Procast P1 点 | (0, 119.325) | 18+101.325 | ✅ |
| Procast P2 点 | (23.8235, 138.384) | 37.0588+101.325 | ✅ |
| Procast P3 点 | (36.3235, 158.384) | 57.0588+101.325 | ✅ |

`10200` 是**单位换算常数**：`ρ[g/cm³] × h[cm] × 9.80665[m/s²] / 1000 = ρ·h/102.0` kPa… 表内取 `ρ·h·K/10200` 直接得 MPa，
等价于 `ρ·h·K·9.80665/1000` kPa ÷ 1000。**常数本身正确**（`1/10200 ≈ 9.804e-5 ≈ 9.80665e-7×100`）。

**单位列系统性标注错误**：体积/表面积一律写 `mm`（应为 `mm³`/`mm²`）。产品化会直接继承这个错误。

**模数判据是本表最有价值、且完全可验证的部分**：`横浇道模数 ≥ 产品模数 × (1.1~1.4)`（原则第 2 条），
算例 0.676 ⇒ **不通过**，备注"不通过则需要增加横浇道模数" —— 判据、阈值、动作三者自洽。

**7 条设计原则**（原文，可作为规则库/检查清单，无需新系数）：
1. 入水口直径 > 入水口壁厚，一般 1~1.3 倍
2. 横浇道直径一般最大壁厚 1.5~2 倍，模数是产品的 1.1~1.4 倍，距离产品 70~90 mm
3. 冷铁一般放下面
4. 冒口要不不要，要不放的特别大
5. 顶部加排气片，8 mm 厚，高 50~70；或顶部加 ⌀3.5 排气孔，高 30
6. 冷铁不是越多越好
7. 厚大位置放下面

## 4. 两个系数的证据状态（143 §二.5 专项检索结果）

### 4.1 检索范围与结果

### 4.2 系数一：`入水口直径 = 入水口壁厚 × 1.2`

- **状态：落在表内文字区间 [1.0, 1.3] 内，但"为什么取 1.2"没有依据。**
- 敏感性（唯一算例 壁厚 72.5 mm）：

| 倍数 | 直径 | 截面积 | 相对 1.2 档 |
|---|---|---|---|
| 1.0（下界） | 72.5 mm | 5,256 mm² | −40% |
| **1.2（表内取值）** | **87.0 mm** | **7,547 mm²** | — |
| 1.3（上界） | 94.25 mm | 8,883 mm² | +18% |

- ★ **区间上下界之间截面积差 1.69 倍（+69%）**。入水口是低压的**阻流截面**，面积差 69% 会直接改变充型速度与
  卷气倾向 —— 这不是可以"取中间值"了事的参数。
- 建议：**产品化时把它做成用户可调参数并显示原则区间**，默认值必须由企业确认；不得把 1.2 写成固定常量。

### 4.3 系数二：`浇注重量 = 产品重量 × 1.8` —— **本轮最需要企业回答的一处**

- **状态：整本工作簿（5 sheet）内没有任何文字或公式依据。**
- 工程含义换算：`1.8 ⟺ 工艺出品率 = 产品重/浇注重量 = 62/111.6 = 55.6%`。
- ★★ **与仓库自有的低压出品率区间直接冲突**（`calcs/yield.js`，项目内既有数据，非我引入）：

| 来源（仓库内 `calcs/yield.js`） | 区间 | 1.8 隐含的 55.6% 是否落在区间内 |
|---|---|---|
| `'轮毂 / 铸铝件' × '低压'` | **75 ~ 85%** | ❌ 低 **19.4 ~ 29.4** 个百分点 |
| `'铝合金(Al)' × '低压'` | **72 ~ 85%** | ❌ 低 **16.4 ~ 29.4** 个百分点 |
| `PROCESS_YIELD['低压']` | **70 ~ 82%** | ❌ 低 **14.4 ~ 26.4** 个百分点 |

- 反推：若出品率取 72~85%，则系数应为 **1.18 ~ 1.39**，而不是 1.8。
- 敏感性（产品重 62 kg 固定）：

| 系数 | 浇注重量 | 隐含出品率 |
|---|---|---|
| 1.18 | 73.2 kg | 85% |
| 1.33 | 82.5 kg | 75% |
| 1.39 | 86.2 kg | 72% |
| **1.8（表内）** | **111.6 kg** | **55.6%** |
| 2.2 | 136.4 kg | 45.5% |

- ⚠ **我不下"1.8 是错的"的结论**，理由有三，必须一并写清：
  1. 仓库的出品率区间是**行业共识数据**，不是本企业的实测数据；
  2. 该 `.xls` **只有 1 个算例**，且是入水口壁厚 72.5 mm 的**特厚大件**（产品重 62 kg），
     出品率偏低在特厚件上是可能的——但表内没有说明它是不是特厚件的专用系数；
  3. 1.8 也可能包含了原则第 5 条要求的排气片等工艺附件重量（表内没有分解）。
- ⇒ 结论应当是：**存在可量化的内部不一致，且这个不一致足以改变浇注系统的全部下游尺寸**，
  必须由企业确认 1.8 是"低压通用系数""本产品专用系数"还是"含工艺附件的口径"。

## 6. 建议的处理方式

### 6.1 立即可做（**不依赖任何未知系数**，且不扩大代码修改范围）

**最小方案：只读"低压压力复算器"** —— 复刻 §2.1 表格中全部带 ✅ 的公式：

- 输入：`h1 / h2 / ρ / K1 / K2 / V1 / V2 / V3 / 增加值 / 壳体增压 / 结晶增压 / t3保压`
- 输出：`P1..P3 / p1..p3 / t1..t3 / 型顶压力 / 最终压力 / Procast 4 点曲线`
- **全部公式可在表内确认**，且已逐格复算 0 误差 ⇒ 可以按"复算器"定位交付
- 必须先修正 §2.2 的 A/D 两处口径（增量 vs 累计、X 轴是否含 t1），并在界面上**显式标注每个取值的口径**
- **不引入 1.8 / 1.2**，因此不触碰任何未经验证的工程常数

**同样可做**：`横浇道模数 ≥ 产品模数 × k`（k ∈ [1.1,1.4] 由用户选，默认不预设）的判据 + 7 条原则清单。

### 6.2 必须先由企业确认（**不得静默写入固定公式**）

1. `浇注重量/产品重量 = 1.8` 的口径与依据（§4.3，附上出品率对比表作为提问材料）。
2. `入水口直径/壁厚` 的推荐取点（原则给 1~1.3，跨度过大，截面积差 69%）。
3. `K` 的两段取值（1 与 1.2）是否应按同一结构复杂度统一。
4. `P3保压压力` 的用途；`K22/K3/K4` 三个速度参数的用途。
5. 是否有**第二种材料的算例**（目前只有 1 个铝合金算例，无法验证系数的材料相关性）。

### 6.3 建议的决策形式

给出一个**"复算器 + 待定参数显式标注"**的形态：
公式确定的部分照实算并标注依据；两处待定系数做成**必须由用户填写、且界面显示"该值无表内依据，请与工艺确认"**的输入项，
默认值留空。这既能让工具立刻可用，又不会把猜测固化成工程常数 —— 符合"数据准确 > 一切"的既有原则。
