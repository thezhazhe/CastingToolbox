# P49 实施报告（50.txt 已确认问题修复）

## 一、修改内容

### 1. P47 浇注时间公式 W 定义修正（50.txt §二.1 / §三）

**修改前**：浇注时间经验公式的 W 误用"浇注重量 G = 单件铸件重量×型腔数÷出品率"。

**修改后**（`calcs/gating.js runGating`）——重量变量职责分离：

```
castingMass (W_c)   = 单件铸件重量 pw × 型腔数 cav     → P47 浇注时间公式 calc_t 的 W（不出品率）
pouringMetalMass G  = W_c ÷ 出品率                     → 奥赞阻流面积 / 流量 Q / A_target / v_final 全部下游
```

- 分档判据随之修正：灰铁 450kg 按 **castingMass**（W≤450 式1/W>450 式2）；球铁 K₁ 分档仍按壁厚
- 新增输出字段 `castingMass`、`boundaryNote`
- Hb 查表仍按 G（浇注重量，企业口径）——不变
- 全部下游检查：奥赞 A、直浇道/横浇道/内浇口参考面积、Q、A_target、v_final 全部消费 G（pouringMetalMass），
  无一处再混用 W_c ✓（49-W1 测试锁定：改 yr 只动 G/A/Q，t 不动）

**公式前后对照**（同一案例，灰铁 pw=46.8×2 件、yr=75、壁厚 20）：
- 修改前：W=124.8kg → t = 0.70(1.41+20/14.59)√124.8 ≈ 21.8s（且 yr 改变会连带 t 变化）
- 修改后：W_c=93.6kg → t = 0.70(1.41+20/14.59)√93.6 ≈ 18.8s（与 yr 无关；与企业 Excel K11 用 F3=毛重×件数口径一致）

### 3. 内浇口方形长度取整 round → ceil（50.txt §十五）

**修改前**：L = max(5, round(A/(个数×厚度)/5)×5)——round 向下可致 Fg < 目标面积（实测最坏 F/A=0.73，v 被顶高 +36%）。

**修改后**：L = max(5, ceil(A_rec/(个数×厚度)/5)×5)——**目标面积驱动的尺寸一律 ceil，实际面积不得小于目标面积**。
（圆形直径原本即 ceil；未增加任何未经验证的硬性尺寸上限。）
