## ① 3D 砂型吃砂量（sandbox）

**入口**：3D砂型吃砂量。模块 `calcs/sandbox.js` + 数据 `data/sandbox_calc.js`（企业规范《铸造铝合金3D打印砂型工艺设计规范》，3D 打印砂型专用，勿套传统造型）+ smallCalcs 视图。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 造型方式 | 埋箱（树脂砂埋箱，默认）/ 裸浇 |
| 砂型最大轮廓尺寸 dim | mm（默认 800） |
| 砂型重量 wt（埋箱时） | Kg（默认 300） |
| 铸件高度 castH + 静水压头高度 headH（裸浇时） | mm（默认 200/300） |

### (b) 结果输出
- 埋箱：非承重壁厚（恒定 30mm）+ 承重壁厚（查表值或超表保守值）+ 查表依据行；超出表范围（轮廓>2000mm 或重量>1800kg）时给「同尺寸段承重上限」保守值并红字提示按强度评估
- 裸浇：侧壁吃砂量（含推导过程文本）+ 底面吃砂量（1.5× 侧壁）+ 高度/压头显示
- 两种模式都显示：砂型最小壁厚（轮廓 <100mm → 8mm；100~4000mm → 30mm）
- 模式提示行（埋箱=强度由箱砂承担；裸浇芯包轮廓应 ≤1200×1200）

### (c) 中间计算过程
1. `minWall`：dim <100 → 8mm，否则 30mm（表5）
2. 埋箱查表（表3，20 档：dimLo<dim≤dimHi 且 wtLo<wt≤wtHi）：承重档从 40mm 到 160mm；未命中 → 同尺寸段内 load 最大值作保守参考 + 警告
3. 裸浇：`sideRaw = 溃散层5 + (headH − castH)`；`side = max(40, sideRaw)`；`bottom = round(side×1.5)`

### (d) 输出逻辑（为什么）
- **两种模式物理工况不同**：埋箱砂型外面有箱砂承托，浇注冲击由箱砂/外型承担，吃砂量只需满足砂型**自身强度**（翻转/施涂/转运）→ 查「轮廓×重量」强度表；裸浇砂型直接面对金属液冲击，吃砂量必须**同时抗冲击** → 用静水压头（决定冲击压力）与铸件高度的差换算所需壁厚 + 溃散层
- **为什么压头高度减去铸件高度**：侧壁吃砂量只需承受"压头超出铸件顶面那一段"的附加压力（铸件高度内壁厚由铸件-型腔形状决定），压头越高、差值越大，侧壁越厚
- **溃散层 5mm**：3D 打印砂受热表面溃散一层，实际承力截面要扣除
- **底面 1.5× 侧壁**：底面承托整个型+金属液总重，且受热面大，规范取 1.5 倍
- **非承重壁恒 30mm**：只是自承重薄壳，与强度表分开；承重壁才按重量分档
- 表数据为企业规范（脱敏）；明确声明范围限制与"勿套传统造型"（打印砂强度仅 6±1MPa）

## ② 尺寸公差 CT 查询（ct）

**入口**：尺寸公差 CT 查询。模块 `calcs/ct.js` + 数据 `data/ct_calc.js`（GB/T 6414-2017，≈ISO 8062-3，CT/DCTG 同值）。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 基本尺寸（毛坯） | mm（默认 120） |
| CT 等级 | CT1~CT16 直接选（图纸已标注时）；或「方法×材质」查推荐后点「填入推荐」 |
| 是否壁厚 | 是 → 自动粗一级 |
| （辅助）铸造方法 × 材质 → 推荐区间 | 5 方法 × 5 材质，点按钮填入中档等级 |

### (b) 结果输出
- 总公差值（mm）+ 上/下偏差（对称 ±公差/2）+ 等级 + 尺寸档区间
- 壁厚选择时：壁厚公差行（粗一级，如 CT8 → CT9 值）
- 尺寸 ≤16mm 段不采用 CT13~16 → 明确提示（"须个别标注"）
- 辅助行显示推荐区间（如"推荐等级：CT10~13（砂型取松、压铸/熔模取紧）"）
- 标注示例行（GB/T 6414—CT10 · 120⁺¹·⁸₋₀·₈）
- 结果区旁完整展示 16 级 × 16 尺寸档数值表供人工查阅

### (c) 中间计算过程
1. `lookupCTRow(size)`：查行区间 (lo, hi]，首行即 ≤10mm；超 10000mm → null
2. `ctTolerance(size, grade)`：等级归一（'11'→CT11）→ 查该行该级值；值 null（该段不采用）或等级不存在 → null
3. 壁厚：等级 +1 级（CT16 时越界 → 提示按图纸标注）
4. 推荐填入：区间串（如 "8~10"）→ 解析全部等级 → 取**中档等级**填入选框（如 CT9）

### (d) 输出逻辑（为什么）
- **图纸已标等级就只做查表**：CT 等级由铸造方法+材质+批量决定，图纸标了说明设计已定——工具不替代设计师，只把等级×尺寸翻译成 ± 偏差值
- **没标等级才给推荐**：推荐区间按「方法×材质」从 GB/T 6414 表3 取（砂型手工 10~13 级粗、机器造型 8~10、金属型 7~9、压铸 4~7、熔模 4~7 的格局）——**砂型取松、压铸/熔模取紧**是标准原文精神
- **为什么填"中档"而非最紧**：推荐区间是"通常可达到范围"，取中档代表该工艺的代表性水平；批量大可再提两级（UI 注明）
- **壁厚粗一级**：铸件壁厚在砂型中尺寸波动大于一般尺寸（厚度方向受型芯/漂移影响），GB/T 6414 规定壁厚公差粗一级（壁厚 ≤1.2mm 特例可同级）——工具对"是壁厚"输入自动 +1 级，属标准规则落地
- **≤16mm 段与 CT13~16 不采用**：标准规定该段不采用粗等级（对薄小件粗等级公差超过尺寸本身无意义），须个别标注——工具如实返回"不采用"而非硬算一个值
- 数据 16 档数值逐档对照多方来源核对过（数据文件注释声明）；不同材质统一引用 GB/T 6414（差异在可达到等级不在数值表）

## ③ 熔炼加料计算（charge）

**入口**：熔炼加料计算。模块 `calcs/charge.js` + 数据 `data/charge_calc.js` + `js/views/chargeCalc.js`（功能最重的查算工具之一）。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 材质牌号 | HT150/200/250 · QT400-18/450-10/500-7/600-3/700-2（首批） |
| 铁液总重 | Kg（默认 1000） |
| 生铁/废钢/回炉料 | **百分比%** 输入（自动折算 kg，显示合计应≈100%）；每行可选规格（生铁 6 种/废钢 2 种）、可「自定义」填本厂成分（C/Si/Mn/P/S）、吸收率可改（生铁/废钢默认 90%、回炉料 UI 默认 95%） |
| 合金与增碳 | 增碳剂/硅铁/锰铁按 **kg** 输入（可选规格或自定义）；默认 0 |
| 球化剂/孕育剂（仅球铁牌号显示） | kg 输入，默认=总重×1.3% / ×0.6%；吸收率 Mg45/RE55/Si80、孕育 Si85 可改 |
| （默认配比随牌号自动装填） | 灰铁：Z18 生铁 20% + 废钢 40% + 回炉 40%；球铁：Q10 生铁 30% + 球铁废钢 30% + 回炉 40% |

### (b) 结果输出
- 目标基准行（灰铁=目标成分；球铁=原铁液目标，已扣球化/孕育硅）
- 五行成分平衡：C/Si/Mn/P/S 各一行——目标 %、计算（原铁液）%、差额（目标−计算，正=缺）
- 碳当量 CE = C+0.33(Si+P)（计算值 + 目标区间，如 3.7~4.1）
- 球铁附加「成铁成分预估」行：C/Si/Mn/Mg/RE（含处理剂带入）
- 补料建议：差额 >0.05% 的元素给出建议补料量（增碳剂/硅铁/锰铁，带「应用」按钮一键填入该合金输入框）；无差额时显示 ✅ 达标
- 生成配方记录（报告弹窗：配比/成分平衡/补料/依据）

### (c) 中间计算过程
1. 回炉料成分 = **本牌号成品成分**（灰铁=目标成分；球铁=成铁成分：Si 用成铁 SiF、含残留 Mg）——回炉料就是上一炉的成品金属
2. `base[el] = Σ(各料 kg × 元素% × 吸收率) / 铁液总重`——生铁/废钢/回炉料/合金/增碳剂全部计入
3. 球化/孕育带入（球铁）：`add.Mg = 球化剂kg/总重 × Mg% × 0.45`；`add.RE = … × RE% × 0.55`；`add.Si = 球化剂Si带入×0.80 + 孕育剂Si带入×0.85`
4. `final = base + add`；差额 `diff = 目标 − base`（**对原铁液**，因目标本身是"原铁液目标"）
5. 补料建议：`diff>0.05%` → `kg = diff%×总重 ÷ (合金含量%×吸收率)`，按当前所选合金规格计；0.05% 内视为达标（allOk）

### (d) 输出逻辑（为什么）
- **金属炉料按%、合金按 kg 分栏**：炉料是"配方"（百分比是铁液总重的配比，直观且便于缩放），合金/处理剂是按炉实际称量的少量辅料（kg 直输）；两栏各自符合炉前习惯
- **分母=铁液总重而非炉料总重**：成分定义按"占铁液"计（金相/光谱取样也按铁液），炉料合计≈100% 时两种口径等价；合金 kg 直接加入使炉料总重略超 100% → base 轻微稀释（近似口径，报告提示）——差额显示真实方向，补料迭代一次即可收敛
- **吸收率为什么可改且必要**：元素入炉有烧损/未熔（Si/Mn 尤甚），手册给的是典型值（无芯感应炉中值），各厂炉况不同——放行级修改是实用设计；默认值有出处（《铸造工程师手册 第3版》表3-316），数据注释还标注了**弃用的可疑值**（FeMo 50~55% 偏低、网络 Cr 烧损 39.4% 与惯例矛盾——不用）
- **球铁为什么"原铁液目标已扣硅"**：球化剂+孕育剂会带入大量 Si（1.3%×45%×80% + 0.6%×75%×85% ≈ 0.85% 有效硅），若原铁液直接对准成铁 Si，处理后就超了——所以目标表里球铁 Si（如 QT500-7 的 1.55%）是"处理前的炉内目标"，成铁 Si 是 SiF（2.45%）。差额口径因此对 base（原铁液）——这正是视图"目标=原铁液目标 · 差额=目标−计算"的含义
- **差额>0.05% 才建议补料**：0.05% 是炉前光谱/取样精度内的合理容差，避免为 0.03% 的偏差反复加减料
- **回炉料用成品成分**：本厂回炉料=浇冒口+废品，化学成分就是成品成分（球铁含 Mg），不是生铁/废钢成分——这是很多加料表算不准的常见原因，数据层用 returnComposition 单独处理
- 球化剂默认 1.3% + 孕育 0.6% 为库内脱敏案例值，UI 允许按本厂调；牌号表首批 8 个，扩展留接口（数据文件注明"批B 扩展"）

## ④ 开箱时间（shakeout）

**入口**：开箱时间。模块 `calcs/shakeout.js` + 数据 `data/shakeout_calc.js`（《实用铸造手册》冷却时间表 + 多源开箱温度）。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 材质 | 灰铁/球铁/铸钢/铝/铜 |
| 铸件重量 / 壁厚 | Kg / mm（默认 50 / 20） |
| 造型方式 | 流水线（×0.65）/ 地面（×1.0，默认） |
| 铸件风险 | 一般 / 复杂（壁厚差大，×1.30）/ 易裂（×1.15） |
| 铸件重要性 | 一般 / 重要（×1.10，开箱温度 ≤250℃） |
| 开箱后做热时效？ | 否 / 是（×0.85，温度放宽） |
| 开箱温度目标（可改） | 默认按「材质×热时效×重要性」自动预填，可改成本厂规定值 |

### (b) 结果输出
- 建议开箱时间（中小件 min，>60min 附换算 h；大件直接 h）+ 查询档位行（重量/壁厚档 → 基础时间）
- 开箱温度目标（如 "≤200℃"）及来源说明（默认/重要件上限/热时效放宽/易裂特例/自定义）
- 调整明细行（各系数 ×）
- 风险提示（红）：壁厚超档延长 30%、易裂件高温开箱必须缓冷、自定义温度过严/过高警告、材质常规警告（灰铁防白口 ≤200℃ 等）、大件建议热电偶实测
- 生成计算记录

### (c) 中间计算过程
1. 综合调整系数 `adj = 造型方式 × 热时效 × 风险 × 重要性` 四因子相乘
2. 分表查时：
   - **大件**（重量 ≥1000kg）：t=吨位查 COOL_LARGE（1~100t → 10~270h），`时间 = h × adj`（单值）
   - **中小件**：重量查 COOL_SMALL（8 档：<5kg/20~30min … <1000kg/480~720min），`时间范围 = [min×adj, max×adj]` 取整；**壁厚超过本档典型壁厚 tMax → 警告建议再延长 ~30%**；重量超 1000kg 且大件表无档（>100t）→ 返回空（视图提示实测）
3. 开箱温度目标分派：
   - 易裂 → "800~900℃（高温开箱→去浇冒口→砂坑缓冷）"特例
   - 一般+重要 → `min(250, 材质noHT)`；热时效 → 材质 withHT；否则 → noHT（灰铁 200/球铁 300/铸钢 250/铝 80/铜 200）
   - 用户自定 → 与默认比较：更严 → 建议延长 20~30%；超常规上限 → 风险警告；不热时效 → 材质常规警告

### (d) 输出逻辑（为什么）
- **为什么用经验表而不用凝固系数 k 计算**：k 值各手册差异极大（灰铁 0.7 vs 球铁 2.0 与糊状凝固事实相悖），公式化反而不可靠——直接采用权威手册实测经验表（工具说明里明示了这一取舍）
- **四因子相乘**：每项调整独立（流水线早开箱、热时效早开箱、复杂/易裂晚开、重要件保守），物理上互不冲突故相乘而非相加
- **流水线 ×0.65**：线体节拍要求高温开箱，冷却时间可大幅缩短（但温度目标相应提高）
- **热时效的本质**：热时效=开箱后的去应力退火。要做就不怕开箱残存内应力 → 温度放宽（200→300℃）时间缩短；**不做则必须低温开箱防内应力/白口**——这一步决定整个温度目标体系，故独立成输入
- **易裂件倒过来 800~900℃ 高温开箱**：热应力开裂风险件要在脆性温度区间前开箱去浇冒口，然后砂坑缓冷——与"低温开箱防应力"是两套逻辑（防开裂 vs 防残应力），工具分派特例避免冲突
- **壁厚超档只警告不硬算**：重量档内典型壁厚是表的隐含前提，壁厚超了说明件"厚而轻"，冷却时间表低估——给 30% 延长建议并保留人工判断
- 开箱温度目标默认值与材质相关并注明"须按本厂实测修正"

## ⑤ 铸件结构工艺性（castability）

**入口**：铸件结构工艺性。模块 `calcs/castability.js`（数据：铸造工程师手册 + JB/T 5105-2022 等）+ smallCalcs 视图。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 材质 | 铸钢/灰铁/球铁/可锻/铝/铜 |
| 铸件最大轮廓尺寸 | mm（默认 300，决定壁厚分档） |
| 两相连壁厚度 w1 × w2 | mm（默认 10×14，算圆角用，自动取均值） |
| 生产批量 | 大量/成批/单件小批（决定最小铸出孔） |
| 起模面高度 H | mm（默认 50） |
| 模样材质 | 金属/塑料 / 木模 |
| 造型方式 | 6 种砂种自动归入「粘土砂/自硬砂」两类 |

### (b) 结果输出
- 最小壁厚建议（范围文本+分档说明）与**临界壁厚**（≈3×最小中值）
- 铸造圆角：外 R（1/5~1/3 均值）/ 内 R（1/3~1/2 均值），各带范围说明
- 拔模斜度：外壁角度（如 "1°30′"）/ 内壁角度 / 铸孔 1°~4°，注明 H/模样/砂种依据与归入类别
- 最小铸出孔（按材质×批量查表；无表材质给说明行）
- 灰铁附加按牌号最小壁厚提示行（HT100~HT400）
- 材质设计提示行（收缩/流动性/氧化特性一句话）
- 说明区附完整参考表（壁厚分档表/拔模工艺快速参考表）

### (c) 中间计算过程
1. 壁厚分档：轮廓 ≤200/≤500/>500 → 表值（如灰铁 3~4 / 5~7 / 8~12）；`mid = 范围中值`；`临界 = round(3×mid)`（一位小数）
2. 圆角：`avg=(w1+w2)/2`；外 R = max(2, round(avg/4))（≈均值 1/4，落在 1/5~1/3 内）；内 R = max(3, round(avg/2.5))（≈0.4×avg，落在 1/3~1/2 内）；同时输出两端范围文本
3. 拔模斜度：砂种归类（潮模/干型→粘土砂；树脂/水玻璃/覆膜→自硬砂；其他→粘土砂取小）→ 按「高度 ≤10/40/100/160/250/400/630/1000mm 档 × 模样（金属 或 木模）」查表（分 ' 单位）
   - 粘土砂：外壁金属模 140′~15′ 随高度递减 / 木模更缓；内壁用独立内壁表（更大，摩擦大）
   - 自硬砂：外壁查自硬表；**内壁 = 外壁 ×1.5**（JB 表3 规则）
4. 最小铸孔：材质×批量查表（如 灰铁 大量 12~15 / 成批 15~30 / 单件 30~50mm；球铁同灰铁；铸钢成批 30~50 单件 ≥50）

### (d) 输出逻辑（为什么）
- **一个工具五类"结构性参数"一次给全**：设计画图阶段最常要查的工艺性边界——壁厚（能不能铸出来）、圆角（避免应力集中/裂纹）、拔模（能不能起模）、铸孔（要不要先钻孔）——按同一套输入一次性输出，减少翻手册次数
- **最小/临界/适宜三区间逻辑**：小于最小壁厚=浇不进去（冷隔/浇不足）；最小~临界=适宜区间；超过临界=内部补缩困难（缩松）+ 厚薄过渡裂纹——输出刻意同时给"最小"与"临界"，让设计把壁厚控制在中段
- **圆角按"两相连壁均值"**：圆角半径的工程依据是相邻壁厚过渡（不是铸件整体尺寸）——UI 让用户填 T 字筋两腿的各自厚度，自动取均值；外/内圆角不对称：内圆角应力集中更甚且形成热节风险，故内 R 大于外 R（1/3~1/2 vs 1/5~1/3）
- **拔模斜度为什么随高度递减**：起模面越高，同样的角度产生的放尺/偏差越大，JB/T 5105 按高度分 8 档递减——木模比金属模大（木模表面粗糙、起模阻力大）；自硬砂整体更大（固化后型壁更硬，起模更易擦伤）且内壁再 +50%
- **自硬砂内壁 +50% 是标准规则**：表3 只给外表面，内表面按表值增加 50%——代码直接执行而不臆造内壁表
- **最小铸孔随批量变**：单件小批宁可钻孔（铸孔要下芯/型芯成本高），大量生产用铸出孔分摊成本划算——批量越大可铸孔越小
- 可锻铸铁最小壁厚参照灰铁并偏小、最小铸孔参照灰铁——数据文件注明映射

## ⑥ 缺陷查找（defect_finder）

**入口**：缺陷查找（🩹，第 8 个计算工具）。模块 `js/defect.js`（searchDefects）+ `data/defects.js`（分类/别名）+ `data/defects/*.json`（正文）+ 视图 `defectFinder.js`。**性质：知识检索工具（非数值计算）**。

### (a) 用户输入
| 字段 | 含义 |
|---|---|
| 描述问题（查询词） | 缺陷名 / 俗称 / 症状自由文本（如"缩松""气孔""上表面 圆形孔洞"），可空 |
| 材质过滤 | 全部材质 / 灰铁/球铁/铸钢/铝/铜（当前生产场景自动预选） |
| 分类过滤 chips | GB/T 5611 八大类 + 各类计数（全部/多肉/孔洞/裂纹/表面/成分…） |

### (b) 结果输出
- 命中缺陷列表：标题 + 所属分类 chip + 置信度徽标（🟢 高/🟡 中高/🟠 中）+ 典型现象（首条症状）+ 元信息（出处书籍 · 原因 N 条 · 对策 M 条 · 命中方式「按名称/俗称/关键词/按内容」）
- 空查询 = 按分类顺序全部浏览（含总数徽标）；无命中给空状态提示
- 点击条目 → `#/search/<id>` **完整工艺卡片**（特征/原因/对策/检验 + 相关标准/相关计算工具/相关知识），返回时自动恢复搜索状态（查询词/材质/分类）

### (c) 中间计算过程（匹配引擎 searchDefects）
1. 数据加载 `defectDocs()`（defects.js 索引 + defects/*.json 正文）
2. 预过滤：材质标签（`TAGS` 中 `mat:xxx`）+ 分类
3. 空查询 → 直接返回全列表（按分类排序展示）
4. 分词：查询按空格/逗号/顿号/斜杠拆 tokens
5. 逐文档打分（只取最高分档）：
   - **100 分**：别名表（DEFECT_ALIASES，俗称如"呛火"）命中任一 token
   - **60 分**：标题包含 token
   - **40 分**：关键词表包含/被包含
   - **20 分**：全部 tokens 都出现在正文 JSON 中（内容级匹配）
   - 0 分不命中
6. 按分数降序输出

### (d) 输出逻辑（为什么）
- **为什么有四级命中方式**：现场工人常用俗称/症状描述而非标准名——别名表（呛火/砂眼/鼠尾…）给最高权重；标题>关键词>全文的降级保证"标准名命中优先、模糊内容命中兜底"，分数还暴露给用户（"按名称/俗称"让结果可解释）
- **全文匹配要求"全部 token"**：多词查询如"上表面 圆形孔洞"须两词都出现在正文才命中——防止只沾一个词的大量噪音；宁可少而准
- **置信度徽标分级**：每条对策带置信度（🟢 一手/官方 · 🟡 标准成熟值 · 🟠 二手整理），出处见卡片——工程知识检索必须让用户知道依据强弱
- **分类/材质过滤先行**：八大类 GB/T 5611 + 材质标签把搜索空间先收敛到相关缺陷族，提升命中率；材质还自动取当前生产场景（少一次选择）
- 状态恢复（sessionStorage）：从详情卡片返回时保留检索现场，避免"查一次翻一次"的重复劳动
