## 2. 修改内容（数据流变化）

**改前（48-B/P49）**：几何恒按 A_rec=max(A_gt, A_target) 生成 → 超速工况默认自动放大。
**改后（P50）**：
```
默认（不点击）: 几何按 A_gt（基础奥赞设计）→ Fg 基础 → v_gate 超目标 → ⚠️ 偏高 + [按目标速度优化]
点击按钮:      runGating({...输入, optimize:true}) → 几何按 A_rec → Fg↑ → v_gate↓ ≤ 目标 ✅
```
- A_target/A_rec/vTheory/vState 等字段与公式**全部保留**（50.txt §五 不回滚）
- 数量/形状/厚度：用户选择不变（几何函数同一套，只换面积基准）
- 取整：沿用 P49 ceil（A_actual ≥ A_optimized 有测试锁定）
- 确认弹窗阈值 1.5× 代码注释与文案均标注"界面提示阈值（非工程标准）"

## 5. 与 P49 基线的行为差异（如实声明）

**唯一差异**：默认（不点击）内浇口几何基准从 A_rec（自动放大）回到 A_gt（基础奥赞设计）——
超速工况默认显示"基础面积+偏高提示+按钮"，不再自动放大。这正是 51.txt §4.1/§11 明确要求
（"不要因为速度超过目标值就自动把面积改大；用户主动点击才执行"），非顺带改动。
其余（t/G/Q/choke/直浇道/横浇道/排气/边界提示/W_c 分离等）与 P49 完全一致。
