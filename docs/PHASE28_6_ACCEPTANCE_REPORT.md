## 4. C. P1-13 自交检测（43.txt 四）

### 4.1 实现

```
validateMesh 第 5 节：
  分箱加速：均匀网格（N=min(32, cbrt(triCount))）→ 三角 bbox 覆盖格登记（非暴力 O(n²)）
  候选对：同格去重（数值 pk）+ bbox 预筛 + 邻接排除（共享顶点=正常相邻）→ Möller–Trumbore 线段-三角（6 边）
  相交判定：参数 t∈(1e-8, 1-1e-8) 才计穿越（端点接触=相切不算）；det 相对容差 1e-12·D³
  截断保护：非邻接候选对 > 250 万 → 返回 truncated（SELF_INTERSECTION_UNCHECKED——不假装检测完成）
```

### 4.2 问题区分（43.txt 四：不归为一个"坏网格"）

| code | 语义 | 触发 |
|---|---|---|
| `SELF_INTERSECTION` | 非相邻三角形穿越相交 | MT 命中（独立检出，不与 OPEN_MESH 等合并） |
| `SELF_INTERSECTION_UNCHECKED` | 检测未完成（候选对超上限） | 超大/病态模型（如实告知，不假装无自交） |
| `NON_MANIFOLD_EDGE` | 非流形边（c>2） | 双体焊接等 |
| `OPEN_MESH` | 边界边 | 开口 |
| `INCONSISTENT_WINDING` | 缠绕方向不一致 | 有向边冲突 |

### 4.5 关键实现教训（本次修的两个坑）

1. **Set 爆炸崩溃**：候选对 Set 首版在 bbox 预筛前 → 大模型 RangeError 崩溃。修复=bbox 预筛 + 邻接排除提前（壳体网格相邻占 85%+）+ 数值 pk + 上限截断。
2. **斜置误报 UNCHECKED**：45° 旋转网格三角 AABB 膨胀 √2 → bbox 重叠对 15万→109万（7 倍）→ 超过首版 100 万上限 → 干净模型被误标"可能有自交"。修复=邻接排除提前（非邻接候选 95.8 万 < 250 万新上限）+ 上限按实测最坏值设定。**教训**：检测上限必须覆盖"任意旋转 + 壳体类"最坏场景，否则干净模型被误报。
