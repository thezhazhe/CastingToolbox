## 1. Executive Summary

Casting Toolbox 的 13 个计算器中，**查表/知识型工具（shrinkage 数值表、machining RMA、ct、yield 出品率表、sandbox、castability、chill 系数、shakeout 经验表）总体质量良好**，标准引用与数值大多可溯源（GB/T 6414-2017 数值逐档核对一致）。**问题集中在两个"核心计算型"工具——浇注系统（gating）与冒口（riser）——以及它们与项目参数的数据链上**：

- **P0×3（本次新确认）**：
  1. **yield.riserWt 单位换算错误 1000 倍**（`Vr(mm³)×rho(g/cm³)/1000` 结果单位是 g，UI 标 kg）——结果中心与工艺报告直接展示错误冒口重量，且与同屏"冒口体积"（已正确 /1000）自相矛盾（calcManifest.js:141 → resultsCenter.js:71 / reportGenerator.js:69）
  2. **gating 中注 Hp 公式与权威文献形式不符**（默认 rh=0 时 P 项 =1.5C 而非文献 C/2，实测 A 偏差 +31%，Hp 小时直接无结果）——中注是最常见浇注方式之一（calcManifest.js:83 → gating.js:69）
  3. **浇注重量 pw 语义与出品率表错位风险**：STL 净重（无加工余量）÷出品率表（行业表按含余量毛坯统计）→ G 系统性偏小（gating.js:109）
- **P0（PHASE 27-A 已列，本阶段补充工程定性）**：密度三处不一致（gating 7.5 液态偏高 / riser 7.8 固态合理 / 项目 7.0），本质是"液态密度与固态密度混用一个参数"
- **P1×12**：gating fv 系统性偏大（顶注 0.8 超文献封闭式上限 0.75）；Dietert 公式变体来源未确认（√G+∛(wG/5)）×2/3 未在权威文献找到原形；chill 有热结时 T=2×热结M 语义错误（圆柱热结应 T=D 而非 D/2）；riser 体积校核漏冒口自身收缩（文献 εv(V件+V冒)≤ηV冒）；machining method 声明不生效（硬编码砂型·机器造型）；shakeout 全部调整系数死代码（mode/heatTreat/risk/importance 硬编码）；charge 铸钢/铝/铜静默无结果（CHARGE_TARGETS 无对应牌号）；线收缩率按绝对尺寸取率不科学（注释自相矛盾）；COOL_SMALL 冷却时间表不分材质；sandbox 输入铸件重 vs 表语义砂型重待确认；非 90° 旋转热结退化（PHASE 25 遗留）；castability/ct 不读 STL（PHASE 27-A 已列）
- **已验证正确（重要，防止误伤）**：奥赞常数 71.47（Hp mm 体系数值验证与文献 0.31 式一致 ±0.2%）；顶注 Hp；RMA 表数值/单侧/顶面降一级；CT 表全部 16 级数值；冒口效率 14/20/35 在文献范围；冒口颈 1.1×Mc、d=4M；内冷铁 0.3~0.5T；CE=C+0.33(Si+P)；Vc 单位 mm³ 正确

**整体评级：B-**（工程师辅助工具，浇注系统与冒口的关键输出需人工复核；查表类工具可直接使用）

## 2. 当前整体可靠性评级

> 只考虑"计算结果是否值得工程师信任"，不考虑 UI。

### 评级：B —— 可以作为工程师辅助工具，但浇注系统/冒口关键参数需要人工复核

**理由**：

| 维度 | 评级 | 说明 |
|---|---|---|
| 几何数据链（体积/重量/尺寸） | A | STL 三角积分精确（闭合流形前提下）；重量换算已验证 |
| 查表型工具（RMA/CT/出品率/开箱温度） | B+ | 标准数值准确（GB/T 6414 等），表本身为经验范围，属正常工程用法 |
| 浇注系统（gating） | **C+** | fv 偏大 + 中注 Hp 公式错误 + Dietert 变体来源不明，A 值偏差 20~50% 方向不唯一，且出厂率错位 |
| 冒口（riser） | B- | 模数法框架正确（f 迭代/效率/冒口颈均有文献依据），但体积校核简化、球铁适用性存疑、形状选择不生效 |
| 冷铁/砂型/加料/开箱 | B | 框架合理，经验表来源明确（D 级来源本身不构成错误） |
| 知识型（castability/ct 视图） | B+ | 手册值+标准，质量好；起模斜度数值待人工核对 |

**为什么不是 A**：gating 是"最高优先级"计算器，但其 3 个核心公式中有 2 个（Hp 中注、Dietert 变体）来源存疑，1 个（fv）系统性偏大，当前输出不能直接用于生产。

**为什么不是 C/D**：修正方向明确且代价小（fv 改文献表、中注 Hp 改文献式、riserWt 除 1e6），修完后 gating/riser 可达 B+ 级；查表类工具没有发现方向性错误。

### 3.1 gating — 浇注系统设计 ★ 最高优先级

**① 工程目的**：给定铸件重量、材料、浇注方式，算出浇注重量 G、浇注时间 t、阻流截面积 A，并按浇道比分配直/横/内浇道尺寸，校核流速与排气。

**② 当前输入**（runGating，gating.js:86-97；参数来自 calcManifest.js:55-62）：
| 参数 | 变量 | 单位 | 来源 | 合理性 |
|---|---|---|---|---|
| 材料大类 | mat | — | 项目 material.family | ✓ |
| 铸件重量 | pw | kg | **geometry.weightKg（STL 净重）** | ⚠️ 应为"含加工余量毛坯重"，见 P0-3 |
| 一模件数 | cav | 件 | production.cavities | ✓ |
| 主体壁厚 | wall | mm | process.wallUsed=bodyRef（PHASE 26） | ✓ 比 wallMain 可信 |
| 浇注方向 | pos | — | process.pourPos | ✓ |
| 内浇道至上箱面距离 | Ho | mm | process.Ho | ⚠️ 定义与公式需求需核对（见 3.1④） |
| 铸件高度（浇注方向） | ph | mm | process.ph | ✓（PHASE 27-A P1：可由 bbox 自动建议） |
| 预估出品率 | yr | % | material.yieldSug（默认 70） | ✓ |
| 内浇口位置 rh | rh | — | **硬编码 0**（calcManifest.js:83） | ⚠️ UI 无此输入 |

**③ 当前公式**（全部还原自 gating.js）：

```
G     = pw × cav ÷ yv                                          (gating.js:109)
Cmm   = ph + rh
Hb    = 查表(G)：<10→150 / <50→200 / <200→250 / <1000→300 / <3000→500 / <8000→750 / else 1100  (gating.js:51)
Pv    = 顶注 0 / 中注 Cmm/2 / 底注 Cmm                          (gating.js:114)
Hp    = 顶注: Ho+Hb/2 − rh²/(2C)                               (gating.js:68)
        中注: Ho+Hb/2 − (Pv+Cmm−rh)²/(2Cmm)                    ← 与文献不符，P0-2
        底注: Ho+Hb/2 − Ho/2                                    ← 隐含 Ho≈Cmm 假设，P1
fv    = 顶注 0.8 / 中注 0.6 / 底注 0.45                         (gating.js:117)
t     = fc × (√G + ∛(w×G/5)) × 2/3   [Dietert 变体]           (gating.js:63)  ← 来源未确认，P1
A     = 71.47 × G / (ρ×t×fv×√Hp) × 100                        (gating.js:74)  ← 数值验证 ✓
A_sp/A_run/A_gt = A × (该组元比/最小比)                         (gating.js:123-126)
v     = 10×G/(t×ρ×Fg/100)，校核 ≤1.8 m/s                       (gating.js:81,158)
排气  = (π·vrd²/4·vrc + vsw·vst·vsc) / Fs_act ≥ 1.5            (gating.js:163-165)
```

**④ 公式正确性**：
- **G**：数学正确（G=铸件重/出品率 是出品率的定义式），见 P0-3 的语义错位问题。
- **t（Dietert）**：经典 Dietert 为 `t=S·√G`（S 按壁厚取 1.63/1.85/2.2，适用 ≤450kg），另有中大型件 `t=S₁·∛(δG)`（S₁=2 或 1.7~1.9）。**代码的 √G+∛(wG/5)×2/3 形式在权威文献中未找到原形**（多源检索：教材、教学 PPT、俄文奥赞-迪台尔特法讲义均无此式），且 f 为"材质系数"（0.8~1.2），与经典公式中 f/S 作为"壁厚系数"（1.63~2.2）语义完全不同。数值对照（100kg 铸铁、壁厚 10mm）：代码 10.6s vs 经典 S√G=18.5s vs 经验表 4~6s——三者差 2~4 倍，属"范围很宽的工程估算"，但代码形式无出处。**【存在问题】**
- **Hp 顶注**：rh=0 时 =Ho+Hb/2=H0，与文献 Hp=H0−P²/2C（P=0）一致 ✓。
- **Hp 中注**：代码 P 项=(Pv+C−rh)，默认 rh=0、Pv=C/2 时 P 项=1.5C；文献中注（内浇口在型腔中部）P=C/2 → P 项=C/2。**实测（C=100、Ho=150）：Hp 代码 137.5mm vs 文献 237.5mm → A 偏大 31%**；当 Ho<1.125C 时 Hp≤0，calc_A 直接返回 0（gating.js:75）→ 全结果清零。**【存在问题：P0-2】**
- **Hp 底注**：代码=H0−Ho/2，文献=H0−C/2。仅当 Ho≈C 时一致（实测 C=100、Ho=150 时差 25mm，A 差 6.5%）。Ho 的 UI 定义是"内浇道至上箱面距离"，底注时通常 Ho≈铸件高度 ✓ 近似成立。**【基本正确但有条件】**
- **A（奥赞）**：与文献通式 A=m/(ρμt√(2gHp)) 及铸铁简化式 A=G/(0.31μt√Hp)（Hp 以 cm）**数值交叉验证一致**（实测 1404 vs 1402 mm²，±0.2%），常数 71.47 在 Hp 用 mm 时正确。**【正确】**
- **v 校核**：v=10G/(tρFg/100) 量纲：G kg×10/(t×ρ×Fg/100)=kg×10×100/(s·g/cm³·mm²)。单位换算（kg→g、mm²→cm²）后 v(m/s)=G/(ρ·t·A_cm²)/10？ 实测与常见式 v=G/(ρ·t·ΣF)（cm/s 量级）可对上（10 倍系数含 mm²→cm²=100 与 m/s 换算 1/10）。算例：G=100、t=10、ρ=7、Fg=400mm² → 10×100/(10×7×4)=3.57 m/s（Fg 单位 cm² 时 4cm²）→ 与常见 v=G/(ρtF)=100/(7×10×4)=0.36 m/s? 差 10 倍？——**待人工复核**，见 §15。风险：流速校核本身误差不影响 A 主计算。
- **排气 ≥1.5 倍**：经验规则，无文献标准出处，作参考提示可接受（D 级）。

**⑤ 工程合理性**：
- **适用性**：奥赞公式与 Dietert 法主要用于**铸铁件封闭式浇注系统**（转包浇注）。代码对球铁/铸钢/铝（推荐开放式）也用同一奥赞式算阻流——文献明确奥赞式适用于封闭式；开放式阻流在直浇道底部，公式形式可延伸但 fv、Hp 含义需调整，代码未区分。**【存在问题：P1】**
- **fv**：文献铸铁湿型 μ=0.35~0.50（按砂型阻力大/中/小），干型 0.41~0.60，顶注 +0.10~0.20、底注 −0.10~0.20，封闭式 μ 上限 0.75。代码 fv={顶 0.8/中 0.6/底 0.45}——**顶注 0.8 超出文献上限 0.75，中注 0.6 也比"阻力中等 0.42+顶注修正"偏高**。A∝1/fv → A 系统性偏小 20~50% → 内浇道偏小 → 浇不足风险。同时文献指出奥赞计算值本身偏小，生产中常乘 1.1~1.3 增大系数——代码没有此系数，与 fv 偏大叠加。**【存在问题：P1】**
- **G 语义**：pw 来自 STL（零件净重，无加工余量、无冒口/浇道），而出品率表（yield.js）的典型值按"合格铸件（含余量毛坯）重量/铁水总重"统计——STL 净重偏小 3~8% → G 偏小。见 P0-3。
- **S直:S横:S内 比例**：代码预设（封闭 1:1.5:0.8~1:2.5:0.9、开放 1:2:2~1:3:3）在常见范围（灰铁 1:1.5:0.8~1:2:1、球铁/钢开放式 1:2:2~1:4:4 等）；推荐逻辑（灰铁封闭、球铁/钢/铝开放）与文献一致 ✓。**【OK】**
- **v≤1.8 m/s**：未在权威文献检索到 1.8 出处（常见为"内浇道出口流速不宜过高"，具体数值 1.5~2.5 因材料/壁厚而异）；代码对所有材料统一 1.8，铝/铜要求应更低。**【P2，来源未确认】**
- **未校验液面上升速度 vL=C/t**（文献要求 ≥0.8~3.0 cm/s 按壁厚）——大平面铸件可能产生冷隔/结壳。**【P2 建议补充】**

**⑥ 系数审计**：
| 系数 | 当前值 | 来源 | 判断 |
|---|---|---|---|
| 材质系数 f | 灰铁1.0/球铁0.85/铸钢0.8/铝1.2/铜0.9 | 【来源未确认】 | 语义与经典 Dietert 的壁厚系数（1.63~2.2）冲突，需人工核对 |
| 流量系数 fv | 0.8/0.6/0.45（按位置） | 与文献（0.35~0.50+位置修正）不符 | **系统性偏大** |
| 出品率区间 | 灰铁65-85/球铁55-75/钢50-65/铝70-90/铜55-70 | gating.js MATERIALS 表 | 与 yield.js 表（灰铁60-75等）不一致——**同参数两表并存**（PHASE 27-A P0-3 相关） |
| 密度 ρ | 灰铁7.0/球铁6.9/钢7.5/铝2.6/铜8.4 | — | 铸铁 7.0≈液态 ✓；铸钢 7.5 偏高（液态钢 7.0~7.2）；见 §8 |

**⑦ 当前最大风险**（只列影响结果可靠性的）：
1. **中注 Hp 公式错误**（A 偏大 30%+，Hp≤0 时全 0）
2. **fv 系统性偏大 + 无 1.1~1.3 增大系数**（A 偏小 20~50%，方向相反，两者叠加净偏差不确定——即用户无法预知 A 是偏大还是偏小）
3. **Dietert 变体来源未确认**（t 直接决定 A）

**⑧ 改进建议**：
- **P0**：中注 Hp 改文献式 Hp=H0−P²/(2C)（P=C/2），rh 定义确认后支持用户输入；riserWt 单位（见 3.5）
- **P0**：pw 语义——UI 提示"STL 净重，建议加加工余量后使用"或接入加工余量自动加成

- **P2**：v≤1.8 分材料；补液面上升速度校核；Hb 表标注来源

### 3.2 riser — 冒口设计 ★ 最高优先级

**① 工程目的**：按铸件模数 Mc 用模数法设计冒口尺寸（D/H），迭代满足"模数条件 Mr≥Mc×f + 体积条件 eff×Vr≥缩量"，并给冒口颈直径。

**② 当前输入**（runRiser，riser.js:75-82；calcManifest.js:91-99）：
| 参数 | 变量 | 单位 | 来源 | 合理性 |
|---|---|---|---|---|
| 材料 | mat | — | 项目 | ✓ |
| 铸件重量 | cast_wt | kg | geometry.weightKg | 同 P0-3（净重问题） |
| 热节模数 Mc | mc | mm | process.mcUsed | ✓ 链正确（无热结=bodyRef/2，有热结=最大热结 M） |
| 冒口形状 | shape | — | **硬编码 sphere_head** | P1（PHASE 27-A 已列） |
| 高径比 | hd_ratio | — | **硬编码 1.0** | P1 |
| 效率 | eff | — | 未传→用形状默认 | ✓ |

**③ 当前公式**：
```
Mr_need = Mc × f（f 从 1.10 起，+0.05 迭代，≤50 轮）            (riser.js:85-105)
D 由形状 DfromM(Mr_need, hd) 求（圆柱 M=DH/(2D+4H)、球 M=D/6、球顶柱 V/A）(riser.js:28-59)
H = round(D×hd)
Vr = 形状体积(mm³)；effV = Vr×eff
volOk = effV ≥ Vc×shrink，Vc = cast_wt×1e6/rho (mm³)            (riser.js:100-101)
冒口颈：M_neck = Mc×neck_k；d_neck = 4×M_neck                  (riser.js:109-110)
yieldPct = Vc/(Vc+Vr)                                          (riser.js:117)
```

**④ 公式正确性**：
- **Mr=Mc×f 迭代**：文献模数法要求 M铸件:M颈:M冒口 = 1:1.1:1.2（顶明冒口）/1:1.1:1.25（侧暗冒口），f 从 1.10 起步 ✓ 与文献下限一致；迭代至体积满足 ✓ 合理。**【正确】**
- **形状模数公式**：圆柱 M=DH/(2D+4H) ✓（《铸造工艺学》）；球 M=D/6 ✓；球顶柱按 V/A 数值积分 ✓。**【正确】**
- **体积校核**：文献为 **εv(V件+V冒) ≤ η×V冒**（缩孔体积 ≤ 有效补缩体积）；代码为 effV ≥ Vc×shrink——**漏掉冒口自身收缩 Vr×εv 项**。量级：Vr≈0.2Vc、shrink=0.03 → 漏项≈0.6%Vc vs 总缩量 3%Vc，约 20% 低估。模数条件通常主导，实际影响有限。**【基本正确但有条件：P2】**
- **Vc 单位**：cast_wt×1e6/rho → mm³ ✓（kg→g ×1000、cm³→mm³ ×1000），与 Vr(mm³) 可比 ✓。**【正确】**

**⑤ 工程合理性**：
- **Mc 语义切换**（calcManifest.js:108-112 → designCenter 回写）：无热结 Mc=bodyRef/2（板件精确、柱/梁类低估——保守侧是冒口偏大，安全）；有热结=最大热结 M（局部 V/A）✓ **切换逻辑工程上合理**；风险在热结漏报时（PHASE 25 非 90° 退化）回退 bodyRef/2 → 冒口可能不足。**【基本合理，边界风险 P1】**

### 3.3 shrinkage — 线收缩率

**① 工程目的**：按合金与收缩状态推荐模具放尺（线收缩率）。

**② 输入**：材料大类 + 三方向尺寸（STL 自动 ✓）+ 收缩方式（free/common/restrained）。

**③ 公式**（shrinkage.js:46-64）：
```
档位率：free=[restrained值, free值] / common=[restrained, common] / restrained=固定
t = clamp((size−100)/(1000−100), 0, 1)          ← 按绝对尺寸线性插值
rate = lo + (hi−lo)×t
SPLIT_RATE_DIFF=0.2 → 方向率差≥0.2% 则分方向放缩水
```

**④ 正确性**：数学正确 ✓。**⑤ 工程合理性**：**【存在问题】**——代码注释自己已承认"收缩率是'率'，同材同约束下与尺寸大小关系不大，真正拉开差距的是绝对放尺量"（shrinkage.js:8-9），但实现却按绝对尺寸取不同率（100mm→lo、1000mm→hi）。**线收缩率由合金种类+受阻程度决定，与绝对尺寸无直接关系**；同一铸件 50mm 与 1000mm 两个方向收缩率应基本相同（除非各方向约束不同）。当前实现把"率"当"随尺寸增长的量"——1000mm 方向取 hi（如铸钢 2.2%）恰恰可能反向（大方向约束点多，通常受阻更大、率更小）。**方向差异的正确依据是各方向型芯/筋板约束，不是尺寸**。实际影响：差 0.2 个百分点 × 1000mm = 2mm 放尺差——有工程意义。**【P1：算法逻辑与注释矛盾，应按方向约束分档】**

**⑥ 系数审计**：灰铁 0.8~1.0 / 球铁 0.6~1.0 / 铸钢 1.5~2.2 / 铝 0.8~1.1 / 铜 1.2~1.4（%）——全部在常见手册范围 ✓（铸钢 2.2 为上限值）。

**⑦ 最大风险**：方向率取错导致放尺偏差 ~0.2%×尺寸；综合比例（combined=hi）偏大方向安全侧。**⑧ 建议**：P1 按约束分档（或至少保留尺寸锚定同时标注"以约束为准"）；P2 把"分档依据"文案修正。

| 数据链 | 是否传递 | 工程上是否应该这样传递 |

1. **density 是否必须统一为项目级唯一来源**：必须统一为"项目级参数"，但**应拆成两个语义值**：液态密度（浇注计算）与固态密度（重量/体积）——单一值无法正确服务两个链（铸铁 7.0 vs 7.1 差异小，铸钢 7.0 vs 7.8 差异巨大）。P0。

## 14. 推荐下一阶段修改路线

**第 1 步（0.5 天，纯修正，无算法变更）**：TOP 1~4（单位 /1000→/1e6、中注 Hp 文献式、双密度、pw 提示）——全部是定位明确的机械修正，修复后可立即显著提升正确性。

**第 2 步（1 天，系数与参数校准）**：TOP 5~6（fv 文献表、t 公式出处确认）、#8（chill T 语义）、#10~11（machining/shakeout 接通 manifest）、#13（charge 牌号过滤）。

**第 3 步（与 UI 重设计合并）**：TOP 7 相关——参数面板"自动值/估算值/用户值"分级展示（PHASE 27-A 推荐的数据可信等级 UI 落地）；castability/ct 接 STL；riser 形状选择生效；线收缩率按约束分档。

**第 4 步（长期）**：球铁冒口工艺模式、非 90° 旋转鲁棒性、validateMesh 完整性检测、液面上升速度校核。

## 15. 未能确认、需要人工/文献进一步验证的问题

1. **Dietert 变体公式** `t=f×(√G+∛(wG/5))×2/3` 的出处——多源检索未见原形；若来自某手册中文版请提供书名页码，否则建议替换为经典式
2. **中注 Hp 的 rh 参数意图**——calcManifest 无 rh 输入（恒 0），代码 (Pv+C−rh)² 形式可能是从某教材移植（P=阻流到顶距离 + 中注修正？），需作者确认设计意图
3. **内浇道流速 1.8 m/s 出处**——经典文献常见"内浇道出口流速限制"但未见 1.8 具体值；且 v 校核式 `10G/(tρFg/100)` 的量纲换算待复核
4. **COOL_SMALL 冷却时间表原书分档**——《实用铸造手册》（陈琦·彭兆弟）的冷却时间表是否只针对铸铁件（代码注释未注明材质限制）
5. **SB_BURROW 表 3 的分档对象**——企业规范原文"砂型重量"与代码输入"铸件重量"是否一致
6. **JB/T 5105-2022 起模斜度数值**——在线检索不到全文，代码数值（140′/275′ 等）待对照标准原文
7. **chill 系数表**——《铸造工艺设计及应用》CNKI 词条与《铸造手册》冷铁章节数值差异核对（尤其可锻铸铁 1.0）
8. **GB/T 6414-2017 RMA 表 B.1 顶面余量**——代码 nextCoarserGrade 降一级的处理与标准"顶面/底面取粗一级"的文字对应关系

10. **奥赞公式对开放式浇注系统的适用边界**——代码对开放系统沿用封闭式公式，需要工艺书确认是否可接受或需专用方法
