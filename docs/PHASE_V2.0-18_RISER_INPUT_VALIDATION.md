## §1 修复前的缺陷与可达路径

### 1.1 独立复核（129.txt §三：「必须从当前实际代码独立核实，不得只照抄报告」）

**先说一条对 V2.0-17 的自我更正**：

> V2.0-17 §4.3 写「**负重量可从向导界面到达**」—— **这条是错的**。
> 我当时只查到 `wizard.js` **没有 import `numcheck`**，就下了结论，
> **漏看了向导自己的步骤门禁**：`wizard.js:241`
> `validate: () => state.partWt > 0 ? {ok:true} : {ok:false, msg:'👆 请输入铸件毛重（Kg）'}`
> 配合 `stepFrame` 的 `revalidate()`（`next.disabled = !v.ok`），
> **负重量 / 0 / 空都会禁用"下一步"，用户根本走不到计算那一步**。
> **教训与 V2.0-16 同源：「没有某个机制」不等于「没有保护」—— 要查完整的校验链，不能只 grep 一个函数名。**

**向导真正漏掉的是另外两处**（本阶段实测确认，见 §1.3）。

使紧邻的 `a > 0` 除零守卫**永远不可能触发** —— 守卫被写出来了，却被上一行架空。

## §2 参数合法性规则及其依据

### 2.1 三态语义

| 状态 | 判定 | 处置 |
|---|---|---|
| **未提供** | `undefined` / `null` / 空串 | 用**既有默认值**（逐条注明出处，见 §2.2）|
| **非法** | `±Infinity` · 非空且非数值的字符串 · 数值但越界 | **`return null`** |
| **合法** | 有限 number，且落在该参数区间内 | 参与计算 |

**关于 `NaN`（129.txt §四：「必须拒绝……包括 NaN」）**：
**默认按非法处理**，**唯一例外是 `eff`**：

- `eff` 在生产侧**确实存在**"清空输入框 ⇒ `NaN`"的路径：`riserView.js:170`
  `eff: parseFloat(q('#r_eff_…').value)` —— **它没写 `|| 默认值`**；
  而该输入框在 `checkNum(..., {min:0, max:100})` 下**未传 `required`**，空串**是允许的**。
  若把 `NaN` 判为非法，用户"清空效率框"会从"用表值"变成"整页无结果"⇒ **行为回归**。
- 其余参数（`cw`/`rho`/`hd`）的三个生产调用方**全都先做过 `|| 默认值`**，
  不可能传出 `NaN`（`calcManifest.js:269` 更是只传 `undefined` 或正数）⇒ 判为非法**零风险**。

**另有一条更强化的特例**：`cw` 的缺省值 `0` **本身就会关闭整条体积校核**，
所以 `NaN` 若也算"未提供"，就等于绕个弯把 §五.2 要杜绝的"意外关闭体积校核"放回来。
故 `cw` 用 `readNum(v, { nanIsAbsent: false })` —— **`NaN` 一律非法**。

### 2.2 逐参数规则表

| 参数 | 合法区间 | 未提供时的默认值 | 默认值的**依据**（129.txt §四：「必须确认是现有明确约定」）|
|---|---|---|---|
| `mc` | `> 0` 且**有限** | 无（`0` ⇒ 拒绝）| 既有 `Mc <= 0 ⇒ null`；本阶段**补** `Number.isFinite` |
| `cast_wt` | `≥ 0` 且有限 | **`0`** = 不做体积校核 | `riserStatus.js:41` 注释已文档化；`calcManifest.js:274` 显式 `\|\| 0` |
| `rho` | `> 0` 且有限 | `md.rho`（材料表）| `riser.js:82` 原 `input.rho ?? md.rho` 的**显式设计**；`calcManifest.js:269` 与本规则一致 |
| `hd_ratio` | `> 0` 且有限 | **`1.0`** | `calcManifest.js:280` **硬编码 1.0**；`riserView`/`wizard` 两个 select 的默认项都是 1.0 |
| `eff` | `> 0` 且有限 | `RISER_EFF[sd.effKey]` | `riser.js:18-24` 表头注明「源自《铸造手册》」；视图输入框带同名默认值 |
| `shape` | ∈ `RISER_SHAPES`（**自有属性**）| 无 ⇒ 拒绝 | 键集由 `riser.js:27-63` 定义 |
| `cast_a`（`mc_mode='volume'`）| `> 0` 且有限 | 无 ⇒ 拒绝 | `riserView` 对其用 `gt:0, required:true`；`\|\| 1` 是**为避免报错临时发明的值**，本阶段据 §四 移除 |

**关于"不擅自扩大或缩小范围"（129.txt §四）**：
- `eff` **未设上限** —— 原实现允许 `eff=500`（⇒ 5.0），本阶段**不发明**"≤100%"的上界，保持通过（只有 `> 0` 的下界，依据是该参数以 `effV = Vr × eff` 的形式参与体积判据，非正数会令判据失去意义）。
- `cast_wt` **未设上限** —— `cw = 1e6 kg` 仍返回结果（撞 f 上限）。
- `hd` **未设下界**（除 `> 0`）—— `hd = 1e-9` 仍返回结果，见 §9 U-1。
- `Mc` **未设上下界** —— `Mc = 1e6` 仍返回 `D = 6.6 m`，见 §9 U-2。
