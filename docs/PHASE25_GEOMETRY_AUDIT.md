**单位**：全部 mm（STL 无单位，解析层不换算——`stl.js` 头部注释明示；`designCenter` 的 scale 默认 1，即假设 STL 坐标 = mm）。**单位转换风险**：若用户 STL 是英寸，体积偏 16.4×、面积偏 6.45×——目前 UI 无单位选择入口，这是产品层缺口（非算法缺陷）。

**UI 模数与热结模数不是同一种东西**：概览"Mc" = wallMain/2（主体壁厚派生的工艺参数，半壁厚语义）；热结列表"M" = 细化场封顶 M 峰值（局部 V/A 模数，Chvorinov）。两者数学定义不同、用途不同、数值不可比。

## 3. 主体壁厚专项（最高优先级）

### 3.1 数学/统计定义

- **wallMain**：内部采样点半距直方图的"峰值"（需同时满足：峰值位于 ≥25% 桶位、占比 >20%、显著高于邻桶 1.3×）→ ×2；不满足则 **fallback = wallMax**；另外与 p95×2 取大修正（PHASE 19 多相位修正）。
- **wallAvg**：全部内部采样点半距的算术平均 ×2。**网格点平均**（体素均匀 → 近似体积加权，但受网格相位/表面几何调制）。
- **wallMax**：内部点最大半距 ×2 + 亚体素精化 = **最大内切球直径**（下界意义的"最厚处完整厚度"）。

### 3.2 ALR2510 wallMain=17.2/wallAvg=2.34/wallMax=17.2 的机制（§D 实证）

直方图（orig，nb=12，rawBin=1.43mm 半距）：

```
[0.7:941] [2.0:908] [3.3:761] [4.6:137] [5.9:76] [7.2:39] [8.5:32] [9.9:4] [11.2:12] [12.5:2] [13.8:13] [15.1:5]
```

- 薄壁主体（半距 0.7-3.3mm，即壁厚 1.4-6.6mm）占 **89%** 采样点 → 峰值桶 = 0（0.7mm）
- 厚大轨（半距 ≥8.5mm）只有 107 点（3.7%）
- 判据 `peak ≥ nb×0.25` → 0 < 3 → **sharp=false → wallMain = wallMax = 17.2**（fallback）
- 之后 p95×2 修正：95 分位落在厚轨区 → p95w ≈ 17.2 → 修正不改变

**结论**：wallMain=17.2 是**直方图峰值检测失败后的 fallback**（峰值在最低桶不满足"中段"判据），代表"最厚处壁厚"而非"主体壁厚"。**这是统计定义的错误 fallback，不是合理统计定义**。wallAvg=2.34 反而正确反映了主体（89% 薄壁）。

**矛盾证据**：V3 采样 warning 链内部用 bodyWallOf（wallMain 17.2 未通过 0.9×wallMax 可信校验 → fallback wallAvg=2.34 → bodyRef=max(2.34, tP50=3.6)=3.6，正确识别薄主体）；而 **UI 概览"主体壁厚"直接显示 wallMain=17.2（错误）**。同一模型，UI 与 warning 对"主体壁厚"给出两个矛盾的答案——UI 显示误导。

### 3.3 结论

UI 的"主体壁厚"**不代表"铸件主体区域的典型壁厚"**，它代表"直方图峰值或（检测失败时）最大壁厚"。对薄壁+厚大结构模型（ALR2510 类），UI 显示值可误导 5-8×。

## 4. 旋转不变性实测结果（§B/§C/§E）

### 4.1 精确几何量：完全旋转不变 ✓

36 次运行中体积/面积波动 **全部 0%**（含非 90° 旋转）。bbox 数值按姿态排列（正常）。

### 4.2 采样统计量：随网格相位波动（90° 内）

| ALR2510 v1 | ±13.8% | ±3.3% | **±13.8%**（=wallMax，fallback） | **5 全保持** | ±10%（厚轨 Δ1-2mm） |
| ALR2510 v1_1 | ±2.4% | ±1.8% | ±2.4% | 2 保持 | ±6-10% |

| bossOnPlate | ±1.7% | ±10.2% | ±1.7% | 1 保持 | ±8% |

（注：wallMain 波动大时恰是 wallMain==wallMax 的 fallback 场景——波动来源是 wallMax 而非峰值检测本身。）

### 4.3 90° 轴对齐旋转（rx/ry/rz90）关键结论

- **热结数量：5/6 模型全保持**（只有 ALHR4510 的 rz30——非 90°——丢到 0）
- **厚大结构热结位置强健**：ALR2510 两条厚轨在全部 6 姿态 Δ1-2mm；薄壁壁峰（M≈1.3）漂移 20-60mm（网格相位移动）
- **热结 M 波动 ≤10%**（工程可接受）
- wallMax/wallAvg 波动 ≤15%；wallMain 因 fallback 可跳变 38-44%（见 §3）

### 4.4 非 90° 旋转（rz30/o45——极端场景）

- bbox 外扩 → mdim 变大 → **vs 变粗**（采样降级）
- ALHR4510 rz30：**5 热结 → 0**（NO_HOTSPOT）——采样相位 + vs 综合退化
- bossOnPlate o45：wallMax 59→**216.9（+267%）**——scanInside 对 45° 斜置薄板（8mm）误判，bbox 角落（模型外）点被投票判为内部
- 热结位置漂移普遍增大（20-100mm）

### 4.5 方向依赖定位（§十逐项）

| 依赖点 | 位置 | 影响 | 严重度 |

## 5. 采样率与几何数据关系（§十一）

| 数据 | 依赖采样率/BVH？ |
|---|---|
| 体积/表面积/bbox/三角面数 | **完全不依赖**（精确几何） |
| wallMax/wallAvg/wallMain | 依赖（距离场采样） |
| tP10/tP50/thinFrac | 依赖（V3 采样点） |
| estMinWall/vs/gs | 采样链自产 |
| 热结全部数据 | 依赖（粗场+细化） |
| warning 层级 | 依赖（vs + bodyRef） |

**区分**："模型几何基础数据"中体积/面积/尺寸是精确的；壁厚三件套是采样统计量；热结分析是采样估算链。不要因为壁厚是采样量就认为体积也是采样量（旧报告曾混淆）。

## 6. 问题清单与优先级（§十四）

### P0 = 必须修（1 项，UI 展示层）

**P0-1 主体壁厚 UI 显示语义错误**：wallMain 峰值检测失败时 fallback 到 wallMax，UI"主体壁厚"显示最厚处壁厚（ALR2510 17.2 vs 真实主体 2-3mm，误导 5-8×）。修复方向（本阶段不动手）：
- 方案 A（推荐）：UI"主体壁厚"改用与 samplingWarn 一致的 bodyRef 链（wallMain 可信校验 → wallAvg → wallMax，再与 tP50 取大）——warning 链路已正确，UI 与之一致化即可
- 方案 B：wallMain 检测失败时 fallback 到 wallAvg 而非 wallMax（改 geometryAnalysis）
- 两种方案都只影响 UI 展示，不影响热结/采样链

### P1 = 建议修（2 项）

**P1-1 热结链非 90° 旋转鲁棒性**（ALHR4510 rz30 5→0）：根因 = 非 90° 旋转 bbox 外扩 → mdim 变大 → vs 变粗 + 网格相位双重退化。修复思路（记录）：对 mdim 增量敏感的场景保持 vs 不变（用原始最小外接方向）、或探测阶段对候选区域强制细化。用户正常导入（轴对齐）不受影响，故 P1。
**P1-2 wallMax 亚体素细化范围**：argmax 邻域 ±2×vs/4 太小，argmax 位置随相位漂移时 wallMax 波动 ±5-14%。可扩大到更大邻域或对 top-k 体素细化。

### P2 = 以后修（2 项）

**P2-1 estMinWall 相位敏感**（bossOnPlate rx90 warning 级跳变）：探测网格只有单相位（16³ 级），可加半格偏移取 p10 均值。
**P2-2 scanInside 45° 斜薄结构误判**（bossOnPlate o45 wallMax +267%）：三方向投票对薄板斜置失效，可加网格点合法性校验（距离场值 > 阈值 的内部点才是真内部——距离场本身可自校验）。

### P3 = 不值得修 / 明确不动

- **modulusCeilRatio、采样率默认策略、hotspot.position/displayPosition、V2/V3 核心语义**：本阶段与命令文件双重确认——不动
- **wallAvg 的"点数平均"定义**：±10% 内工程可用，不修
- **非 90° 场景的 bbox 外扩**：几何事实，非缺陷
- **体积/面积的 0.04-0.88% 网格离散偏差**：模型本身近似，非算法误差

## 7. 最终结论（§十五 A-H）

**A. 当前几何数据可直接用于生产 UI 展示吗？**
可以，但有条件：体积/表面积/尺寸/三角面数**可直接展示**（精确）；wallMax/wallAvg 可在 ±10% 工程精度下展示；**wallMain 当前不可直接展示**（P0 fallback 语义错误）；热结结果在 90° 轴对齐姿态下稳定可用。

**B. "主体壁厚"现在可信吗？**
UI 显示的 wallMain **不可信**（ALR2510 实测 17.2 vs 真实主体 2-3mm）；V3 warning 链内部的 bodyRef（bodyWallOf→wallAvg + tP50 取大）**可信**（3.6mm，与实测 2-3mm 一致）。

**C. 主体壁厚与 STL 的 XYZ 朝向有关吗？**
**有关**。壁厚三件套全是轴对齐网格的采样统计量，旋转改变网格相位 → wallMax ±5-14%、wallAvg ±3-15%、wallMain（fallback 场景）±14-44% 波动。

**D. 用户以后必须按 Z 轴朝上导入 STL 吗？**
**不需要**。

**E. 为什么不需要？**
- 精确几何量（体积/面积/尺寸/三角面）完全旋转不变（36 次实测 0% 波动）
- 90° 轴对齐旋转（用户常见操作）下：热结数量 5/6 模型全保持、厚大结构热结位置 Δ1-2mm、热结 M ≤10%、warning 级保持
- 采样统计量 ±10-15% 波动在工程判断范围内（P0 修完后 wallMain 不再受其害）
- 只有极端非 90° 斜置（30-45°）才出现热结丢失/误判——且这是所有体素类方法的固有限制，修复成本高、收益低（P1 记录）

**F. 如果不需要，为什么？**（同 E——不强制）

**G. 当前最该修的 1-3 个问题？**
1. **P0：UI"主体壁厚"展示语义**（wallMain fallback → wallMax 误导）——与 warning 链 bodyRef 一致化
2. **P1：热结链非 90° 旋转鲁棒性**（vs 变粗 + 相位退化）——记录风险，待正常使用场景评估
3. **P1：wallMax 亚体素细化范围扩大**——降低 ±5-14% 相位波动

**H. 结论：**
**当前不需要修改核心几何算法，可以进入 UI/信息架构阶段。** 前提是先修 P0-1（纯 UI 展示层，一行级改动，不动任何核心计算语义）。P1 项作为已知风险记录，不阻塞后续阶段。
