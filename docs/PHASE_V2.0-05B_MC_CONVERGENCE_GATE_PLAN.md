## 三、门禁定义：用「工程结果收敛」，不用百分比

```
判据：把相邻两档的 Mc 分别灌进 runRiser（同材料/形状/hd/净重）
     → |ΔD| ≤ 1 mm 且 |ΔH| ≤ 1 mm 且 ΔMc 单调
```

**推导（关键）**：`D = Math.round(Mr_need × 6)`（圆柱 hd=1）

> **1 个直径档 = ΔMc 的 0.1515 mm** = Mc=10 时 **1.52%** / Mc=5 时 **3.03%** / Mc=15 时 **1.01%**

**要求 Mc 收敛到 ±1%，而输出本身只分辨 1.5~3%，是在要求产品表达不出的精度。**

**判别力已用历史数据回测**（密度轴，cyl hd=1）：

| 模型 | ΔMc | ⇒ ΔD | 判定 |
|---|---|---|---|
| t01 / t20 | 0.000 | **0 mm** | ✅ PASS |
| t16 | +0.14 | **1 mm** | ✅ PASS |
| t08 | +0.08 | **1 mm** | ✅ PASS |
| **t05** | +0.89 | **7 mm** | ❌ FAIL |
| **t19** | +0.72 | **6 mm** | ❌ FAIL |

→ 把"稳的"与"真会跨档的"干净分开。

## 五、Gate v1 判据

| 结果 | 条件 |
|---|---|
| **PASS** | 连续两档都满足 `\|ΔD\| ≤ 1mm` 且 `\|ΔH\| ≤ 1mm` 且 ΔMc 单调不反向 |
| **WARN** | `1 < \|ΔD\| ≤ 3 mm` |
| **FAIL** | `\|ΔD\| > 3 mm` 或非单调 或**峰集合改变**（appeared / disappeared） |

- **只判主热结**（Mc 最大者）。次热结单独列 WARN 表，**不参与判定**（历史上次热结 −25.5%，纳入则门禁永远红）
- **Mc 按位置配对**，不按列表序号（容差 `max(3mm, 0.05×对角线)`）。依据：V2.0-03 实测"按序号配 6 处误报、按位置配 0 处"
- **FAIL 后**：不改阈值、不改 V3 参数、不改 `modulusCeilRatio`（105.txt §铁律）。
  写入 `KNOWN_LIMITATIONS`；**若 HR4012 FAIL → 纯模数法路线暂停**，回到"体积校核主导"的现状。
- **可冻结 Hotspot V3 的条件（三条同时成立）**：① 主热结全绿（或 FAIL 项已记录且有产品提示）② 门禁**落成常设测试**（非一次性报告）③ 纯模数法路线明确声明继承 rotation ≤32% 的已知限制。

## 六、Rotation：不进 gate，只作 WARNING

- **分类**：**geometric limitation**，不是 numerical convergence。
  依据：V2.0-04 证明**求交算法自身 81/81 旋转不变（Δ=±0.000%）**；漂移来自 AABB 锚定 + 轴对齐体素网格（`sampling.js:89/163/332`）。**收敛限制会随分辨率提高缩小，这个不会** —— PHASE 23 实测反而更漂。
- **不参与 PASS/FAIL**，单独输出 `rotationSpread`（同件 ↻X/↻Y/↻Z 的 Mc 最大相对偏差）
- **不在本阶段修复**（= 重新设计 V3，105.txt 明令禁止）
- 已登记边界：90° ≤10%（PHASE 25）· 任意轴 ≤32%（PHASE 29）· 实测最差 −32.95%（V2.0-04）

## 七、两条顺带查出的问题（只报，不修）

1. **`opts.resolution` 在 V3 里是空转键** —— `js/engine/v3/**` 无一处消费它（`V3_DEFAULTS` 只有 `coarseResolution`）。
   即 `hotspot_regression_test.mjs:148` 的 `{resolution: 96}` **实际没有改变分辨率**。它是 V3 一族**唯一的分辨率断言** → **"V3 从没测过分辨率"比原来更硬**。

2. **V2.0-03 的"Mc 逐位不变"是必然结果，不是证据** —— 它改的是 `cellVol`，**不触碰 `sample.pts`**，而 `peakModulus` 直接来自场值。
   该证据只证明"这次改动没动 Mc"，**不是"Mc 对 stride 免疫"**。（疑虑已由 §四 的"stride 是 gs 的确定函数"化解。）

## 附：一条必须随门禁一起记住的事实

本次实测：**HR4012 上 Mc 从 8 → 20（+150%），冒口的 D / H / Vr 一个数都不变**（D 恒 144mm、16.65kg）——今天 Mc 的误差是被**体积校核**吸收掉的。

**⇒ 改走纯模数法 = 把这层遮蔽拿掉。这才是这个门禁现在才重要的理由，也是它必须用"工程结果收敛"而不是"数值收敛"的理由。**
