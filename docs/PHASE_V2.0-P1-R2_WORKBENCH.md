## 0. 一句话

把设计中心从"网页式内容流"改造成**固定视口工程工作台**：页面本身不滚动，
顶部紧凑工具栏 / 左侧信息栏 / 中央三维 / 底部状态栏四段式；参数改为**二次输入对话框**；
分析结果改为**工作台内视图切换**——点导航不再发生任何页面滚动跳转。

**计算与数据契约零改动**：10 个冻结指纹逐位不变（见 §7）。

## 1. 结构（144 §二/§三）

```
body.view-dc .main  ← height:100vh; overflow:hidden（页面不滚动的实现点）
└─ .view（flex column, overflow:hidden, 无入场动画）
   └─ .dc-ws（grid: auto / minmax(0,1fr) / auto / auto）
      ├─ A .dc-topbar       46px 紧凑工具栏：模型 | 参数 | 结果 | 开始分析 | 视图
      ├─ .dc-body
      │   ├─ .dc-main       grid: 300px 左栏 + minmax(0,1fr) 三维
      │   │   ├─ B #dc_rail 信息栏（内部滚动；窄屏改浮层）
      │   │   └─ C .dc-stage 三维工作区（吃满剩余高度；视口控件/热结条改浮层）
      │   ├─ #dc_results    结果工作区（§五：与模型工作区互斥的视图）
      │   ├─ E #dc_panel    参数对话框浮层（+ #dc_dlgLayer 遮罩）
      │   └─ …
      ├─ #dc_staleBar      过期 / 失败横幅
      └─ D .dc-statusbar   单位 · 模型 · 热结 · 参数与结果状态
```

要点与理由：

* **`body.view-dc .view { animation: none }`** —— 入场动画的 `transform` 会成为固定/绝对定位的包含块。
* **对话框浮层放在 `.dc-body` 内**（不是 `position:fixed`）：它天然只覆盖"工具栏以下、状态栏以上"，
  工具栏与状态栏永远可见可点，**不必用 JS 去算工具栏高度**（上一轮那套 `--dc-drawer-top` 已删除）。
* **删掉了 `.page-head` 大标题**（固定视口里 ~90px 死空间）：标题折进工具栏（`.page-title` 文案不变），
  副标题移到 title 提示。**删掉了「铸件信息卡」**：它列的 7 项与左栏概览逐项重复（§三.2 要求消除重复卡片），
  只有"文件名"是概览没有的 ⇒ 进状态栏。

## 2. 参数二次输入对话框（144 §四）

* **复用**既有 `state.draft` / `state.mod` / `saveModule` —— **没有第二套参数状态**。
  对话框只是"把同一批 DOM 显示在浮层里"：打开/关闭不重渲参数区，输入框内容与光标不受影响。
* 底部：`● 未保存：冒口参数` + `[取消] [💾 保存并返回工作台]`；模块内另有 `[保存冒口参数] [放弃修改]`。
* **关闭语义**：有草稿 → 先出**行内确认条**（`继续编辑 / 放弃修改并关闭`，不是模态套模态）；
  无草稿 → 直接关。`Esc` 优先处理对话框，再退放大。
* **「保存并返回工作台」= 提交所有脏模块**（不留静默丢失的草稿）。

## 3. 结果：三层体系（144 §五/§六）

* **消除页面滚动跳转**：原 `box.scrollIntoView()` 删除，改为 `setWorkspaceView('results')`。
* **刻意不自动切视图**：固定视口下模型/结果互斥，自动切走会把三维（刚跑完的模型、热结位置）整个藏起来，
  而且改个参数想再跑一次还得先切回来。改为**明确就绪反馈**：状态 chip + 「结果」入口高亮 6s + toast +
  步骤卡指向"查看分析结果"。
* **第一层 `#dc_coreStrip` 本页结论速览**：冒口页 = D / H / Mr_actual（达标文字）/ Mr_target；
  浇注页 = t / A / 内浇道流速 / 排气比；工艺性页 = 四张详卡的结论 + 状态文字。
  ⚠ **只搬运已算出的值**（读的是同一批对象，`buildPage1Data` 只跑一次），不新增任何计算或判级。
* **第二层**：`.dc-result-sec` 统一卡片外观。**第三层**：旧体积模型参考折进 `<details class="dc-note">`
  （文案一字未改，仍进 textContent）。
* 状态一律 **文字 + 颜色** 双通道。

## 4. 移动端（144 §二）

* `<960px`：左栏从常驻改**可展开浮层**（三维优先）；`.dc-body { overflow:hidden }` 防"收起"后仍挡点击。
* 点热结后自动收起左栏，否则"3D↔列表双向联动"根本看不见。
* 底部标签栏是 fixed ⇒ 工作台必须让出高度（否则状态栏被压在标签栏下）。
* 预览设置：手机端工具栏/状态栏按触控密度（≥28px）收一档。

## 5. 顺手修掉的既有缺陷（都被实拍或测试抓到）

| # | 缺陷 | 说明 |
|---|---|---|
| 1 | **工具栏监听叠加** | `#dc_zoom3d` 等按钮的监听绑在 `renderParams` 里，而它只重渲 `#dc_params` ⇒ **每次重渲都再挂一遍**；`setZoom3d(!state.zoom3d)` 被调用两次正好抵消 ⇒ **渲染次数为偶数时"放大"完全失灵**。已把工具栏绑定上移到 `render()`。 |
| 2 | `[hidden]` 被类选择器盖掉 | `.dc-import-zone{display:flex}` 让导入后拖拽区仍占半屏。现在 `.dc-ws [hidden] { display:none !important }` **一次性消灭这一类**。 |
| 3 | **对话框不居中** | 遗留的 `.dc-panel { flex-direction: column }`（"参数区常驻右栏"时代）排在新的 `.dc-panel` 之后，同权重后写者胜 ⇒ 水平居中失效、对话框贴左。已删除该遗留规则。 |
| 4 | 概览状态 chip 无颜色 | `.chip-ok` 只在 `.dc-overview-grid` / `.dc-cast-stats` 下定义，而实际渲染用 `.dc-ov-grid` ⇒ "分析正常 / 通过"一直是灰 chip。 |
| 5 | 抽屉状态与界面不一致 | 勾选热结只刷新页签圆点，不刷新对话框页脚 ⇒ 横幅说"有未保存"、页脚写"当前没有未保存的修改"；"放弃修改并关闭"只清 state 不重画，屏幕上留着旧横幅与圆点。 |
| 6 | 移动端顶栏动作被压扁 | "关于 / 反馈"被 flex 压成两行竖排 ⇒ 动作组 `flex: 0 0 auto`。 |
| 7 | `.dc-step*` 命名冲突 | 与 V2.3 遗留同名组件冲突（JS 零引用，已核实）⇒ **本轮删除该遗留样式块**（144 §七 明确要求排查）。同时清掉 `.dc-cast-card*` / `.dc-overview-grid*` 等确认无消费者的死样式。 |
